Chapter 7

该做 / 不该做

✓ Do

  • 颜色一律走 CSS 变量
  • 复用 Base* 基元，对齐其密度/圆角
  • 氛围靠 ::before/::after 辉光 + backdrop-filter
  • 动效统一 --transition 缓动
  • 文字层级用暖白透明度，不用冷灰
  • 标记用弱描边小字

✕ Don't

  • 硬编码 HEX / 引入青紫渐变霓虹（AI-slop）
  • 给房间根铺不透明渐变背景
  • 用 height:100vh 硬撑视图根
  • 另起 border-radius / padding 数值体系
  • 组件内硬编码宪法软效果
  • 强依赖外部字体 CDN
