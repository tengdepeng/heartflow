# 第11类 · 感知 / 系统 / 设备（11个）

> **核心答案**：手机传感器怎么用
> **影响模块**：感知层 / 模块三十·地图室
> **宪法兼容**：传感器数据仅本地处理、脱敏元数据；拒绝云端上传与行为追踪；网络能力类仅作本地参考。

---

## 一、蓝图规格内 App（8个）

### 1. 传送门（智能文本识别与快捷操作）
- **核心功能**：是 MIUI 系统的智能文本识别与快捷操作组件，核心功能是在用户长按或选中文本时，自动识别文本中的实体类型（人名、地名、链接、快递单号、航班号等），并在屏幕底部弹出对应的快捷操作卡片。
- **借鉴点**：
  1. 长按文本智能识别——书签入口架「速查」
  2. 实体类型自动分类——感知层「文本感知」
  3. 快递/航班自动追踪——书签入口架「物流追踪」
  4. 翻译/搜索快捷入口——知微阁「速查工具」
  5. 卡片式结果展示——书签入口架「信息卡片」
  6. 剪贴板历史——感知层「剪贴板管理」
- **目标房间**：感知层 / 模块三十三·书签与入口架 / 模块三十四·知微阁

### 2. 互传（跨设备文件传输）
- **核心功能**：以「跨设备文件传输」为核心，支持手机与手机、手机与电脑之间的文件传输。跨设备文件传输的体验可借鉴到输出管理的数据导出和设备间同步场景。
- **借鉴点**：
  1. 跨设备文件传输——输出管理「设备传输」
  2. 传输速度优化——感知层「传输优化」
  3. 文件类型筛选——输出管理「文件筛选」
- **目标房间**：模块一·输出管理 / 感知层

### 3. 健康数据共享（统一健康数据中枢）
- **核心功能**：Android 系统级的健康数据统一存储与共享平台，核心理念是打破各健康应用之间的数据孤岛，让不同应用的数据汇聚到一个中心化的本地数据库中，并允许授权应用读取和写入。
- **借鉴点**：
  1. 统一健康数据模型——身体温室「健康数据中枢」
  2. 跨应用数据聚合——身体温室「数据聚合」
  3. 细粒度权限控制——感知层「数据权限」
  4. 数据变化自动同步——身体温室「数据联动」
  5. 历史数据趋势分析——身体温室「趋势仪表盘」
- **目标房间**：模块十五·身体温室 / 感知层

### 4. 卫星云图（卫星云图实时监测与天气推演）
- **核心功能**：基于实时气象卫星数据，为用户提供全球云图、降水雷达、台风路径等可视化气象信息。核心价值在于将抽象的气象数据转化为直观的视觉化图像。
- **借鉴点**：
  1. 云图时间轴回放——时间长廊「情绪气象图」
  2. 多通道卫星图像切换——守护室「氛围通道」
  3. 台风路径追踪——时间长廊「事件风暴追踪」
  4. 降水雷达动画——守护室「环境预警」
  5. 全球视角缩放——时间长廊「时间尺度缩放」
- **目标房间**：模块三·时间长廊 / 模块六·守护室

### 5. 堪舆山水卫星地图（风水地理与山水格局分析）
- **核心功能**：结合卫星地图与风水堪舆理论的应用，核心功能是通过卫星影像分析地形地貌，识别山脉走势（龙脉）、水流方向（水口）、地形格局（四象）等风水要素。
- **借鉴点**：
  1. 卫星地图+罗盘叠加——地图室「空间罗盘」
  2. 多层地理信息图层——地图室「信息图层」
  3. 山脉走势分析——知微阁「知识山脉」
  4. 四象格局分析——地图室「空间四象」
  5. 二十四山向方位——知微阁「二十四节气方位」
- **目标房间**：模块三十·地图室 / 模块三十四·知微阁

### 6. 全球街景高清地图（高清街景地图）
- **核心功能**：以「高清街景+全球地图」为核心，街景地图和地点浏览的体验可借鉴到地图室的足迹回溯和地点记忆。
- **借鉴点**：
  1. 街景浏览——地图室「街景回溯」
  2. 地点搜索与收藏——地图室「地点收藏」
  3. 路线规划——地图室「路线回顾」
- **目标房间**：模块三十·地图室

### 7. 地图帝（高清地图浏览）
- **核心功能**：以「高清地图浏览」为核心，借鉴点与全球街景高清地图类似——地图浏览和地点标记功能。
- **借鉴点**：
  1. 高清地图浏览——地图室「高清地图」
  2. 离线地图——地图室「离线地图」
  3. 地点标注与分类——地图室「地点标注」
- **目标房间**：模块三十·地图室

### 8. 元地球Earth（3D地球可视化）
- **核心功能**：以「3D 地球可视化」为核心，提供 3D 地球模型浏览和地理信息查看。3D 地理可视化的思想可借鉴到地图室的足迹记录和可视化。
- **借鉴点**：
  1. 3D 地球可视化——地图室「3D 地球」
  2. 地理标记——地图室「地点标记」
  3. 卫星视图/街景——地图室「地图视图」
- **目标房间**：模块三十·地图室

## 三、落地要点小结（感知层 / 模块三十·地图室）

1. **文本感知**：吸收传送门——长按文本实体识别、快捷操作卡片、剪贴板历史。
2. **数据权限**：吸收健康数据共享——统一数据模型、细粒度权限、跨应用聚合（本地脱敏）。
3. **气象可视化**：吸收卫星云图——云图时间轴回放、多通道切换、事件追踪。
4. **地理感知**：吸收元地球/街景/地图帝/堪舆——3D 地球、街景回溯、离线地图、多层地理信息图层。
5. **网络能力**：Clash Meta/OurPlay/UU 仅作本地网络能力参考。
6. **拒绝**：云端上传、行为追踪、传感器数据外泄。
