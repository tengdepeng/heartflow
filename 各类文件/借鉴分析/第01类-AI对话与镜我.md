# 第1类 · AI对话 / 幕僚 / 镜我（20个）

> **核心答案**：镜我这张脸怎么长出来
> **影响模块**：模块七·镜我
> **宪法兼容**：全部能力本地化改造；拒绝云端账号、评价性回复、吉祥物化、分支人格；仅保留「陈列而非叙事」的对话与推理可见性。

---

## 一、蓝图规格内 App（8个）

### 1. DeepSeek（深度思考型AI助手）
- **核心功能**：以「深度思考型AI助手」为核心，支持长文本理解、代码生成、逻辑推理和多轮对话。深度思考模式会在回答前展示推理过程，让用户理解 AI 的思考路径。文件可被上传并分析内容。
- **借鉴点**：
  1. 深度思考模式——对话中展示推理过程（对应镜我「定音锤四幕」的推理可见性）
  2. 长文本理解——摘要/分析/问答
  3. 多轮对话——保持上下文记忆，支持分支和回溯
  4. 代码生成与调试——生成/解释/调试
  5. 文件上传分析——自动分析内容，提取摘要和关键信息
- **目标房间**：模块七·镜我 / 模块十·经略阁

### 2. Kimi（超长上下文AI助手）
- **核心功能**：以「超长上下文AI助手」为核心，能够一次性处理超长文本，包括整本书、长篇论文、完整代码库等文件。用户上传 PDF、Word、PPT、网页链接等文件后，可基于文件内容进行问答、摘要、翻译和分析。
- **借鉴点**：
  1. 文件对话——基于上传文件问答/摘要/分析
  2. 超长上下文——整本书级别内容分析
  3. 网页链接解析——抓取网页内容并分析
  4. 多语言翻译——AI 高质量翻译，保留语义和风格
  5. 编程辅助——代码生成/解释/调试/优化建议
- **目标房间**：模块七·镜我 / 模块十·经略阁

### 3. 千问（多模态理解AI助手）
- **核心功能**：以「通义千问」为核心，支持文本、图片、语音、视频等多模态输入。用户可上传图片让 AI 描述内容、分析图表、识别物体，也可上传语音让 AI 转写并分析，上传视频让 AI 总结内容。
- **借鉴点**：
  1. 多模态理解——文本/图片/语音/视频输入
  2. 图片分析——描述内容/识别物体/解读图表
  3. 语音转写与分析——转写并编辑修正
  4. 创意写作辅助——灵感/续写/改写建议
  5. 对话风格切换——专业/创意/简洁
- **目标房间**：模块七·镜我 / 模块十·经略阁 / 模块九·思绪书房

### 4. TRAE（AI编程助手与项目级代码理解）
- **核心功能**：以「AI编程助手」为核心，专注于编程辅助场景。TRAE 不仅能回答单个代码问题，还能理解整个项目的代码结构和依赖关系，提供跨文件重构建议、Bug 定位和架构分析。
- **借鉴点**：
  1. 项目级代码理解——理解项目结构和依赖关系
  2. 智能代码补全——基于上下文感知
  3. Bug 定位与修复建议——定位 Bug 并提供修复方案
  4. 对话式编程——自然语言描述需求，AI 生成代码
  5. 代码审查——检查质量/安全漏洞/性能问题
- **目标房间**：模块七·镜我 / 模块一·输出管理

### 5. WorkBuddy（AI工作伙伴与工作流自动化）
- **核心功能**：以「AI工作伙伴」为核心，支持文档处理、会议纪要、任务管理、日程安排等办公场景。用户可通过自然语言描述工作任务，WorkBuddy 自动拆解为子任务、分配优先级、设置截止日期，并跨工具执行操作。
- **借鉴点**：
  1. 工作流自动化——自然语言描述→拆解子任务→设置优先级
  2. 会议纪要生成——录音转写→摘要→提取待办
  3. 文档处理——AI 辅助写作/编辑/格式调整
  4. 跨工具协同——任务/日历/文档/导出联动
  5. 自然语言交互——自然语言描述需求，AI 理解并执行
- **目标房间**：模块七·镜我 / 模块二十一·更漏

### 6. ima（个人知识库AI助手）
- **核心功能**：以「个人知识库AI助手」为核心，支持用户上传文档构建个人知识库。用户可上传 PDF、Word、网页链接等文档，AI 基于用户知识库进行问答和知识检索，所有问答优先基于用户自己的知识库。
- **借鉴点**：
  1. 个人知识库构建——上传文档→自动构建知识索引
  2. 基于知识库的 AI 问答——答案来源可追溯
  3. 文档解析——自动解析 PDF/Word/网页内容
  4. 知识图谱可视化——展示概念关联和知识结构
  5. 智能标签——AI 自动生成标签和分类
- **目标房间**：模块十·经略阁 / 模块七·镜我

### 7. 扣子（AI Bot搭建平台）
- **核心功能**：以「AI Bot搭建平台」为核心，用户可通过可视化界面搭建自定义 AI Bot。每个 Bot 可独立配置知识库、工作流、插件、系统提示词和交互风格，用户可在不同场景下切换不同 Bot。
- **借鉴点**：
  1. 多 Bot 创建——多个不同用途的对话分身
  2. 可视化 Bot 配置——知识库/工作流/交互风格配置
  3. 知识库绑定——每个分身绑定专属知识库
  4. 工作流编排——多步骤自动化流程
  5. Bot 模板市场——预设常用场景模板
- **目标房间**：模块七·镜我 / 模块一·输出管理

### 8. 秘塔AI搜索（AI驱动的深度搜索）
- **核心功能**：以「AI驱动的深度搜索」为核心，对搜索结果进行语义理解、信息整合和结构化呈现。搜索结果不是链接列表，而是包含「概述」「要点」「来源」的结构化摘要，用户还可一键生成思维导图或大纲。
- **借鉴点**：
  1. 结构化搜索结果——概述/要点/来源
  2. 思维导图生成——搜索结果生成思维导图
  3. 信息来源标注——每条信息标注来源
  4. 深度搜索——AI 理解搜索意图，整合多源信息
  5. 学术搜索模式——优先检索学术文献
- **目标房间**：模块十·经略阁 / 模块七·镜我

## 二、补充参考 App（12个，通用产品知识）

### 9. 蚂蚁阿福（情感陪伴）
- **核心功能**：以「情感陪伴」为核心，不是工具、不是助手，而是一个安静的陪伴者。通过拟人化形象、日常问候、倾听回应，提供情绪价值而非任务执行。
- **借鉴点**：
  1. 陪伴者定位——镜我「安静陪伴」而非「工具助手」
  2. 拟人化形象——温和的视觉形象与语气
  3. 倾听式回应——先听再说，不急于给建议
  4. 日常微互动——低打扰的问候与关怀

## 三、落地要点小结（模块七·镜我）

1. **推理可见性**：吸收 DeepSeek「深度思考模式」——镜我回答前展示推理路径，对应「定音锤四幕」。
2. **场景卡 / 工具卡 / 归档**：吸收 Kimi 文件对话、TRAE 项目理解、ima 知识库问答——镜我可基于用户本地资料作答并标注出处。
3. **流式对话**：吸收豆包、讯飞星火的语音对话与流式输出。
4. **多分身**：吸收扣子「多 Bot」——镜我支持「不同自我」的对话分身，但拒绝云端账号与分支人格。
5. **陈列而非叙事**：吸收蚂蚁阿福「安静陪伴者」定位——镜我是陪伴者而非评判者，拒绝评价性回复与吉祥物化。
6. **本地优先**：所有 AI 能力端侧化（参考第10类·小米澎湃AI引擎），拒绝云端依赖。
