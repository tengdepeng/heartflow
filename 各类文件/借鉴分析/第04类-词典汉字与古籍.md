# 第4类 · 词典 / 汉字 / 古籍（30个）

> **核心答案**：查字、释义、古籍阅读
> **影响模块**：模块三十六·殿堂辞典 / 模块三十四·知微阁
> **宪法兼容**：全部本地离线；命理/占卜类（批八字、六爻、紫微、称骨）仅借鉴 UI 交互模式，不引入迷信推算内容；古籍数据本地化。

## 一、蓝图规格内 App（13个）

### 1. 现代汉语字典（汉字深度学习体系）
- **核心功能**：以「汉字即世界」为核心，将一部完整的汉语字典转化为多维度、多入口的汉字深度学习平台。支持拼音、部首、笔画数、手写识别四种查字方式。汉字详情包含基本信息、释义、笔顺动画、字源演变和相关词语。
- **借鉴点**：
  1. 拼音查字——同音字分组列表
  2. 部首查字——214 个部首网格面板
  3. 笔画数查字——双端滑块设定范围
  4. 手写识别查字——Canvas 手写面板 + 本地离线识别
  5. 笔顺动画——SVG 路径动画，逐笔描红
- **目标房间**：模块三十六·殿堂辞典 / 模块三十四·知微阁

### 2. 中华汉语字典（多维检索汉字字典）
- **核心功能**：以「汉语学习的终极参考工具」为核心，构建覆盖拼音、部首、笔画、五笔、仓颉等多维检索体系的汉字字典。每个汉字不仅展示基本释义，还包含笔顺动画、字形演变（甲骨文→金文→篆书→楷书）、康熙字典原文、说文解字注、汉语大字典引用等多层级知识体系。
- **借鉴点**：
  1. 多维汉字检索——拼音/部首/笔画/手写/语音/拍照
  2. 单字详情页——基本释义 + 笔顺 + 字源演变 + 经典文献引用
  3. 部首树形检索——214 个部首树形结构
  4. 笔顺动画——Canvas 逐笔绘制，调速与暂停
  5. 生字收藏与复习——列表/网格 + 多条件排序
- **目标房间**：模块三十六·殿堂辞典 / 模块三十四·知微阁

### 3. 搜古籍（古籍全文搜索）
- **核心功能**：以「让古籍触手可及」为使命，构建古籍全文检索引擎，并围绕经、史、子、集四部组织语料库。阅读界面采用「原文-注释-翻译」三层架构。支持书签、批注、阅读进度和分类书单。
- **借鉴点**：
  1. 古籍全文检索引擎——FTS5 + 通假字映射 + 异体字对照
  2. 原文-注释-翻译三层阅读架构——竖排/横排 + 多密度注释
  3. 书签收藏与段落标记——多维度筛选排序
  4. 个人批注与笔记——浮动卡片附着
  5. 分类书单与主题阅读——自定义书单 + 拖拽排序
- **目标房间**：模块三十四·知微阁 / 模块十·经略阁

### 4. 识典古籍（古籍数字化阅读与注疏分层）

## 三、落地要点小结（模块三十六·殿堂辞典 / 模块三十四·知微阁）

1. **多维查字**：吸收现代汉语字典/中华汉语字典——拼音/部首/笔画/手写/语音/拍照六种查字入口。
2. **汉字详情五层**：基本信息 → 释义（基本义/引申义/古义）→ 笔顺动画 → 字源演变（甲骨→金文→篆→隶→楷）→ 相关词语/同部首字族。
3. **古籍阅读**：吸收识典古籍/搜古籍——竖排排版、影印对照、注疏分层、句读切换、原文-注释-翻译三层架构。
4. **内容数据源**：新华字典/康熙字典/说文解字/汉语大词典/成语词典/古汉语常用字字典/诗词大全/四库全书/国学大师/汉典/字源/甲骨文/金文/篆刻/书法字典 作为殿堂辞典与知微阁的本地数据源。
5. **中医知识**：吸收中医通/人纪针灸/中医经络穴位典籍/快背中医——经络→穴位→定位→主治→配伍→禁忌层级 + 卡片化记忆。
6. **命理类仅 UI**：批八字/六爻/紫微/称骨仅借鉴结构化输入与展示 UI，不引入迷信推算。
7. **拒绝**：云端词典、联网查询依赖、广告、付费墙。
