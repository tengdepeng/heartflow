# 简记事（三合一轻量管理）

> **所属大类**：第2类 · 笔记 / 写作 / 知识沉淀
> **对应房间**：模块九·思绪书房 / 模块二十一·更漏
> **宪法兼容**：本地存储与密码锁；拒绝云同步，待办与日历本地化。

## 核心功能
将记事本、待办清单、日历备忘融合为统一轻量应用，支持 Markdown 内联编辑、实时渲染、待办复选框、日历统一视图和全应用密码锁。

## 抄作业借鉴点
1. 三合一融合架构 —— 思绪书房与更漏「日课桥接」
2. Markdown 内联编辑 + 实时渲染 —— 思绪书房「双栏实时预览」
3. 待办复选框 —— `- [ ]` 渲染为可交互复选框
4. 子任务层级结构 —— 更漏「任务树」
5. 日历统一视图 —— 更漏「日课历」月视图

## 落地要点（对应房间）
- **模块九·思绪书房**：双栏实时预览、交互式待办复选框。
- **模块二十一·更漏**：任务树、日课历月视图、日课桥接。
