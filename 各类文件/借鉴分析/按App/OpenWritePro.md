# OpenWrite Pro（专业 Markdown 写作工作台与发布管理）

> **所属大类**：第14类 · 输出 / 导出 / 文件管理
> **对应房间**：模块九·思绪书房 / 模块一·输出管理
> **宪法兼容**：本地导出、多平台适配格式本地生成；拒绝外部分享链路（违第1条本地私有）。

## 核心功能
以「Markdown 作为写作的通用语言」为核心，构建从内容创作到多平台分发的写作工作台。左侧为 Markdown 源码编辑器，右侧为实时渲染预览面板。文章支持草稿、待发布、已发布等生命周期管理。

## 抄作业借鉴点
1. Markdown 编辑器 + 实时预览 —— 双栏布局，语法高亮
2. 文章管理 —— 状态分栏展示，无限编辑
3. 多平台发布工作流 —— 本地生成各平台适配格式
4. 图片资源管理 —— 网格缩略图，拖拽添加
5. 文章模板系统 —— 预设模板 + 基于已有文章保存模板

## 落地要点（对应房间）
- **模块九·思绪书房**：双栏编辑器（Markdown 源码 + 实时预览）、文章生命周期管理、图片资源管理、文章模板系统。
- **模块一·输出管理**：多平台适配格式本地生成。
