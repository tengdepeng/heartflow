# 说文解字（殿堂辞典数据源）

> **所属大类**：第4类 · 词典 / 汉字 / 古籍（补充参考 · 殿堂辞典内容数据源）
> **对应房间**：模块三十六·殿堂辞典 / 模块三十四·知微阁
> **宪法兼容**：字源 / 造字法数据源，本地化收录。

## 核心功能
东汉许慎著，中国第一部系统分析汉字字形、考究字源的字典，以六书理论解释汉字构造。

## 抄作业借鉴点
1. 殿堂辞典「字源 / 造字法」数据源
2. 汉字构造（象形 / 指事 / 会意 / 形声）可视化

## 落地要点（对应房间）
- **模块三十六·殿堂辞典**：字源 / 造字法数据源。
- **模块三十四·知微阁**：汉字构造（象形 / 指事 / 会意 / 形声）可视化。
