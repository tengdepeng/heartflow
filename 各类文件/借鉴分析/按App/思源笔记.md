# 思源笔记（本地优先知识管理）

> **所属大类**：第2类 · 笔记 / 写作 / 知识沉淀
> **对应房间**：模块九·思绪书房 / 模块十·经略阁 / 模块三十三·书签与入口架
> **宪法兼容**：数据以本地文件 / JSON 存储（第1条本地私有）；拒绝云同步与协作。

## 核心功能
以本地优先、块级粒度、双向链接为核心，将数据以本地文件系统存储，通过 wiki 链接建立正向引用，并自动维护反向链接图谱。

## 抄作业借鉴点
1. 本地优先文件存储 —— 所有知识数据以本地 JSON / 文件系统存储
2. 块级内容模型 —— 每条知识条目作为独立可寻址内容块
3. 双向链接 —— `[[条目名]]` 语法
4. 块引用嵌入 —— 书签条目引用殿堂辞典定义块
5. 快照版本控制 —— 数据资产层定期自动创建数据快照

## 落地要点（对应房间）
- **模块九·思绪书房**：本地 JSON 存储、块级内容模型、双向链接与反链图谱。
- **模块十·经略阁**：知识条目结构化组织与引用关系。
- **模块三十三·书签与入口架**：块引用嵌入——书签条目引用辞典定义块。
