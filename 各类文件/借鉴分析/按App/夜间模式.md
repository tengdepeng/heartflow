# 夜间模式（超低亮度 + 蓝光过滤）

> **所属大类**：第10类 · 安全 / 护眼 / 音乐 / 白噪音
> **对应房间**：模块六·守护室 / 感知层
> **宪法兼容**：护眼能力本地计算；定时启停本地；拒绝云端依赖。

## 核心功能
以「超低亮度 + 蓝光过滤」为核心，提供比系统最低亮度更暗的屏幕亮度和色温调节。多重护眼策略包括亮度遮罩、蓝光过滤、灰度模式，用户可独立调节每种策略的强度，也可选择预设组合。

## 抄作业借鉴点
1. 多重护眼叠加 —— 亮度遮罩 / 蓝光过滤 / 灰度模式
2. 超低亮度模式 —— 半透明黑色遮罩，0% - 80% 可调
3. 灰度模式 —— 降低视觉刺激，可叠加蓝光过滤
4. 定时启停 —— 基于日出日落或自定义时间
5. 快捷开关 —— 通知栏磁贴，一键切换

## 落地要点（对应房间）
- **模块六·守护室**：多重护眼叠加（亮度遮罩 / 蓝光过滤 / 灰度）、超低亮度、定时启停、快捷开关。
- **感知层**：屏幕亮度与色温本地调节能力。
