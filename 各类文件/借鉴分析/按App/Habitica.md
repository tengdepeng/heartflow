# Habitica（游戏化习惯 RPG）

> **所属大类**：第9类 · 效率 / 习惯 / 任务（补充参考）
> **对应房间**：模块十六·自律工坊 / 模块三十七·成长庭院
> **宪法兼容**：习惯 RPG 化适度保留（成长维度）；拒绝社交公会与排行榜、失败掉血惩罚。

## 核心功能
将习惯养成 RPG 化，完成任务获得经验 / 金币，角色升级，失败掉血（游戏化部分借鉴，社交 / 公会拒绝）。

3. 拒绝社交公会与排行榜

- **模块十六·自律工坊**：成长维度（习惯 RPG 化）、任务 / 习惯 / 每日待办分类。
- **模块三十七·成长庭院**：角色升级与成长映射（拒绝失败惩罚、公会与排行）。
