# 小米澎湃AI引擎（端侧 AI 推理引擎与模型调度）

> **所属大类**：第10类 · 安全 / 护眼 / 音乐 / 白噪音
> **对应房间**：模块七·镜我 / 感知层
> **宪法兼容**：端侧推理本地化、不联网；拒绝云端依赖与数据收集。

## 核心功能
是小米 HyperOS 的端侧 AI 推理框架，核心功能是在手机本地运行 AI 模型，实现图像识别、语音转文字、自然语言理解、智能推荐等 AI 能力，无需联网。

## 抄作业借鉴点
1. 端侧 AI 推理引擎 —— 镜我「本地推理引擎」
2. CPU / GPU / NPU 自动调度 —— 感知层「算力调度」
3. 模型动态加载与卸载 —— 镜我「模型管理」
4. 标准化 AI 能力 API —— 感知层「AI 能力接口」
5. 端侧优先 + 云端增强 —— 镜我「混合推理」

## 落地要点（对应房间）
- **模块七·镜我**：本地推理引擎、模型管理（动态加载 / 卸载）、混合推理（端侧优先）。
- **感知层**：算力调度、AI 能力接口。
