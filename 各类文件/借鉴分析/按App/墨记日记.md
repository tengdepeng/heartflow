# 墨记日记（水墨风格日记）

> **所属大类**：第6类 · 日记 / 情绪 / 心锚
> **对应房间**：模块五·逐日心锚 / 模块四·情绪花房
> **宪法兼容**：心情、天气、时辰、节气、位置等元数据本地自动采集；拒绝社交分享。

## 核心功能
以中国传统水墨画美学融入日记写作，通过极简水墨视觉语言营造书写氛围，并自动关联心情、天气、时辰、节气、位置和自定义标签。

## 抄作业借鉴点
1. 水墨极简 UI 语言 —— 情绪花房「水墨晕染」
2. 心情标签体系 —— 逐日心锚「心绪七色」
3. 日记元数据自动采集 —— 逐日心锚自动抓取天气 / 时辰 / 节气
4. 图文混排编辑器 —— 思绪书房富文本编辑器
5. 情绪花房浇水交互 —— 心情与成长反馈

## 落地要点（对应房间）
- **模块五·逐日心锚**：心绪七色心情标签、自动采集天气 / 时辰 / 节气元数据。
- **模块四·情绪花房**：水墨晕染 UI、浇水交互（心情与成长反馈）。
