# Duolingo（多邻国，游戏化学习引擎）

> **所属大类**：第3类 · 知识图谱 / 学习工具
> **对应房间**：模块三十四·知微阁 / 模块十六·自律工坊
> **宪法兼容**：技能树 / 皇冠等级 → 改为「探索星图 + 深度标尺」的自我激励；拒绝 XP / 排行 / 积分 / 连续签到压力；固定引导可关闭或可替换。

## 核心功能
将学习变成游戏，构建多层激励引擎，以经验值（XP）、皇冠等级、连胜天数、宝石货币和成就徽章驱动学习。学习路径按知识节点组织，每个节点包含多个探索深度等级，并完成具体课节任务。

## 抄作业借鉴点
1. 技能树关卡系统 —— 知微阁「探索星图」
2. 皇冠等级制 —— 知微阁「探索深度标尺」（每个节点 5 级掌握度）
3. 微学习单元 —— 知微阁「微探索」
4. 多种回顾模式交替 —— 联想 / 闪卡 / 填空 / 配对 / 复述 / 应用
5. 沉浸式故事 / 场景内容 —— 知微阁「知识场景」

## 落地要点（对应房间）
- **模块三十四·知微阁**：探索星图（技能树）、探索深度标尺（皇冠等级，每节点 5 级掌握度）、微探索、多种回顾模式交替、知识场景。
- **模块十六·自律工坊**：学习路径与进度追踪（克制游戏化，拒绝排行压力）。
