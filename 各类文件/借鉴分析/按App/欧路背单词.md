# 欧路背单词（词典 + 背单词一体化）

> **所属大类**：第3类 · 知识图谱 / 学习工具
> **对应房间**：模块三十四·知微阁 / 模块十·经略阁
> **宪法兼容**：词典离线、间隔重复本地化；拒绝云端依赖。

## 核心功能
以「词典 + 背单词一体化」为核心，将权威词典与间隔重复记忆系统融合。阅读中遇到生词时，长按查词可显示词典释义，并将该词加入生词本与复习计划。系统支持多本权威词典和听力训练。

## 抄作业借鉴点
1. 查词即学习 —— 阅读中查词 → 加入复习计划
2. 多词典切换 —— 自由切换，对比释义风格
3. 间隔重复复习引擎 —— 遗忘曲线 + 原词 / 释义 / 例句 / 发音
4. 生词本管理 —— 分组 / 标签 / 排序 / 筛选 / 搜索
5. 听力训练 —— 标准发音 / 调速 / 跟读 / 听写

## 落地要点（对应房间）
- **模块三十四·知微阁**：查词即学习、多词典切换、间隔重复复习引擎、生词本管理、听力训练。
- **模块十·经略阁**：与殿堂辞典词条联动检索。
