# Journey（跨平台日记）

> **所属大类**：第6类 · 日记 / 情绪 / 心锚
> **对应房间**：模块五·逐日心锚 / 模块四·情绪花房
> **宪法兼容**：Markdown、情绪标签、端到端加密本地化；拒绝云端同步与社交分享。

## 核心功能
跨平台日记应用，支持 Markdown 编辑、心情标签、日历视图、照片日记与端到端加密。

## 抄作业借鉴点
1. 心情标签 —— 逐日心锚「心绪标记」
2. 日历视图 —— 逐日心锚「心锚历」
3. 端到端加密 —— 本地加密存储
4. Markdown 编辑 —— 日记富文本

## 落地要点（对应房间）
- **模块五·逐日心锚**：心绪标记、心锚历（日历视图）、本地加密存储、日记富文本（Markdown）。
- **模块四·情绪花房**：情绪标签与日历回溯。
