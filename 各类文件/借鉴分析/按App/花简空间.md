# 花简空间（极简美学日记）

> **所属大类**：第6类 · 日记 / 情绪 / 心锚
> **对应房间**：模块四·情绪花房 / 模块五·逐日心锚
> **宪法兼容**：无压力记录本地化；拒绝社交分享。

## 核心功能
以「极简美学日记」为核心，通过极简界面和优雅交互，让写日记成为享受而非负担。日记没有字数要求、格式限制和必填字段，打开即写，并可自动保存。日记列表以时间轴形式展示，每篇显示日期和首行预览。

## 抄作业借鉴点
1. 无压力日记 —— 无字数 / 格式 / 必填要求
2. 时间轴日记列表 —— 日期 + 首行预览
3. 心情标记 —— emoji 或颜色标记
4. 主题 / 字体自定义 —— 背景色 / 字体 / 间距
5. 日记搜索 —— 全文搜索 + 关键词 / 日期 / 心情筛选

## 落地要点（对应房间）
- **模块四·情绪花房**：无压力日记（打开即写、自动保存）、时间轴列表、心情标记。
- **模块五·逐日心锚**：主题 / 字体自定义、日记全文搜索。
