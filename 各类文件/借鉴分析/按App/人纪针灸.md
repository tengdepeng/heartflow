# 人纪针灸（针灸学习与经络穴位结构化）

> **所属大类**：第4类 · 词典 / 汉字 / 古籍 + 第8类 · 健康 / 身体 / 运动
> **对应房间**：模块十五·身体温室 / 模块三十四·知微阁
> **宪法兼容**：经络穴位以「象」呈现、不做诊断建议；黄色警告标识仅作提示；数据本地化。

## 核心功能
以「倪海厦人纪针灸教程」为核心，提供系统化的针灸学习与经络穴位知识体系。将 14 条正经和奇经八脉的穴位知识按「经络 → 穴位 → 定位 → 主治 → 配伍 → 禁忌」的层级结构组织。

## 抄作业借鉴点
1. 经络穴位结构化学习 —— 层级结构组织
2. 穴位详情展示 —— 定位 / 解剖 / 深度 / 主治 / 配伍 / 禁忌
3. 经络循行路线动画 —— 高亮线条 + 沿途穴位
4. 穴位定位图 —— 2D / 3D 视图切换
5. 针灸禁忌与注意事项 —— 红色警告标识

## 落地要点（对应房间）
- **模块十五·身体温室**：经络穴位结构化身体观（以「象」呈现），穴位定位图（2D / 3D 切换）。
- **模块三十四·知微阁**：经络循行动画、穴位详情层级（定位 / 主治 / 配伍 / 禁忌），禁忌以红色警告标识仅作提示。
