# TickTick（滴答清单国际版）

> **所属大类**：第9类 · 效率 / 习惯 / 任务（补充参考）
> **对应房间**：模块二十一·更漏 / 模块十六·自律工坊
> **宪法兼容**：任务 + 日历 + 番茄本地整合；拒绝排行与签到压力。

## 核心功能
滴答清单的国际版，功能类似，整合任务、日历、番茄钟、习惯。

## 抄作业借鉴点
1. 任务 + 日历 + 番茄整合 —— 更漏「日课桥接」
2. 习惯打卡 —— 自律工坊
3. 多视图 —— 列表 / 看板 / 日历

## 落地要点（对应房间）
- **模块二十一·更漏**：日课桥接（任务 + 日历 + 番茄整合）、多视图。
- **模块十六·自律工坊**：习惯打卡。
