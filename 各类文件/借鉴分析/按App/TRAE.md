# TRAE（AI 编程助手与项目级代码理解）

> **所属大类**：第1类 · AI对话 / 幕僚 / 镜我
> **对应房间**：模块七·镜我 / 模块一·输出管理
> **宪法兼容**：推理过程本地化呈现；拒绝云端账号、评价性回复；仅保留「陈列而非叙事」。

## 核心功能
以「AI 编程助手」为核心，专注于编程辅助场景。TRAE 不仅能回答单个代码问题，还能理解整个项目的代码结构和依赖关系，提供跨文件重构建议、Bug 定位和架构分析。

## 抄作业借鉴点
1. 项目级代码理解 —— 理解项目结构和依赖关系
2. 智能代码补全 —— 基于上下文感知
3. Bug 定位与修复建议 —— 定位 Bug 并提供修复方案
4. 对话式编程 —— 自然语言描述需求，AI 生成代码
5. 代码审查 —— 检查质量 / 安全漏洞 / 性能问题

## 落地要点（对应房间）
- **模块七·镜我**：镜我的「项目理解」能力——理解用户本地项目结构与依赖，跨文件推理，Bug 定位建议。
- **模块一·输出管理**：代码 / 项目数据的结构化导出与装订。
