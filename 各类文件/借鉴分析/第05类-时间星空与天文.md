# 第5类 · 时间 / 星空 / 天文（7个）

> **核心答案**：时间怎么变得看得见
> **影响模块**：模块三·时间长廊 / 模块三十·地图室
> **宪法兼容**：天文数据本地计算；AR 识别本地化；拒绝推送轰炸与云端依赖。

---

## 一、蓝图规格内 App（7个）

### 1. 生辰（生命计时与时间视觉化）
- **核心功能**：以「向死而生」为核心，通过「生之时」实时展示已流逝时间，与「死之时」的剩余时间倒计时并置，形成时间感知。
- **借鉴点**：
  1. 生之时六级粒度实时计时——时间长廊「生命刻度」
  2. 死之时倒计时与生命进度条——时间长廊「生命进度」
  3. 心愿单倒计时与紧急程度——逐日心锚「心愿锚」
  4. 里程碑标记与生命时间轴——逐日心锚「里程碑锚」
  5. 极简数字美学——整体 UI 风格参考
- **目标房间**：模块三·时间长廊 / 模块五·逐日心锚

### 2. 时光提醒（倒计时管理与时间可视化）
- **核心功能**：将抽象时间流逝转化为倒计时视觉呈现，通过倒计时卡片、正计时、分类管理、周期性提醒和纪念日管理提醒用户珍惜时间。
- **借鉴点**：
  1. 倒计时卡片——更漏「时间哨塔」
  2. 正计时——更漏「耕耘计时」
  3. 分类管理与标签筛选——更漏「工作分类」
  4. 周期性重复提醒——更漏「周期节律」
  5. 纪念日管理与双历法支持——逐日心锚「纪念日锚点」
- **目标房间**：模块二十一·更漏 / 模块五·逐日心锚

### 3. 观星（天文观测与星图）
- **核心功能**：以「天文观测与星图」为核心，提供实时星图、星座识别、天文事件提醒等功能。星图可视化和时间轴的思想可借鉴到时间长廊。
- **借鉴点**：
  1. 实时星图——时间长廊「时间星图」
  2. 天文事件提醒——逐日心锚「天文提醒」
  3. 星座识别——知微阁「AR 识别」
  4. 时间回溯——时间长廊「时间回溯」
- **目标房间**：模块三十四·知微阁 / 模块三·时间长廊 / 模块五·逐日心锚

### 4. AR星座（AR星空识别）
- **核心功能**：核心理念是将手机摄像头对准天空即可实时识别星座、恒星和行星，将虚拟的星座连线叠加在真实星空画面上。
- **借鉴点**：
  1. AR 实时星空识别——时间长廊「星空视角」
  2. GPS 定位 + 陀螺仪朝向感知——感知层「天文姿态」
  3. 天体数据库与星等分级——知微阁「天文知识库」
  4. 星座连线与神话故事——知微阁「星座故事」
  5. 夜间模式与红光护眼——守护室「天文护眼」
  6. 时间穿越与天体追踪——时间长廊「时间旅行」
- **目标房间**：模块三·时间长廊 / 模块三十四·知微阁 / 模块六·守护室 / 感知层

### 5. 星空漫步（智能天文观测规划）
- **核心功能**：专业级天文观测辅助工具，核心功能是帮助用户规划天文观测活动——根据用户所在地理位置、天气状况、光污染等级和月相，智能推荐当天最适合观测的天体目标，并生成详细的观测计划。
- **借鉴点**：
  1. 观测条件综合评分——时间长廊「时间质量评估」
  2. 深空天体数据库——知微阁「灵感天体库」
  3. 观测计划生成器——自律工坊「深度计划」
  4. 月相与光污染日历——时间长廊「节律日历」
  5. 高度角轨迹预测——时间长廊「目标轨迹」
- **目标房间**：模块三·时间长廊 / 模块三十四·知微阁 / 模块十六·自律工坊

### 6. 天文大师（天文观测条件预测与星历计算）
- **核心功能**：面向天文爱好者的专业观测辅助工具，核心功能包括天文星历计算、观测条件预报、天体事件提醒等。内置精确的星历计算引擎，可以预测数年内任意时间点的日月出没、行星位置、月相、日月食、流星雨等天文事件。
- **借鉴点**：
  1. 天文星历计算引擎——时间长廊「时间星历」
  2. 观测窗口时间预测——自律工坊「最佳行动窗口」
  3. 天体事件智能提醒——时间长廊「时间事件提醒」
  4. 月相/日月食精确时刻——时间长廊「月相计时」
  5. 流星雨/彗星预报——季节仪式「天文事件日历」
- **目标房间**：模块三·时间长廊 / 模块十六·自律工坊 / 模块十三·岁时阁

### 7. 天文通（天文气象与观星条件预报）
- **核心功能**：面向天文爱好者的观星条件预报应用，核心功能是综合气象数据和天文数据，生成「观星指数」——一个 0-100 的综合评分，帮助用户快速判断某地某时的观星条件。
- **借鉴点**：
  1. 观星指数综合评分——守护室「身心状态指数」
  2. 72 小时条件趋势图——时间长廊「72 小时趋势」
  3. 多维数据彩色图表——身体温室「多维数据面板」
  4. 光污染等级地图——守护室「环境质量地图」
  5. 暗夜保护区推荐——守护室「静修空间」
- **目标房间**：模块六·守护室 / 模块三·时间长廊 / 模块十五·身体温室

## 二、落地要点小结（模块三·时间长廊 / 模块三十·地图室）

1. **时间视觉化**：吸收生辰「生之时/死之时」——生命刻度、生命进度条、六级粒度实时计时。
2. **倒计时体系**：吸收时光提醒——倒计时卡片、正计时、纪念日、周期节律。
3. **星空时间轴**：吸收观星/AR星座——实时星图、时间回溯、AR 叠加、时间旅行。
4. **观测规划**：吸收星空漫步/天文大师/天文通——综合评分、观测窗口预测、星历计算、72 小时趋势。
5. **拒绝**：推送轰炸、云端天文数据依赖、社交排行。
