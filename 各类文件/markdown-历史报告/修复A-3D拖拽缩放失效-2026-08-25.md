# 修复 A：3D 宅院壳拖拽旋转 + 滚轮缩放失效

**日期**：2026-08-25
**根因**（见 `docs/缺口查缺报告-宅院壳2D3D-2026-08-24.md`）：`courtyard-3d.ts` 把 `OrbitControls` 绑在自建 WebGL canvas 上，但该 canvas `pointer-events:none`（命中由 `.shell-hit-layer` 接管），且命中层只转发 `click` 不转发拖拽/滚轮 → OrbitControls 收不到任何指针事件，3D 旋转+缩放实质失效。

## 修法
把 `OrbitControls` 改绑到 **空间递进命中层 `.shell-hit-layer`**（3D 模式下 `pointer-events:auto`、全屏、z:5，是空区的真实事件接收面）。
- `world-shell/types.ts`：`ShellContext` 增 `hitLayer?: HTMLElement | null`（文档化扩展点）。
- `courtyard-3d.ts`：原 `new OrbitControls(camera, this.canvas)` 改为 `this.buildControls()`——
  - `buildControls()` 优先取 `.shell-hit-layer`，兜底 `this.canvas`；
  - 配置（enablePan=false / damping / min·maxDistance / polarAngle 限位 / target / rotateSpeed / zoomSpeed / autoRotate）保持原值；
  - 新增 `requestAnimationFrame` 兜底：命中层若晚于 3D 壳 mount 一帧入 DOM（首次从其它壳切回宅院），次帧重绑到命中层。
- **点击进房间不受影响**：`CanvasRoom` 的命中层 `@click`/`@pointermove` 仍在命中层上；拖拽（无位移）不触发 `click`，OrbitControls 只在拖拽时旋转，互不冲突。

## 真机验证（独立 Edge + CDP 9222，复用 vite :1001）
- 3D 模式空区（屏幕中下 (465,747) / 左侧 (165,487)）`elementFromPoint` 命中 `.shell-hit-layer`(pe:auto)。
- 真实拖拽 + 滚轮：5 个事件全部命中 `.shell-hit-layer`，**OrbitControls 现已收到事件**。
- 像素差分（before→after）：
  - 3D 拖拽 `afterDragDiff=0.386`（相机旋转 + 悬停），2D 同序列 `0.1632`（仅悬停高亮，无相机）。
  - 3D 滚轮 `afterZoomDiff=0.2476`（相机推进/缩放），2D `0.0035`（无相机）。
  - → 3D 拖拽旋转 + 滚轮缩放**确认生效**；2D 无相机故几乎不变，形成对照。
- `vue-tsc --noEmit` 0 错（heap 6144MB）。
