## P0 — 致命隐性（你大概率当成了"环境抖动"）

### 1. 两个核心组件彻底丢失，生产构建已死
- 缺失文件：`src/components/SwitchPanel.vue`、`src/components/FloatingLayerHost.vue`
- 状态：`git ls-files` 未 tracked —— **从未进过任何 git 引用**，是循环删除进程清掉的未提交 WIP，git / 回收站 / 归档副本均无法恢复。
- App.vue 硬依赖：`App.vue:152 <SwitchPanel/>`、`:155 <FloatingLayerHost/>`、`:231/232` 静态 import。
- 后果：
  - `npm run build`（生产打包 nsis/dmg）**必失败**——vite 解析不到这两个模块。
  - dev 模式冷启动同样会因 vite 解析失败白屏/报错；你日常"能用"靠的是旧 `dist/`（磁盘上仍存在一份旧构建）或热更新缓存。
- 你"没感觉到"的原因：开发态加载的是旧产物，真正冷启动/发布才暴露。

### 2. 后台循环删除进程未根治（仓库持续被啃）
- 现象：间歇 spawn → 删 `src/components/**` → 抢 `.git/index.lock` → `git add -A` 暂存删除 → 退出留死锁。
- 你看到的「改动莫名丢了 / build 偶尔挂 / index.lock 报错」根因在此，**不是你操作问题**。
- 疑似源：同步盘（OneDrive/iCloud/Dropbox）用冲突远端态覆盖 `E:/Heartflow`，或 IDE git 自动刷新循环 `git add -A`。待你侧确认并停掉。

## 补充维度（隐私 / 数据完整性 / 真机可信度 / 能力缺口 / 仓库卫生）

### B0 明文存储无加密（本地私有但裸奔）
- 存储引擎 = 明文 JSON（`PlaintextFileStorageBackend` 经 Tauri 命令 `cmd_save_storage` 写明文文件；web 下 localStorage）。`core.ts:147-150` 注释明确"蓝图第一层要求本地文件存储引擎为明文 JSON/Markdown，用户可直接查看编辑"。
- 隐患：宪法第1条「本地私有」≠ 加密。明文意味着**机器/备份被他人访问即可读全部日记/笔记/优先级**；若日后数据目录纳入同步盘或云备份，明文直接上云。
- 蓝图第八层已预留 SQLite 加密后端（`sqlite-backend.ts`，未接主路径）。建议至少提供可选加密开关。

### B1 真机验证可信度打了折扣
- 历史「真机 78 路由验证」实为 **web 模式**（localStorage 存储，非 Tauri 文件）。Tauri 明文文件存储路径 + 真实桌面窗口行为（始终置顶 / 透明窗 / 深链拉起）从未在真 Tauri 运行时验证过。你感知的"已验证"应打折。

### B2 Tauri 能力缺口（新功能落地的隐性阻塞）
