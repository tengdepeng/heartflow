## 三、本轮新发现缺口与补齐内容

### 缺口 1：APK 2.212 剪贴板管理（快贴 → 输出管理）——原完全缺失
蓝图要求：剪贴板历史可检索、固定收藏、素材入库（常驻片段 Snippet）、按条数/天数自动清理、复用统计。
补齐文件：
- `src/modules/output/clipboard.ts`（新增）：ClipItem/Snippet/ClipCleanPolicy 数据模型（对齐蓝图 JSON）；历史去重（同文刷新时间而非重复入库）、固定置顶、全文搜索、复制回剪贴板、升级片段、复用计数高频优先、清理策略（maxItems 默认 500 / maxDays 默认 30，固定豁免，可配置连固定清）。
- `src/components/ClipboardPanel.vue`（新增）：历史 / 片段库 / 清理策略三页签；「读取系统剪贴板」（navigator.clipboard，权限失败优雅降级提示）与「监听应用内复制」（document copy 事件）双捕获通道。
- `src/views/Output.vue`（修改）：嵌入 ClipboardPanel。
- `src/modules/output/index.ts`（修改）：导出剪贴板 API。
- `src/modules/output/__tests__/clipboard.test.ts`（新增）：11 用例（落盘/去重/固定排序/搜索/过期清理/上限清理/策略钳制/片段升级/复用计数/更新删除）。

### 缺口 2：APK 2.209 听书 TTS（微信读书 → 阅览殿）——原完全缺失
蓝图要求：本地 TTS 朗读当前书籍、倍速与语速调节、全程本地无云端。
补齐文件：
- `src/modules/reading/tts.ts`（新增）：基于 Web Speech API 的本地朗读引擎；长文按句切分排队（句末标点 → 逗号/空格 → 180 字硬切三级切分，规避 utterance 长度限制）；0.5x~2.0x 倍速（播放中即时生效）；暂停/续播/停止；单句失败跳过不中断；环境不支持时 supported=false 供 UI 降级。
- `src/views/ReadingHall.vue`（修改）：阅读工具栏接入「▶ 听书 / ⏸ 暂停 / ▶ 续播 / ⏹ 停止 + 倍速选择 + 句块进度」，清除文本与组件卸载时自动停止。
- `src/modules/reading/index.ts`（修改）：导出 TTS API。
- `src/modules/reading/__tests__/tts.test.ts`（新增）：5 用例（句块切分/超长句二次切分/排队续读状态机/空文本拒绝/倍速钳制）。

## 四、本轮修正的既有问题

### 循环依赖：engine/automation.ts ↔ modules/operation-mode/gate.ts
- 成因：三级操作模式落地时 gate.ts `import type { SavedFlow } from '../../engine/automation'`，而 automation.ts 运行时 import gate，madge 判环。
- 修复：gate.ts 改为本地结构化类型 `GateFlowRef`（与 SavedFlow 结构对齐，附注释说明）；消费侧 PendingActionsTray.vue 在执行点 `as SavedFlow` 断言。
- 结果：`madge --circular` 由 1 环 → ✔ 零环。
