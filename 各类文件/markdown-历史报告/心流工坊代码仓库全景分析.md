## 1. 项目概览

### 1.1 定位

心流工坊是一个**完全私有、完全本地的私人数字世界**——不是效率工具，不是笔记软件，不是人生管理系统。核心哲学：**沉淀 → 映照 → 编排 → 安放**。

### 1.2 技术栈

| 层级 | 技术选型 | 备注 |
|------|----------|------|
| 跨端容器 | **Tauri 2.x** | 桌面为主，可扩展至移动 |
| 前端框架 | **Vue 3.5 + TypeScript 5.6** | Composition API + `<script setup>` |
| 状态管理 | **Pinia 3.x** | Stores 分散在 `stores/` |
| 路由 | **Vue Router 4.x** | Hash 模式 |
| 构建工具 | **Vite 6.x** | 开发服务器 :1001 |
| 测试 | **Vitest 4.x + happy-dom** | 单元测试 |
| 存储 | **Tauri FS / localStorage** | 本地明文 JSON |

### 1.3 Git 提交历史

仅 3 次提交，项目处于**极早期阶段**：


## 4. 核心引擎分析

### 4.1 存储引擎 (`engine/storage/`)

**当前架构**：Adapter 模式

```
core.ts (loadSchema / saveSchema)
  └── 选择后端：Tauri FS (invoke) / localStorage / test mock
       └── 加载完整 JSON → 修改 → 写回完整 JSON
```

**各存储文件**：每个数据域一个文件，调用 `loadSchema()` + `saveSchema()` 读写全部数据。

**问题**：
- 每次写操作都序列化/反序列化**整个 schema**，大数据量（如 10 万条笔记）时性能灾难
- 无增量写、无
