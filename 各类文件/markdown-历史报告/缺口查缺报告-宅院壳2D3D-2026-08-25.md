## 审计方法与关键证据

真机用 CDP 注入真实鼠标事件，像素差分取证（阈值 15/255）：

**3D（宅院 3D）**
- `hasCamera = true`（`window.__courtyard3dControls` 暴露 OrbitControls，dev-only 探针，生产零足迹）。
- 空区拖拽 280px：场景差分 `dragRotatesSceneDiff = 0.17–0.49`（远大于 3D 自身呼吸基线 0.03–0.08）→ **拖拽旋转确认生效**。
- 缩放：滚轮推进范围受 `minDistance/maxDistance` 约束（B 落地）。

**2D（宅院 2D 静态背景）**
- `hasCamera = false`（2D 无 OrbitControls）。
- 基线动画差分 `0.0001`（几乎静止）。
- **纯悬停对照** `worldShellHoverDiff = 0`：移动鼠标不按键，画布零变化。
- 拖拽差分 `0.0772`：来自 `mousePressed`（点击进房间），**不是"拖拽看世界"**。
- 判定 `worldShellHasCameraDrag = false` → 2D 世界壳**无看世界相机、无拖拽方向/大小自定义**。这符合蓝图「屏风后那层世界是环境背景」的定位，不算缺口——是对「是否拖拽方向大小自定义」的直接答复：**仅 3D 可自定义**。

**面板一致性（修复前后对照）**
- 修复前：`courtyardMode=2d` 时 `.shell-3d-tweaks` `present:true`（标题「宅院 3D 漫游」）——2D 模式误露 3D 专属控件（语义错位，且滑块在 2D 下毫无作用）。
- 修复后（强制整页重载到 `#/decoration-workshop`，`dwMounted:true` 验证）：2D `present:false`、3D `present:true`。✅

**单窗口护栏（代码层核查）**
- `project/src-tauri/Cargo.toml`、`tauri.conf.json`、`src-tauri/src` 均无 `tauri-plugin-single-instance`。
- `tauri.conf.json` 仅一个窗口定义，但双击 exe 仍可开多个独立窗口 → **缺口（C 待做）**。web 沙箱无法双开 Tauri exe，故为代码层结论。

**审美（像素采样，品牌三色：暖金 #d4a574 / 墨 / 宣纸留白）**
- 2D：ink 0.78–0.91、gold 0.001、harsh 0.0002 → 墨色剪影主导，无刺眼色。
- 3D：gold 0.08–0.14、ink 0.55、harsh≈0 → 暖金描金 + 墨色，无霓虹。
- 二者 `harsh < 0.02` 且品牌色占比 > 0.3 → **审美在线（ON_BRAND）**。
