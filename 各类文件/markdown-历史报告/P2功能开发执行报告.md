## 二、P2-1 身体三环（Body Three Rings）

### 2.1 设计意图
蓝图模块 15「身体温室」：状态导向三环（活动/休息/感受），长期趋势；**明确拒绝目标评分、穿戴依赖、健康建议**。

### 2.2 实现
新建 `src/modules/body/rings.ts`，导出 `useBodyRings()`：
- 三环快照 `RingSnapshot { level, label, todayValue, trend }`，档位 `RingTier = 0|1|2|3|4`（空白/微动/舒展/充盈/盈满）——**离散状态描述，非 0-100 分数**。
- 动作 `logActivity(minutes)` / `logRest(minutes)`（按分钟阈值升级档位）、`setFeeling(tier)`（主观感受，非数值）。
- 计算属性 `activityRing` / `restRing` / `feelingRing`，趋势 `trendFor()` 输出固定 7 长度近 7 天档位序列（长期趋势）。
- 存储键 `hf:body:rings`，遵循 `body` 模块单例范式（模块级 `ref` + KV 加载/落盘）。

### 2.3 关键决策
- **不复用 `useBodyGreenhouse().greenhouseState` 的 `bodyScore`/`plantHealth`（0-100 评分）**——该评分与"拒绝目标评分"冲突。三环独立成环，用离散档位表达"今天的状态"。
- 三环数据**独立于** `metrics`/`sleepRecords`，避免把活动/休息硬性绑定到具体指标记录（规避穿戴依赖语义）。

新增 `src/modules/body/__tests__/rings.test.ts`（6 项）：默认空白档、活动环阈值升级、休息环阈值升级、感受环设置、趋势 7 长度、持久化重载恢复。

## 三、P2-2 间隔重复（Spaced Repetition）

### 3.1 设计意图
蓝图模块 19「阅览殿」+ 模块 17「字镜阁」：艾宾浩斯间隔重复 + 三选一（认识/模糊/忘记）最小化决策；**拒绝连续打卡压力**。

### 3.2 实现
- **扩展既有引擎**（不重写）：`src/modules/note/knowledge-ring.ts` 新增 `ReviewGrade` 类型与 `recordReviewGrade(ring, grade)`，三档映射：
  - `know` → 等同原 `recordReview`（年轮增长）
  - `fuzzy` → 弱回顾，最高停在倒数第二档、下次间隔更短（非失败、也非完全掌握）
  - `forget` → 等同错过窗口的遗忘处理（裂缝 + 重置间隔）
  - **原二值 `recordReview` 完全保留不动**，笔记模块现有行为零影响。
- `src/modules/note/index.ts` 新增 `reviewRingGrade(noteId, grade)` 并导出（桥接写入 `knowledgeRings` KV）。
- 新建 `src/modules/reading/srs.ts`，导出 `useReadingSrs()`，复用知识年轮引擎：
  - `reviewQueue`（到期/逾期年轮，含 `daysUntil`/`forgotten`）
  - `review(noteId, grade)` → 委托 `note.reviewRingGrade`
  - `memoryCurve`（按年轮层数/掌握度的聚合分布曲线）
  - `stats`（总/待复习/已遗忘/重逢/均值，复用 `computeRingStats`）
- `src/modules/reading/index.ts` barrel 导出 `useReadingSrs` / `SRS_GRADE_LABELS` / 类型。

### 3.3 关键决策
- SRS 调度数据**留在笔记模块的 `RING_KV_KEY`**，绝不写入共享 `notes` 数组——规避 `study.Note` 与 `note.StickyNote` 同读 `storage.getNotes()` 的互相覆盖隐患。
- 复用而非重写：艾宾浩斯 `INTERVALS=[1,2,4,7,15,30,60,120]` 与年轮/遗忘/统计逻辑直接复用，仅叠加三档映射。

新增 `src/modules/reading/__tests__/srs.test.ts`（6 项）：队列过滤、know 推进并移出、forget 裂缝重置、fuzzy 弱掌握、记忆曲线分布、统计待复习。

## 四、P2-3 时光胶囊（Time Capsule）

### 4.1 设计意图
蓝图模块 29「梦境区」/ 模块 13「岁时阁年度胶囊」：写现在、未来**主动开启**（非提醒），兼容宪法第 52 条沉默默认。

### 4.2 实现
- **该特性原本已在 `views/ParallelWorld.vue` 中以视图局部逻辑实现**（键 `hf:time_capsules`、主动开启无提醒）。P2 将其**抽取为规范模块单例 composable**：
- 新建 `src/modules/parallel-world/time-capsule.ts`，导出 `useTimeCapsule()`：`Capsule` 接口 + `sortedCapsules`(computed) / `checkReady` / `tryOpenCapsule` / `addCapsule` / `removeCapsule` / `load` / `capForm`(reactive)。
- 新增可选 `scope: 'year' | 'free'` 字段，支持「年度时间胶囊」语义（默认 `free`）。
- 重构 `views/ParallelWorld.vue`：删除局部 `Capsule` 接口、`K_CAPS`、胶囊相关 `ref`/`computed`/函数/`load`/`save`，改为 `const { capsules, capForm, sortedCapsules, checkReady, tryOpenCapsule, addCapsule, removeCapsule, load: loadCapsules } = useTimeCapsule()`；`onMounted` 的 `loadCapsules()` 现指向组合式暴露的 `load`。
- `src/modules/parallel-world/index.ts` barrel 导出 `useTimeCapsule` / 类型。
- 改进点：`tryOpenCapsule` / `addCapsule` 通过重赋值 `capsules.value` 触发响应式更新（原视图局部实现存在嵌套属性变更不触发 `sortedCapsules` 重算的隐患，已修正）。

新增 `src/modules/parallel-world/__tests__/time-capsule.test.ts`（8 项）：默认空、封存自由胶囊+表单重置、空内容拦截、未到日期不可开、到日期可开、删除、排序（未开启在前）、持久化重载恢复。
