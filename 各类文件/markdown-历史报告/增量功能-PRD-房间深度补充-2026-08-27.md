## 1. 背景与问题

心流工坊按蓝图建设了多个"房间"（学习、保险库、工作日志、知识塔、输出、节气仪式、智慧阁等），每个房间已有主视图，但**单房间的信息密度与可操作性不足**——用户进入房间后只能看到表层聚合数据，缺少把数据"结构化、自动化、可沉淀"的深度面板。具体缺口：

| 房间 | 缺口 | 影响 |
|---|---|---|
| 学习（笔记） | 笔记无法结构化为思维导图 | 知识关联不可见，难做全局回顾 |
| 保险库 | 无空闲自动锁定策略 | 隐私敏感资产在离座时裸奔 |
| 工作日志 | 日志不可导出 | 复盘/沉淀受阻，数据困在本地 |
| 知识塔 | 缺 AI 管家洞察面板 | 知识健康度、关联不透明 |

## 2. 目标

- 为 4 类房间补"深度面板"，提升单房信息密度与可用性（structured / automated / exportable）。
- 全程遵守项目宪法两条硬约束：
  - **① 本地私有**：所有数据走 `engine/storage` 明文 JSON 本地文件，零网络调用。
  - **② 超级自定义**：面板内的用户偏好（如自动锁时长）本地保存，不由系统定死。

## 3. 范围

**In scope（已交付）**
- 3 个新面板：`MindMapPanel`（心智地图）、`VaultAutoLockPanel`（保险库自动锁）、`WorklogExportPanel`（工作日志导出）。
- `StewardPanel`（知识塔 AI 管家）扩展 + `knowledge-shared.css` 样式补全。
- 9 个房间视图接线：Study / Vault / WorkLog / KnowledgeTower / Output / SeasonalRituals / WisdomPavilion 挂载对应面板。
- 模块导出注册：`modules/index.ts`、`modules/note/index.ts`、`modules/vault/index.ts` 暴露面板背后的 composable 公共 API。
- 测试：3 新面板各附单测（共 21 passed）+ KnowledgeTower 视图测试。

**Out of scope（本次不做）**
- 新房间创建 / 房间层级重构。
- 任何云端同步、后端服务、网络请求。
- 3D 场景（世界壳 / 正厅）改造。
- 面板内嵌富交互编辑器（如思维导图拖拽编辑）——首版为"生成 + 概览 + 配置"，非全功能画布。

## 4. 用户故事与需求

- **US-1（学习）**：作为笔记用户，我希望把书架笔记一键生成思维导图并看到导图概览（导图数/节点数/连接数/均深），以便掌握知识结构。
- **US-2（保险库）**：作为隐私敏感用户，我希望设置"空闲 N 分钟后自动锁定"并可选时长，以便离座时资产不裸奔。
- **US-3（工作日志）**：作为记录者，我希望把日志导出为可带走的文件，以便复盘沉淀。
- **US-4（知识塔）**：作为知识管理者，我希望有 AI 管家给出知识节点数 / 关联数 / 活跃分类 / 健康评分，以便知道知识库状态。

**功能需求（FR）**
- FR-1 `MindMapPanel`：新建导图（标题/根节点）、从 N 条笔记生成导图、展示导图概览统计。
- FR-2 `VaultAutoLockPanel`：展示并修改自动锁设置（`settings` prop + `update` 事件），时长选项来自 `IDLE_OPTIONS`。
- FR-3 `WorklogExportPanel`：导出工作日志为本地文件。
- FR-4 `StewardPanel`：展示知识概览 + 健康评分环，可关闭。

**非功能需求（NFR）**
- NFR-1 零网络：所有读写经 `engine/storage` 明文 JSON，不触网。
- NFR-2 可测：每个面板有单测；全量 `vitest` 0 failed；`vue-tsc --noEmit` 0 error。
- NFR-3 薄层契约：面板组件仅做展示与事件转发，状态/存储由 `modules/*` 内 composable 持有（避免"接线孤儿/空壳"）。

## 6. 风险与对策

- **R-1 薄委托层被误判为空壳**：面板 `.vue` 很薄，易被当成"空壳"。对策：判缺失前先 `grep` 实现层——`MindMapPanel` 背后有 `modules/note/mind-map`（`useMindMap` 真实持有状态+存储），`VaultAutoLockPanel` 背后有 `modules/vault/auto-lock`（`useVaultAutoLock`），均真实消费。
- **R-2 偏好持久化跨重启丢失**：用户 touched 标记须落 config 字段。对策：自动锁设置经 `AUTO_LOCK_KEY` 写入 storage，重载后恢复。
- **R-3 面板遮挡路由视图**：知识塔 StewardPanel 用 `v-if` + 固定层 + `z-index` 收敛，遵循空间容器布局契约，不压住导航 chrome。
