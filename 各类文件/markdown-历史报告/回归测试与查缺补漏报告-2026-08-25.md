## 5. 真机多路由（Edge headless + CDP，受控）— 78 路由

每路由 fresh reload，抓未捕获异常 + 控制台错误 + 截图。明细见 `hf-route-results.json`。

### 5.1 未捕获异常（4 路由）
`/advisors/archive`、`/constitution`、`/room-manager`、`/output` —— 错误文本均为：
```
Error: Could not establish connection. Receiving end does not exist.
```
**根因**：web 模式（vite :1001）下这些路由调用 Tauri IPC / 桥（如 `openOverlayWindow`、`checkAutoStart`），浏览器环境无接收端 → 抛错。**桌面壳内不会发生**；但 web-preview 路径应加 `try/catch` 守卫，避免未捕获异常。

### 5.2 控制台渲染错误（24 路由）—— 系统性同一定罪根因
下列 5 处 `undefined` 在 24 个路由上反复出现，属 **world-shell 第三层配置未注入**：

| 位置 | 读取的 undefined 字段 | 含义 |
|---|---|---|
| `src/App.vue:288` | `activeShell` | 当前世界壳未注入 |
| `src/App.vue:147` | `value`（home-space） | panelVisible 派生链 undefined |
| `src/modules/canvas/CanvasRoom.vue:36`（setup） | `activeShell` | 画布房间壳未注入 |
| `src/modules/canvas/CanvasRoom.vue:526` | `layoutMode` | 布局模式未注入 |
| `src/modules/canvas/SurfaceStage.vue:11` | `surfaceState` | 表面态未注入 |
| `src/components/FloatingLayerHost.vue:12` | `floatingLayers` | 浮层列表未注入 |

→ world-shell 状态源（`activeShell` / `surfaceState` / `layoutMode` / `floatingLayers`）未接通到消费组件，壳层计算属性返回 `undefined`，Vue 渲染时抛 `TypeError`（被 Vue 捕获并记 console，**不整页崩**）。**结论：内容层（安全岛 / screen）仍可渲染，但壳层（世界壳 / 浮层 / 星盘）处于「挂了但没崩」的降级态**——这正是此前怀疑的第三层断裂的运行时实证。

## 6. 查缺补漏分类（系统性不完整重构级联）

按「符号被拆出 / 改名但消费方未跟上」归为四类：

**A 类 — 符号移除 / 改名，消费方未同步**
- `RoomDomain`：`App.vue:200` 仍 `import`，重构已移除。
- `WorldShellType`：`screenContract.ts:9` / `types.ts:9` 仍 `import`，重构已移除 / 迁移。
- `defaultNavVisible`：`nav-dedupe.test.ts` 引用，`RoomNode` 类型未含。
- `parallelWorld.updateCheckpoint`：`SceneSyncPanel.vue:151` 调用，对象已不含该方法（致 2 未处理 rejection）。
- `getRoomsBySlot`：`CanvasRoom.vue` 静态 import，重构剥离 → **已用 fix A 恢复**。
- `useAppearance` 6 键：`App.vue` 解构为 undefined → **已用 fix B 补**。

**B 类 — 类型不兼容（由 fix A 引入，我方须先修）**
- `ShellSlot` 不可赋值 `RoomSlot`（`world-shell/rooms.ts:16`）。需解耦两套 slot 语义：`RoomSlot` = 宅院空间分区（front-yard/hall/back-yard，属 room-graph 领域）；`ShellSlot` = world-shell 私有壳槽（含 `screen`）。二者不应混用，建议 room-graph 的 `slot` 与 world-shell 的壳槽各自定义、通过映射层转换。

**C 类 — 壳层配置未注入（运行时第三层，影响面最大、最可见）**
- `activeShell` / `surfaceState` / `layoutMode` / `floatingLayers` 在 App / CanvasRoom / SurfaceStage / FloatingLayerHost 全 `undefined`。world-shell 状态源未接通到消费组件。影响 24 路由壳层渲染（内容层仍可用）。**本轮最高优先级修复项**。

**D 类 — 环境 / 桥接**
- web 模式 Tauri IPC 抛 `Receiving end does not exist`（4 路由）；浏览器扩展噪声。非缺陷，但 web-preview 路径应守卫。
