## 三、P1-2 双向链接（Bi-directional Links）

### 3.1 设计意图
对应「思绪书房」落地：笔记正文用 `[[id]]` 或 `[[标题]]` 引用，自动建立链接，并在编辑器内展示「反向链接」（被哪些笔记引用）。

### 3.2 链接引擎 `note-links.ts`（新建）
文件：`src/modules/study/note-links.ts`（P1-2 主干）
```ts
export interface NoteLink { id: string; sourceId: string; targetId: string; createdAt: string }
const LINKS_KEY = 'hf:note_links'

parseLinkRefs(content)      // 正则 /\[\[([^\]]+)\]\]/g，去重
resolveTargetId(token, notes) // 先精确 id，再按 title（trim+小写）匹配
connect(sourceId, targetId) // 拒绝自引用、去重
disconnect(sourceId, targetId)
getOutgoingLinks(noteId)    // 本笔记引用
getBacklinks(noteId)        // 反向链接（反链面板核心）
syncLinksForNote(noteId, content, notes) // 幂等：依据 [[...]] 重建出链
useNoteLinks()              // 统一返回上述 API
```
- `links` 为模块级 `ref<NoteLink[]>`，从 `storage` 加载；`generateId` 生成主键。
- 选用**独立链接存储**（`hf:note_links`），而非复用 knowledge 模块的 `KnowledgeRelation`——后者绑定 `KnowledgeNode.id`，跨域耦合成本高，故自包含实现以贴合「思绪书房」语义。

### 3.3 study 模块接入
文件：`src/modules/study/index.ts`
- L8：`import { syncLinksForNote } from './note-links'`
- `create()`（L42）、`quickCapture()`（L70）、`update()`（L84，仅当 `data.content` 变更时）三处 `persist()` 之后调用 `syncLinksForNote`，保证出链随正文实时同步。

### 3.4 反链面板与编辑器接入
- 新建 `src/components/BacklinksPanel.vue`：`props.noteId`；`emit('open', noteId)`；展示「本笔记引用」与「被引用·反向链接」两段；`titleOf(id)` 解析标题或「（已不存在的笔记）」；无链接时 `v-if="hasLinks"` 整体隐藏；含作用域样式（`.backlinks-panel`、`.bl-item:hover`、`.bl-dir` 强调色）。
- 编辑 `src/components/NoteEditor.vue`：引入 `BacklinksPanel`，`defineEmits` 增 `open`；在预览区之后、页脚之前挂载 `<BacklinksPanel v-if="props.note" :note-id="props.note.id" @open="emit('open', $event)" />`。

## 四、P1-3 自然语言创建（NL Creation）

### 4.1 设计意图
对应「经略阁 / 自律工坊」复用镜我意图解析：一句自然语言自动分派到对应创建 API，**不引入第三套解析器**。

### 4.2 编排器 `nl-create.ts`（新建）
文件：`src/modules/mirror/nl-create.ts`
```ts
export type NLCreateResult =
  | { kind: 'plan'; id: string; title: string }
  | { kind: 'habit'; id: string; title: string }
  | { kind: 'note'; id: string }
  | { kind: 'focus' }
  | { kind: 'unsupported'; intent: IntentCategory | 'unknown' }

const HABIT_KEYWORDS = ['习惯','每天','坚持','养成','打卡','日常']
detectHabitIntent(raw)          // 习惯关键词预检
executeNaturalLanguageCreate(raw) // 主入口
```
分派逻辑：
1. **习惯关键词预检优先** → `useDisciplineBridge().addHabit(title,'','🌱','easy','daily',1)`（标题去除关键词）。
2. 否则 `parseTaskBest(text)` 分派：
   - `plan` → `createPlanNode(text)`：经 knowledge `createNode` 建 `KnowledgeNode`（`cat='frame'`）。
   - `note` → `useStudy().quickCapture(text)`。
   - `focus` → `{ kind:'focus' }`。
   - 默认 → `{ kind:'unsupported' }`。
- `createPlanNode`：`genId('node')` 生成主键，填充 title/desc/createdAt/updatedAt。

新增 `src/modules/mirror/__tests__/nl-create.test.ts`（5 项）：习惯意图命中/未命中、『每天坚持跑步』→ 习惯且标题『跑步』、『制定计划…』→ 计划节点标题含『季度复盘』、『记一下灵感 #idea』→ 笔记、空串→unsupported。
