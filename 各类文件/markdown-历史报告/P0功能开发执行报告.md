## 2. P0-1 镜我场景卡（Mirror Scene Cards）

**目标**：在"镜我"（All Selves）入口将"此刻想做什么"前置为一组可点击的意图场景卡，按意图路由到对应房间，或直接触发专注计时。

**实现内容**：

| 文件 | 动作 | 说明 |
|------|------|------|
| `src/modules/mirror/intent-launch.ts` | 新增 | 纯逻辑意图→路由分发映射：`INTENT_ROUTE`、`DIRECT_ACTION_INTENTS`、`getIntentRoute(category)`、`isDirectAction(category)` |
| `src/components/MirrorSceneCards.vue` | 新增 | 渲染 10 个 `INTENT_INFO` 场景卡（排除 `unknown`），`emit('launch', IntentCategory)`。导出 `TIntentCardInfo` 类型（4 字段，匹配 `INTENT_INFO` 形态，规避 TS2739 缺字段问题） |
| `src/views/AllSelvesMirror.vue` | 修改 | 概览卡后插入"此刻想做什么"分区并挂载 `MirrorSceneCards`；`handleIntentLaunch` 对 `focus` 启动专注计时（`useTimer().interrupt(); setMode('focus', 25); start()`），其余意图执行 `router.push(getIntentRoute(category))` |

**测试**：`src/modules/mirror/__tests__/intent-launch.test.ts`（4 项）、`src/components/__tests__/MirrorSceneCards.test.ts`（3 项）。

## 3. P0-2 笔记快速记录（Quick Note Capture）

**目标**：flomo 式无标题原子卡片快速捕获，输入即存，`#标签` 自动涌现（标签涌现机制）。

**实现内容**：

| 文件 | 动作 | 说明 |
|------|------|------|
| `src/modules/study/index.ts` | 修改 | 新增模块级 `extractTags(raw)`（正则 `/(?:^|\s)#([\p{L}\p{N}_]+)/gu`，去重去 `#`）；`useStudy().quickCapture(raw)`（标题置空、提取标签、剔除标签 token、空内容返回 `null`）；`quickCapture` 纳入 `useStudy` 返回 |
| `src/components/QuickCapture.vue` | 新增 | `textarea` + 实时 `#标签` 预览，回车精确 / 失焦提交，`emit('capture', raw)`，占位符默认可配置 |
| `src/views/Study.vue` | 修改 | header 后插入 `<QuickCapture @capture="onQuickCapture">`，`onQuickCapture` 调用 `study.quickCapture` |

**测试**：`src/modules/study/__tests__/quick-capture.test.ts`（5 项）、`src/components/__tests__/QuickCapture.test.ts`（3 项）。

## 4. P0-3 情绪前置 · 双轴（Emotion-first / Dual-axis）

**背景**：`EmotionGarden.vue` 中"情绪选择前置、文字可选"的核心需求**已实现**（`selectedType` 默认 `'calm'`、类型按钮、可选文字输入、`plantFlower` 调用 `garden.add`）。依据《蓝图17》模块 4 Moo 日记规格"双轴（情绪 / 天气）"，本次补齐**可选的天气第二轴**。

**实现内容**：

| 文件 | 动作 | 说明 |
|------|------|------|
| `src/modules/emotion/types.ts` | 修改 | 新增 `EmotionWeather = 'sunny' \| 'cloudy' \| 'rainy' \| 'windy' \| 'snowy'`；`EmotionRecord` 增加可选 `weather?: EmotionWeather`；新增 `WEATHER_OPTIONS` 选项数组 |
| `src/modules/emotion/index.ts` | 修改 | `add(type, note='', weather?)` 持久化 weather；`update(id, data)` 的 `data` 类型增加可选 `weather`；导出 `EmotionWeather` 与 `WEATHER_OPTIONS` |
| `src/views/EmotionGarden.vue` | 修改 | 新增 `selectedWeather` ref + `toggleWeather()` + `weatherLabel`；情绪选择器下方新增可选天气选择器（圆形按钮，再次点击取消）；选中预览显示天气徽标；`plantFlower` 传入 weather 并在提交后复位；导出文本补充天气字段 |

**测试**：`src/modules/emotion/__tests__/index.test.ts` 扩充 5 项（不带天气时 `weather` 为 `undefined`、带天气持久化、仅天气无文字仍创建、通过 `update` 补充天气）。
