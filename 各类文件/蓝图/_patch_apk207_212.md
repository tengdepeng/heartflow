## 2.207 番茄专注计时（Forest → 自律工坊/更漏）

### 核心设计理念
Forest 用「种树」把专注可视化：每完成一个专注时段就种下一棵树，中途放弃则树枯萎，让时间投入看得见、舍不得中断。它把抽象的意志力转译成可积累的成长符号，配合每日统计与连续天数，形成温柔的自我监督。

心流工坊的「更漏」已承担时间仪式感，「自律工坊」负责行为管理；专注计时补上任务级的时间颗粒度——把一天切成一段段可执行的专注块，并用树的成长作为回馈，比单纯倒计时更有温度。

### 关键数据模型
```json
{
  "focus_session": {
    "id": "uuid",
    "task_title": "string",
    "duration_minutes": 25,
    "mode": "pomodoro | custom",
    "break_mode": "short | long | none",
    "status": "active | completed | abandoned",
    "interrupt_reason": "string",
    "started_at": "ISO8601",
    "ended_at": "ISO8601",
    "tag": "string"
  },
  "tree_record": {
    "id": "uuid",
    "session_id": "uuid",
    "tree_type": "string",
    "grown_at": "ISO8601",
    "status": "grew | withered"
  },
  "focus_stats": {
    "date": "YYYY-MM-DD",
    "total_sessions": 0,
    "total_minutes": 0,
    "interruptions": 0,
    "streak_days": 0
  }
}
```

### 交互规格
**专注启动流程**：自律工坊「专注计时」→选择任务与时长（25/45/自定义）→开始番茄钟→进入专注状态→计时结束进入休息倒计时。

**中断记录流程**：自律工坊「专注计时」→主动暂停/中断→如实记录中断原因（分心/急事/疲劳）→本次会话标记「未完成」→不惩罚、不美化，仅留下诚实记录。

**每日回顾流程**：更漏「专注回顾」→按日/周查看专注会话→统计总时长、中断次数与连续天数→与任务完成情况对照→趋势一目了然。

**自定义节奏流程**：自律工坊「节奏设置」→设置专注时长、休息时长与轮数（2~6 轮后长休息）→长期统计数据自动提示最适合个人的节奏区间。

**树园回看流程**：自律工坊「树园」→每个专注时段长成一棵树→按月份/主题浏览树园→枯萎的树也在，构成完整的时间年轮。

## 2.208 白噪音与冥想（潮汐 → 守护室/梦乡小筑）

### 核心设计理念
潮汐把白噪音、冥想引导与番茄钟、睡眠结合，用声音搭建可切换的环境：下雨、海浪、篝火、风铃，以及有引导语的冥想段落。它不依赖画面，而是通过听觉把人的注意力收拢到当下，是成本最低的「换境」方式。

心流工坊的「守护室」负责心境维护，「梦乡小筑」负责睡眠陪伴；本条目把声音场景做成可收藏、可定时、可组合的本地资源——所有音频文件存在本地，冥想前后记录心境，让情绪变化有迹可循。

    "duration_minutes": 10,

    "mood_before": "string",
    "mood_after": "string",
    "note": "string"

    "ended_at": "ISO8601",
    "auto_off_minutes": 30,

### 交互规格
**白噪音播放流程**：守护室「声音场景」→选择自然/氛围音（雨声、海浪、篝火等）→调节音量→开始播放（纯本地音频文件，无网络流）→可随时切换场景。

**冥想引导流程**：守护室「冥想」→选择引导语（呼吸、身体扫描、正念）与时长→跟随引导→结束后记录冥想前后心境→心境变化归档可回顾。

**助眠场景流程**：梦乡小筑「睡前声音」→选择白噪音→设置定时关闭（15/30/60分钟）→声音自动淡出→睡眠记录写入梦乡小筑。

**声音库管理流程**：守护室「声音库」→浏览/试听/收藏预设→支持导入本地音频文件作为自定义场景→按类别整理。

**心境对照流程**：守护室「冥想回顾」→按时间线查看每次冥想前后心境→识别情绪变化模式→形成个人情绪地形图。

| 声音预设管理 | 守护室「声音库」 | 守护室 |
| 心境前后对照 | 守护室「冥想回顾」 | 守护室 |

- ✅ 用户主动触发播放与冥想
- ✅ 无云端依赖，白噪音为本地文件播放

## 2.209 电子书阅读器（微信读书 → 阅览殿）

### 核心设计理念
微信读书以书架为核心容器，把「读」扩展为完整闭环：书架管理、进度续读、划线笔记、阅读时长统计，再加上听书解放双手。它让人同时看见「正在读什么」和「读了多少」，阅读因此变得可积累、可复盘。

心流工坊的「阅览殿」承载书库，「思绪书房」承接思考碎片；本条目补齐阅读器本体——本地电子书导入、进度同步、划线笔记与阅读统计，让书里画下的每一笔都自然流进个人知识体系。

### 关键数据模型
```json
{

    "id": "uuid",
    "title": "string",
    "author": "string",
    "file_path": "local_path",
    "cover_path": "local_path",
    "format": "epub | mobi | txt | pdf",
    "total_progress": 0.0,
    "current_location": "string",
    "added_at": "ISO8601",
    "last_read_at": "ISO8601",
    "shelf": "reading | finished | wish | archived"
  },
  "highlight": {
    "id": "uuid",
    "book_id": "uuid",
    "content": "string",
    "note": "string",
    "location": "string",
    "color": "string",
    "created_at": "ISO8601"
  },
  "reading_stat": {
    "date": "YYYY-MM-DD",
    "minutes": 0,
    "pages": 0,
    "book_id": "uuid"

```

### 交互规格
**续读流程**：阅览殿「书架」→打开任意书→自动回到上次阅读位置→进度条与页码清晰展示→翻页即保存进度→随时合上随时续上。

**划线笔记流程**：阅览殿「划线」→选中文字→划线/高亮→附写想法→笔记自动归入思绪书房→可回看书内原文上下文。

**听书流程**：阅览殿「听书」→本地 TTS 朗读当前书籍→支持倍速与语速调节→后台播放→阅读时长同样计入统计。

**阅读统计流程**：时长廊「阅读统计」→按日/周/月查看阅读时长→关联书目、划线数与笔记数→阅读节奏可视化。

**书架整理流程**：阅览殿「书架整理」→书目按在读/读完/想读/归档分类→支持搜索与标签→书与书之间的引用关系可记录。

## 2.210 思维导图（XMind → 思绪书房/经略阁）

### 核心设计理念
XMind 以中心主题向外层层发散，支持导图与大纲一键互转、多种结构布局（逻辑图、树形图、时间轴），把「想」的过程可视化。它的价值不在图本身，而在强制要求每一层都有清晰层级，倒逼思考结构化。

心流工坊的「思绪书房」存放思考碎片，「经略阁」承担知识整理；本条目让碎片长出骨架——从任意思绪一键生图，节点可挂接原文笔记，导图完成后再导出为文稿，打通「想清楚→写出来」的路径。

**节点挂接流程**：思绪书房「节点关联」→任意节点可关联既有思绪、笔记或书籍划线→点击节点直接跳转原文→导图成为知识体系的导航索引。

**导图导出流程**：经略阁「导出」→导图导出为图片/Markdown大纲/纯文本→Markdown 可直接进入输出管理继续成文→结构不丢。

**想法转图流程**：思绪书房「碎片成图」→选中一条已有思绪→一键以该思绪为中心生成导图草稿→原碎片内容自动落到中心节点备注。

## 2.211 密码与密钥管理（KeePass → 保险库房间）

### 核心设计理念
KeePass 是本地优先的密码管理器：数据库以强加密格式存成单个本地文件，仅凭主密码即可解锁，不依赖任何云端账户。它把「安全」建立在用户自己持有的密钥上，而不是托管给第三方服务器。

心流工坊的「保险库房间」正是为此而设——本地加密数据库、主密码解锁、自动锁定、内置强密码生成器，让账号密码这类最敏感的隐私，以最朴素的方式被守护：文件在自己手里，密钥在自己脑里。

### 关键数据模型
```json
{
  "vault": {
    "id": "uuid",
    "name": "string",
    "db_path": "local_path",
    "encryption": "aes256-gcm",
    "key_derivation": "argon2id",
    "auto_lock_minutes": 5,
    "created_at": "ISO8601",
    "last_unlocked_at": "ISO8601"
  },
  "vault_entry": {
    "id": "uuid",
    "vault_id": "uuid",
    "title": "string",
    "username": "encrypted",
    "password": "encrypted",
    "url": "encrypted",
    "notes": "encrypted",
    "category": "login | card | note | key",
    "tags": ["string"],
    "created_at": "ISO8601",
    "updated_at": "ISO8601"
  },
  "password_generator": {
    "length": 20,
    "use_upper": true,
    "use_lower": true,
    "use_digits": true,
    "use_symbols": true,
    "exclude_ambiguous": true
  }

```

### 交互规格
**解锁流程**：保险库房间「解锁」→输入主密码→本地解密数据库文件→解锁后倒计时显示剩余锁定时长→空闲自动上锁。

**条目管理流程**：保险库房间「新增条目」→填写标题/账号/密码/网址/备注→按分类归档（登录/卡片/密钥/杂项）→所有字段加密存储→支持搜索与标签筛选。

**密码生成流程**：保险库房间「生成密码」→设置长度与字符集→一键生成强密码→强度即时评估→直接填入新条目并保存。

**自动锁定流程**：保险库房间「锁定策略」→设置空闲分钟数或手动锁定→锁定后任何界面均需重新输入主密码→加密文件可整体导出备份。

**备份与恢复流程**：保险库房间「备份」→加密数据库导出到本地其他目录/移动介质→验证备份完整性→恢复时导入并校验主密码。

|---------|------------|------|
| 本地加密库 | 保险库房间「本地加密库」 | 保险库房间 |
| 主密码解锁 | 保险库房间「解锁」 | 保险库房间 |
| 条目分类管理 | 保险库房间「条目管理」 | 保险库房间 |
| 强密码生成器 | 保险库房间「生成密码」 | 保险库房间 |
| 自动锁定 | 保险库房间「锁定策略」 | 保险库房间 |
| 加密备份恢复 | 保险库房间「备份」 | 保险库房间 |

- ✅ 无社交功能、无共享库

## 2.212 剪贴板管理（快贴 → 输出管理）

### 核心设计理念
快贴把系统剪贴板从「一次性暂存」升级为「可检索的历史库」：复制过的每段文本、图片都按时间留存，可固定、可搜索、可复用。它解决的是信息在设备间流转时的碎片化——复制不是终点，素材积累才是。

心流工坊的「输出管理」是素材与成品的集散地；本条目把剪贴板变成素材入口——历史可回看、常用片段可固定、条目可一键存入素材夹供写作调用，让随手复制的内容最终流向产出，而不是淹没在剪贴板深处。

### 关键数据模型
```json
{
  "clip_item": {
    "id": "uuid",
    "type": "text | image | file",
    "text": "string",
    "image_path": "local_path",
    "file_path": "local_path",
    "source_app": "string",
    "copied_at": "ISO8601",
    "is_pinned": false,
    "tags": ["string"]
  },
  "snippet": {
    "id": "uuid",
    "title": "string",
    "content": "string",
    "created_at": "ISO8601",
    "updated_at": "ISO8601",
    "usage_count": 0
  },
  "clean_policy": {
    "max_items": 500,
    "max_days": 30,
    "clear_pinned": false,
    "last_cleaned_at": "ISO8601"
  }
}
```

### 交互规格
**历史浏览流程**：输出管理「剪贴板历史」→按时间倒序浏览复制记录→点击任意条目复制回剪贴板→支持关键词全文搜索→文本/图片/文件分区展示。

**固定收藏流程**：输出管理「固定」→常用片段（地址、邮箱、模板句）点击固定→置顶排列且不受自动清理影响→随时一键取用。

**素材入库流程**：输出管理「存入素材」→剪贴板条目转存为素材→自动建议标签与素材夹→后续写作/输出时直接调用→来源可追溯。

**清理维护流程**：输出管理「清理」→按条数上限与天数自动清理过期条目→固定条目豁免→敏感内容手动删除并清除本地缓存。

**复用统计流程**：输出管理「复用统计」→记录每条素材被引用次数→高频内容优先展示→可升级为常驻片段（Snippet）提升取用效率。
