# A3 · 12 个「缺口」的蓝图合规行为定义（逐条锚条款）

> 评审依据：`engine/constitution-effects.ts`（effect 定义）+ `stores/constitution.ts`（规则 title/description/articleNumber）+ `modules/constitution/effect-consumer-map.ts`（A2 账本·运行时真实消费映射，单一事实源）+ `蓝图21心流工坊.txt`（宪法条款原文）
>
> **核心结论（先说清楚）**：这 12 个**不是未实现的缺口**，而是经 A2 账本诚实审计后，确认「无对应可门控运行时特征 / 逻辑」或「建了反而违宪」，故标 `declared`（诚实声明式·已封口·永不建）。**这种「诚实声明式」本身就是符合蓝图的行为**——不是遗漏，是合规选择。
>
> 之前称其为「缺口」是按「只有运行时消费才算已接」的口径，与代码账本（A2 ledger）冲突。本文件以代码账本 + 条款原文为唯一事实源更正。

## 锚定方法

每个 target 的合规行为 = `规则描述`（代码侧宪法表达）+ `蓝图条款原文`（意图源头）。门控方向以 effect `type`（enable/disable）与条款意图共同决定，不靠 effect 名臆测。

## 一、enable 型（规则活跃=允许该自由）· 8 个

### 1. `relation:unbounded` —— 关系不预设结论
- **规则**：`elastic-relation` / `enable` / 默认启用。描述：**"可为人与关系相关内容保留位置，但不预设关系结论或情感解释。"**
- **蓝图条款**：第15条「关系纽带」——"你可以为一个人留一个位置，即使 ta 永远不会来。"
- **合规行为**：保留关系记录位置，但**不自动生成关系结论 / 情感解释**。关系数据未做自动分析即天然留白。
- **代码状态**：`effect-consumer-map.ts:105` → `declared` ✅。"关系数据未做自动分析即天然留白，`relation:auto-analyze` 已消费……诚实声明式·不影响运行时·不伪造宪法之实【决策已定·永久诚实声明·永不建】"
- **是否需改代码**：否。已合规（留白天然成立）。

### 2. `data:unfinished` —— 允许未完成停留
- **规则**：`elastic-stillness` / `enable` / 默认启用。描述：**"允许记录暂停、停留或无明显进展的状态。"**
- **蓝图条款**：第21条「未完成的栖息地」——"你可以把没吃完的菜留在桌上。" + 第24条「不必完全懂得」。
- **合规行为**：未完成内容**被保留、不被强制完成或清理**。删除/释放是 `data:cleanup`/`data:auto-archive`（已运行时消费）的域，且需用户显式确认。
- **代码状态**：`effect-consumer-map.ts:99` → `declared` ✅。"仅手动 confirmCleanup，无 force-complete/auto-archive 逻辑……诚实声明式·不影响运行时·不伪造宪法之实【决策已定·永久诚实声明·永不建】"。`UnfinishedGarden.vue` 页面存在即其体现。
- **是否需改代码**：否。已合规。

### 3. `focus:interrupt` —— 允许中断
- **规则**：`elastic-forget` / `enable` / 默认启用。描述：**"不要求连续签到、持续记忆或固定频率使用。中断后可直接继续。"**
- **蓝图条款**：第34条「允许遗忘」——"你可以忘记自己曾来过这里。"（另归第3条「心流第一」弹性宪法，用户可关）
- **合规行为**：`interrupt()` **始终允许**中断，这是用户自主权。
- **代码状态**：`effect-consumer-map.ts:93` → `declared` ✅。"interrupt() 始终允许中断，基础 UX 已无条件保障「允许中断」自主权；**接入反向门控（关闭即禁止中断）会制造宪法陷阱、剥夺用户中断权**，故诚实声明式·不影响运行时【决策已定·永久诚实声明·永不建】"
- **是否需改代码**：否。**反向门控会违宪**，所以"不建"才是合规。

### 4. `focus:return` —— 中断可续接
- **规则**：`elastic-return` / `enable` / 默认启用。描述：**"中断后可从现有记录继续，不要求重新建立全部上下文。"**
- **蓝图条款**：第37条「应答不必成篇」——"回应不必被展开成对话……一个字，也可以是一个完整的回合。"

### 5. `note:fragment` —— 支持片段式记录
- **规则**：`elastic-convergence` / `enable` / 默认启用。描述：**"不同主题、对象或时间点的内容可在同一空间并列出现，无需统一口径。"**

### 6. `timer:pause-interval` —— 允许操作间暂停间隔
- **规则**：`elastic-breath` / `enable` / 默认启用。描述：**"允许在操作之间保留暂停间隔，不以连续动作作为默认预期。"**
- **蓝图条款**：第19条「庭院有自己的时间」——"你不在的时候，庭院依然在过自己的日子……它不因你的缺席而暂停，也不因你的归来而重启。"

- **是否需改代码**：否。建主动提醒才违宪。

### 7. `behavior:tracking` —— 支持重复动作追踪
- **规则**：`elastic-ritual` / `enable` / 默认启用。描述：**"支持将重复出现的动作或步骤作为可追踪内容保留。"**

### 8. `gesture:haptic` —— 手势触觉反馈（无独立门控点）

## 五、对前序 A2 评审清单的更正

`A2-宪法接线-逐条评审清单-2026-09-08.md` 把上述 12 个列为「真实未覆盖缺口」，且 ruleId 多处写错（如 `focus:interrupt`→`elastic-self-care` 实为 `elastic-forget`；`focus:return`→`elastic-forget` 实为 `elastic-return`；`note:fragment`→`elastic-light-memory` 实为 `elastic-convergence`）。其错误根因：**用"仅运行时消费才算已接"的口径，把 `declared` 项误判为缺口**。

现实代码（`effect-consumer-map.ts`，单一事实源）已 42/42 解析（28 运行时 + 13~14 declared）。该 A2 清单文档应标记为**已被代码账本取代**，或按本文件口径重写为"已封口项清单"，以免误导后续"待接"冲动。
