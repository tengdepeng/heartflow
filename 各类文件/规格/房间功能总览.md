## 一、第一层 · 引力场画布（基底）
- 会呼吸的介质；玉珠载体、介质呼吸、结晶落点、**星盘入口**。
- 打包 <5MB，启动 0.5 秒，不需网络。

## 二、第二层 · 家（8 个家居空间）
玄关 / 衣帽间 / 厨房+餐厅 / 卧室 / 浴室 / 客厅 / 书房 / **庭院**（庭院含：溯源树、习惯树、花圃、人生罗盘）。
- 梦境区从卧室床头光点进入。

## 三、第三层 · 功能空间
### 主链路空间（3）
1. **时间长廊** — 垂直滚动光丝、双指缩放日/周/月/年；时间线主轴。
2. **逐日心锚** — 每日锚点六步闭环（倾倒→安放→手札→完成→推迟→放回）；微小记录亦可。
3. **情绪花房** — 情绪记录与花朵隐喻；所有情绪皆为不同颜色的花，无好坏之分。

### 世界空间（约 21 个）
阅览殿 / 字镜阁 / 释光阁 / 身体温室 / 藏象阁 / 动律之间 / 更漏(及其子空间) / 羁绊之厅 / 岁时阁 / 根脉之庭 / 留光阁 / 自律工坊 / 逸趣阁 / 地图室 / 未完成花园 / 平行世界 / 经略阁 / 守护室 / 保险库房间 / 书签与入口架 / 镜我（全局陪伴面，跨层）。

## 四、第四层 · 安全岛（全局状态层，非房间）
- 覆盖画布的安全态；连续快速点击载体 5 次触发。

## 五、30 功能空间 · 逐房间功能（第四部分）
> 格式：定位 → 融合方式 / 宪法兼容要点。

- **模块〇 数据可视化自定义体系**（跨房间基础设施）：五维视觉材质工坊 + 可视化隐喻引擎(10种) + 数据视觉逻辑语言引擎(七维映射，~2200万变体) + 风格包。底座：人升雷达图、华为健康三环、Keep 进度环、OffScreen 克制可视化。
- **模块一 输出管理**：记录的导出/呈现/装订 → 本地导出；**拒绝**外部分享链路（违第1条）。
- **模块二 时间线索引**：按天分片 JSON + 二级索引 + 权重算法（锚点 must=1.0）。Moo 时间轴、flomo 随机回顾（用户主动）。
- **模块三 时间长廊视图层**：垂直滚动光丝、双指缩放。Moo 时间轴 + flomo 标签云聚类。
- **模块四 情绪花房**：情绪记录 + 花朵隐喻。Moo 情绪优先/双轴/温和反馈、YoYo 治愈视觉；**拒绝**情感分析评判。
- **模块五 逐日心锚**：六步闭环；YoYo 微小锚点 + 时光胶囊（给未来的自己，主动）。
- **模块六 守护室**：治理台/安全台/健康台/光笺抽屉。是"拒绝清单"落点（拒推送/建议/操控）。
- **模块七 镜我(MirrorSelf)**：定音锤四幕 + 年度对话；陈列而非叙事。吸收推理可见/场景卡/工具卡/归档/流式；**拒绝**云端/评价/吉祥物/分支。
- **模块八 留光阁**：遗留之物、记忆安放。墨墨记忆曲线光泽、Kimi 归档。
- **模块九 思绪书房(StudyRoom)**：笔记与知识。flomo 无压力记录、思源块级双向链接、幕布大纲⇄图谱、印象富文本+本地AI；**拒绝**云/协作/集市。
- **模块十 经略阁**：人生规划与编排。滴答今日视图/GTD 心智卸载、自然语言解析；**拒绝**日历集成与四象限优先级评判。
- **模块十一 羁绊之厅**：关系纽带（第15条）。社交/排行类全拒；仅"本地为一人留位"。
- **模块十二 根脉之庭**：家族/根源。无竞品映射，保持本地根源叙事。
- **模块十三 岁时阁**：时间仪式/年轮。YoYo 年度时间胶囊 + Moo 时间轴。
- **模块十四 逸趣阁**：趣味/放松。无竞品映射，保持蓝图15。
- **模块十四·五 应用空间自定义体系**（基础设施）：应用使用感知(UsageStatsManager/Health Connect)，仅脱敏元数据。OffScreen 屏幕时间/睡眠仪式。
- **模块十五 身体温室**：身体感受而非指标。Keep 跟随式引导+进度环、华为健康三环(状态导向)；**拒绝**目标评分/穿戴依赖/健康建议。
- **模块十六 自律工坊**：习惯/自律，内在驱动。滴答习惯任务分离、人升成就里程碑+自我奖励(非金币)；**拒绝**XP/等级/排行/积分。
- **模块十七 字镜阁**：字画像（字形光廓/墨色情绪/书写节奏）。墨墨记忆层级 + 多邻国"每日一字"微练习。
- **模块十八 释光阁**：深度推理器（前提/框架/情感/缺席四束光，全本地规则，不依赖 LLM）。吸收推理可见性；**拒绝**云端 LLM。
- **模块十九 阅览殿**：阅读/知识沉淀（呼吸的书，三视角）。墨墨间隔重复、多邻国微单元、思源双向链接；**拒绝**游戏化/排行/推送。
- **模块二十 动律之间**：活动/作息节律。OffScreen 睡眠/屏幕仪式、Keep 活动识别；节律可视化不评判。
- **模块二十一 更漏**：工作类计时。滴答番茄钟绑定任务、OffScreen 专注结晶；**拒绝**提醒。
- **模块二十二 工痕 / 二十三 劳酬 / 二十四 匠庐**：工作痕迹/劳动回报/匠艺。人升自我奖励商店 + 匠艺成长树；**拒绝**数值化属性/社区排行。
- **模块二十五 业脉 / 二十六 行囊 / 二十七 息壤**：事业网络/随身行囊/滋生之地。社交/职业同步类全拒，保留本地叙事。
- **模块二十八 藏象阁**：五藏映射五行色（心红/肝青/脾黄/肺白/肾蓝）；医疗边界"象"非"症"。华为身体/压力/睡眠数据(本地脱敏)；**拒绝**诊断/建议。
- **模块二十九 平行世界·梦境区**：可能性自我/抉择分叉/梦境/时间胶囊。YoYo 时光胶囊 + Moo 时间流。
- **附录 D 地图室**：元地球高清地图，空间回溯（本地）。
- **附录 E 未完成花园**：第21条栖息地。
- **附录 F 保险库房间**：本地加密资产。

## 七、宪法红线对房间的影响（关键）
- **第1条 本地私有（强制）**：所有房间数据本地；flomo/思源云端同步、Kimi 广场、华为账号绑定 → 改造为本地优先或拒绝。
- **第2条 超级自定义（强制）**：交互到视觉、房间结构到宪法均可改；多邻国固定引导/Keep 固定路径 → 改造为可关闭/可替换。
- **第3–52条（可选）**：如推送/排行/广告/积分/连续签到/评价性回复/社交压力 → 在相关房间默认关闭即可兼容，不否决融合。
- **第52条 沉默的默认**：幕僚问候浮窗默认关；拒绝一切推送/轰炸。
