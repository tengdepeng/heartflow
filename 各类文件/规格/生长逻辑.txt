## 主要枝干 · 核心系统（第三阶段落地）


### 幕僚统一体系（城市的居民）

- **幕僚 = 职责 + 性格 + 知识库 + 载体形象**
- **镜我（幕僚长）**：用户创建的第一个幕僚，活在镜像空间里。用户读书时在旁翻书，锻炼时做对应动作，停止专注时提醒。能引用用户知识库回答问题。有不完美（会累、会犹豫）。
- **幕僚创建与管理**：多个分身，独立职责（陪伴型/研究型/工作型/生活型/管家型/综合型）、独立性格（沉稳/活泼/严谨/直觉/关怀）、专属知识库（全殿堂或特定领域）。分身上限默认3个可调。可唤醒、沉睡、删除。
- **幕僚的日常与成长**：独立作息（晨型人/夜猫子/朝九晚五/随用户浮动），独立生活场景（书房/跑道/工作室/温室），独立成长轨迹。性格在相处中自然形成，不是参数滑块。
- **幕僚之间的互动**：协作（伯言推送加班数据给灵犀）、共处（追风和默渊在跑道场景）、互相学习（默渊推送书给伯言）、有分歧（伯言认为先工作，灵犀认为先休息）。
- **幕僚的偷偷翻看**：默渊深夜翻相册被撞见藏身后，灵犀在身体记录旁放花被问时说“这里需要一朵花”，追风在跑步记录旁放发光跑鞋不藏，伯言在工资记录前停顿后说“确实是你应得的”。被翻阅过的记忆在时间长廊留下极淡暖色光点。
- **幕僚的触角（外部感知与主动问候）**：感知通道（应用时长、位置城市级、设备状态——全部逐项授权）。问候浮窗（追风活泼、灵犀温柔、默渊沉静）。场景（工作、健康、关系、学习、生活、安全、娱乐、仪式、用户自定义）。可设置勿扰时段、专注中自动降级、安全岛里自动暂停。可逐幕僚开关、逐场景开关。
- **幕僚的调令、庆祝与退休**：用户自然语言下达调令，镜我分发给合适幕僚，完成后主动回报。用户达成目标时追风拿花环、灵犀做蛋糕、默渊点头、伯言记录。用户生活阶段变化时幕僚慢慢退场但不消失。

### 家与场景系统（身临其境的环境）

- **家（原点空间）**：完整的居住空间，不是功能房间集合。玄关（鞋柜、暖灯）、衣帽间（所有衣物挂放，自动关联记忆光点）、厨房（灶台炖汤，冰箱食材，灵犀研究新菜，追风偷吃）、餐桌/餐厅（厚实木桌，深夜食堂意象具象化）、卧室（床上用品随季节变化，梦乡小筑入口在床头，灵犀睡前说晚安）、浴室（沐浴放松，身体护理记录，加班深夜洗去疲惫）、客厅（沙发茶几书架，幕僚休息聚在这里，访客模式只进客厅）、书房（书架放接引的书，书桌笔记结晶，默渊常驻）、庭院/阳台（身体温室植物实体对应，庭院有一棵自主生长的树，溯源树和庭院树是同一棵）。从家玄关走出去是主画布，所有其他空间是家的延伸。
- **3D全场景**：创建方式（手动搭建、3D扫描导入、社区下载模板后调整、本地AI辅助生成——上传照片+描述，本地AI生成雏形，用户手动调整，所有处理本地完成不上传云端）。场景类型（家·原点场景、老房子与记忆场景、自然场景预设：针叶林/阔叶林/竹林/海边礁石/山巅/溪流边/草原/沙漠夜空、外部场景：常去咖啡馆/第一次约会公园长椅/山顶看日出位置、用户自建任意场景）。
- **场景与专注融合**：逐日心锚设定专注时选择“在哪个场景里专注”，计时开始时殿堂自动切换到该场景。介质呼吸在场景里自然融入（森林是碎光，老房子是尘埃，咖啡馆是蒸汽）。
- **场景切换**：星盘唤出场景列表（动态缩略图），过渡动画像穿过一扇门（门形态随场景风格变化），切换过程中专注计时不受影响。
- **场景隐私**：所有场景数据、3D模型、扫描结果全部本地存储不上传云端。分享只分享“骨架”（空间结构+基础材质），不含个人数据和记忆关联。

### 环境与氛围系统

- **环境系统（殿堂的气候层）**：光线（主光源方向/亮度/色温/柔和度，环境光，局部点光源及动画）、声音（底层音景：雨/海浪/森林/城市/白噪音/无声，细节音层：鸟鸣/风声/杯碟声/翻书声/键盘声，环境音乐：颂钵/古琴/钢琴/电子氛围——每层独立音量）、动态粒子（类型/密度/飘落速度/飘落方向）、气味暗示（通过色彩倾向或文字暗示：雨后泥土/旧书纸/咖啡/海盐/松木）。随时间和天气自动变化，随用户状态自动调整。环境编辑器自己调环境预设，保存可分享。官方预设：清晨书房、雨天的咖啡馆、深夜食堂、森林深处、海边黄昏、冬夜壁炉、极简白。
- **世界的生命（殿堂的心跳）**：不是环境系统一部分，不是用户可调参数，是殿堂作为活物的自主性。用户可在设置中调整幅度或完全关闭。包含自然（树自己长高、鸟偶尔飞过、蜗牛在跑道边）、偶然（殿堂在静默中自己发现记忆间隐秘连接，不主动推送只在撞见时微微亮起）、无用之物（空墙上树影、追风看的蜗牛）、秘密（用户和幕僚之间的暗语默契只有他们知道）、生长（镜像空间感知到用户需要时自己长出新的角落——从未走过的岔路通向从未见过的湖水）、真正的昼夜（默渊深夜灯光自动变暖，追风傍晚跑道有长影子，灵犀熬夜穿着睡衣抱着枕头出现）、风（书页被吹动、跑步迎面有风）、天气（殿堂在用户连续低落时自己下一场安静的雨，雨停后草地开满花）、未完之事（追风没跑完的路线若隐若现，默渊没读完的书堆在角落偶尔新增）、脆弱（用户很久没来角落积灰跑道边长野草温室有植物枯了——不是惩罚只是自然老化，回来时可以修缮）、传承（封存时幕僚沉睡，释放时变成种子可带走，传给新主人时幕僚记得旧主人光晕里保留颜色）、殿堂的梦（用户不在时记忆碎片随机重组，偶尔墙上出现昨天还没有的画慢慢消散只能瞥见不能保存）、敬畏（用户不是唯一的神，有些东西无法控制无法删除——树一直在长，蜗牛一直在，知识幽灵偶尔出现，未完之事一直在远处）、尽头（世界不是无限扩展，走到最远岔路上路断了，前方是柔和光雾看不见对面有什么）、新生（新主人到来时殿堂自我修复，默渊抬头打量，追风试探跑几圈，灵犀从新睡眠数据慢慢了解，伯言开新文件夹）。


## 次级枝干 · 功能房间（第四阶段落地）


### 时间与记忆类

- **时间长廊**：按时间排列所有记忆。统一时间线混排所有碎片（专注结晶、笔记、情绪标记、外部回流数据、聊天信笺、通话磁带、书签标记、运动时刻、工作记录、锚点完成标记）。未记录时间自然留白，视觉密度自然变稀薄。支持沉浸回看（正常速度回放某一天）、缓慢回溯（以接近一天的实际节奏移动）、结晶重访（长按选择“重访”短暂回到生成时的环境参数）、关联漫步（从一枚结晶沿关联路径走到另一枚）。页间连线（时间邻近蓝色、双链金色、情绪共鸣粉色、主题相近绿色）。
- **阅览殿 · 一本书的三种视角**：房间中央木桌上一本呼吸着的书——用户的人生之书。封面用户自选，书脊刻名字或代号，厚度由使用时长决定。横看·时间之流（书页水平延展成时间轴，像手风琴可拉伸收缩），侧看·剖面之镜（书页垂直分层形成多个剖面：情绪/身体/专注/社交/知识/游戏/运动/收藏/字的剖面/认知偏向），正看·全景之书（书页如蝴蝶展翅向两侧展开，中间浮现全景图）。三种视角无缝切换。书页材质随使用时间变化（新书素色略带粗糙，旧书温润有光泽，频繁翻阅更柔软，长久未碰轻微干涩）。书脊上慢慢浮出年轮纹理，年轮间偶尔出现小标记。合上书时极淡合页声。沉睡状态封面微微变暗呼吸更慢更深。封存时书被放进光质书盒。释放时书页慢慢变半透明最终变空白但封面和书脊还在呼吸还在。
- **字镜阁 · 字的画像**：圆形房间，穹顶柔和天光洒下，满墙满穹顶嵌着用户写过的所有字——每个字在微微呼吸。中央石台悬浮字镜（椭圆形光幕）。字的画像包含字形光廓、墨色情绪（开心暖金/低落灰蓝/焦虑暗红微锯齿/平静中性光）、笔压力度（用力粗重锐利/轻柔纤细模糊）、书写节奏（间距呈现为一根光丝）。穹顶高频字星图（一生最高频100字以光点排列，大小对应频率，点击星墙上对应段落微亮）。字间关联光丝（经常一起出现的字光丝较亮）。字的演化（不同时期同一主题文字并排对比，从极端到温和、从紧凑到舒展）。字的剖面在阅览殿侧看中呈现。
- **梦乡小筑**：安放梦的碎片。入口在卧室床头。醒来时趁还记得对着画布说“我梦到……”，语音自动转文字。生成半透明、边缘模糊的梦的结晶。久了飘着几十枚梦的结晶。梦的结晶和其他结晶形态不同——不是“真实发生的事”，是“真实做过的梦”。
- **岁时阁**：仪式与民俗文化空间。岁时环标注二十四节气和传统节日，快到某节气节日时对应位置微微亮起（只有走进岁时阁才能看到不是推送弹窗）。用户可创建私人仪式节点（仪式名称/日期/仪式内容/仪式记录）。人生仪礼区域记录诞生、成人礼、毕业、婚礼、告别等重大仪式时刻。书架上有民俗文化典籍可接引阅读。岁时环节气标记关联藏象阁调养建议。节日氛围：春节门框浮现极淡红色光纹，清明窗外飘细密水墨雨丝，中秋空中悬浮微型明月。
- **平行世界**：基于所有记录，本地AI推演可能性自我。包含AI推演、抉择分叉（每条未选择的路径）、梦境碎片（半透明的梦的结晶）、虚拟人生（游戏存档——你在另一个世界里的足迹）、时间胶囊（给未来的自己写一段话，设定开启时间，到了那天自动打开）。

### 认知与思维类

- **思绪书房**：笔记存放、知识结晶管理。书架上的书以当前风格包质感呈现。聊天记录是泛微光旧信笺按人按时间摆架上。通话录音是老式磁带拖特定位置播放。网页摘录是知识结晶。知识年轮：每枚知识结晶周围浮现一圈圈极淡光圈代表“再认”与“回顾”。
- **经略阁 · 私人知识管家**：知识星图由节点和连接构成。连接有类型（A是B的前提、A是B的反例、A和B经常同时出现、A可推导出B、A是B的简化版、A和B表面矛盾实际互补）。多种展示方式（知识图谱/思维导图以某节点为中心向外层层展开/大纲极简层级折叠/头脑风暴极简白板快速输入光点随机散落拖拽聚拢成组结束后一键转化/时间线按创建时间排列/对比模式两个或多个节点并排对比/地图模式等高线地形图知识密度高处隆起山峰盲区以柔和阴影呈现）。本地AI提供深层连接建议（新节点加入自动分析潜在关联以极淡虚线标记用户确认变实线）、盲区探测、深度追问（这个判断前提是什么/有哪些反例/什么情况失效/教新手怎么比喻/直觉从哪次经历形成）、知识管家对话（自然语言向自己知识库提问只在用户知识库内搜索关联推理不使用外部数据）。与外部软件联动（从浏览器/Notion/Obsidian/飞书/微信导入，AI提炼知识节点初稿等确认；导出思维导图兼容XMind、Markdown大纲兼容Obsidian/Notion、JSON图谱数据）。
- **释光阁 · 认知解释空间**：房间中央释光仪，核心是一束垂直的光柱，用户把任何一件事放上去（观点/判断/信念/决定/情绪反应/反复困扰）。四束光照亮：前提之光（下方照上来照亮默认假设）、框架之光（侧面照过来照亮解释框架：二元/道德/工具/情感）、情感之光（上方照下来照亮情感负载：附着什么情绪记忆触动什么旧伤口）、缺席之光（光柱短暂熄灭只剩暗色照亮不在场的东西：没考虑的角度/忽略的例外/省略的反面证据）。四周四幅认知光图（广度图、深度图、弹性图、演化图）。认知四层次（盲区层、排斥层、理解层、转化层）。四个实操角落（异见之窗寻找反常识信息源、追问光锥连续追问三次为什么每追问一次深入一层、认知书写台把认知写下来写的价值在于写这个动作本身、碰撞之镜切换到羁绊之厅某人视角看同一件事或手动输入“如果换做某某会怎么看”）。
- **素镜 · 行为与语言的底层翻译**：释光阁墙上的一面镜子。把一句话/一个行为/一个冲动放上去翻译成几种可能的“底下真正想要的东西”。翻译路径包括情绪翻译、行为翻译、冲动翻译、关系翻译。有追问机制（点某条翻译继续往下追，每追一层字往深处沉一层）。底层光区追到底时看到最简单的话。翻译记录可保存为“底层觉察”关联蜕变回廊。用户随时可删除翻译记录可设置不保留。
- **殿堂辞典**：思绪书房里一本活字典。每个词条两层内容：客观释义（官方定义暖金色光点）和用户主观理解（用户自己写柔绿色光点）。两者同页左右并置，中间极淡分隔光丝。偏见浮现场：分隔光丝根据两者差异度变化——差异越大光丝越亮，差异越小光丝越柔和几乎看不见。用户可创建自定义词条，可修改主观理解。主观理解演变在词条下方按时间排列。查完就合上，辞典不主动跳出来解释。

### 身体与情绪类

- **情绪花房**：情绪记录以花朵呈现。不同颜色形态对应不同情绪。长时间情绪低落时花房自动变暗变暖。
- **安全岛**：全暗、极静、只有呼吸引导。在任何界面连续快速点击载体五次（三秒内完成）一键沉入，整个屏幕从边缘缓缓暗下去几秒内完全沉入最深的墨色。所有功能暂停，所有房间入口关闭。进入保护机制（三秒内完成五次点击，超时归零不反馈）。退出时长按载体三秒，屏幕缓缓变亮回到进入前界面。安全岛内可做三件事：呼吸（载体光晕以呼吸节奏扩大缩小）、握着载体（触碰光晕变暖脉动与心率同步）、释放（角落唤出半透明流体便签写或画后自动消散不留痕迹除非主动选择保留）。退出时不记录停留时长，只在时间长廊生成一枚极小的几乎不可见的暗色光点。
- **身体温室**：睡眠、运动、饮食、生理周期植物化呈现。状态好时枝繁叶茂，疲惫时安静休眠。数据回流让植物自动生长。运动记录让植物在每次运动后短暂亮起。连续夜班叶片微微卷曲色泽偏暗。
- **藏象阁（三层结构）**：身体层（中医经典、子午流注环形时间图标注十二时辰对应经络脏腑、五运六气、体质自察、症状日志关联，本地AI基于古籍做轻量关联每一条明确标注“基于古籍记载仅供参考不构成医学诊断”）。感知层·问境角落（塔罗、八字排盘、六爻起卦、梅花易数、一掌经，只感知趋势不预测结果，只提供镜鉴不显示剧本，每次问境生成记录挂那天时间线）。护持层·藏经角落（经文阅读、能量音乐：颂钵/古琴/尺八、持诵：光珠计数器每念一声亮一颗、静坐引导：无语音引导只有介质极缓呼吸。不是宗教修行指导是自我护持和能量提升）。
- **动律之间 · 运动记录空间**：记录运动完整体验。和谁运动（关联羁绊之厅人物卡片，长期共同运动形成共同运动轨迹）、在哪里运动（自动定位或手动标记，关联地图室形成运动足迹图：跑道淡绿光轨/泳池水纹光点/山三角光点）、做什么运动（自定义类型，可填数据也可只写一句话）、感觉怎么样（关联情绪记录和身体数据）。运动时刻标记（第一次五公里/第一次全马/学会自由泳/和朋友登顶）自动成为时间长廊高亮标记关联蜕变回廊。与身体温室联动（每次运动后植物短暂亮起，频繁运动枝繁叶茂，长时间不运动植物缓慢休眠——不是警告只是呈现）。

### 关系与成长类

- **羁绊之厅 · 家脉体系**：人物关系图谱，每个人一张有质感的画框。画框边缘纹理代表关系亲密度（亲密温暖光泽/很久没联系极薄灰雾/逝去极淡银色光边）。家脉全图按世代分层（祖辈上层、你和同辈中层、子辈下层）。祖辈·根脉卡（深色温润如老树根，基础档案、健康与照护、相处记录、传承之物以小型光点挂在卡片边缘，已故者忌日关联岁时阁每年那天的光提前三天微亮，可留一段话/一封录音/一封信封存在卡片深处需额外确认打开）。伴侣·连理枝（连线两条光丝交缠成麻花状，上面关键节点锚点：相识/确定关系/同居/结婚/重大波折/和解，相处日志极简记录，关系状态镜自动汇总近期相处状态，对方重要日期关联逐日心锚和岁时阁）。同辈·手足枝（卡片边缘柔和纹理，共同成长记忆以时间锚点挂在卡片上，亲密度随时间自然波动反映在光丝粗细上）。子辈·新芽卡（随年龄自动变颜色：婴儿期奶白/幼儿期嫩绿/少年期淡青/成年后稳定暖色。婴儿期记录喂养、睡眠、健康、里程碑瞬间、日常观察。养育状态自察。特殊时刻殿堂自动生成纪念结晶。十八岁后可设“成长封存”）。共同运动展示区（共同运动以时间线形式排列）。重大事件（挂在人物卡片上的时间锚点：母亲诞辰、结婚视频、重要告别，每枚锚点光晶大小代表重要程度颜色代表事件类型）。亲人数据最高隐私级别和保险库同级。
- **蜕变回廊**：记录“我为什么变了、怎么变的”。每条蜕变是一枚蛹形光点（大小代表深度，纹理代表方向，透明度代表完成度）。包含蜕变前状态、蜕变后状态、驱动力（为一个人/走出困境/为目标/回应痛苦/觉醒）、关键转折点、蜕变过程、关联资源。中断的蜕变不被标记为失败，光茧保持半透明安静待在回廊。驱动力可以改变（最初为某个人改变，后来那个人不在了但改变还在继续）。
- **根脉之庭**：溯源树——根系原生土壤（家庭/故乡/童年），树干成长历程（时代背景/教育/迁移），枝桠分化与选择（价值观演化/信念锚点/被谁影响过/读过的书如何塑造）。在日常回溯中慢慢长出来。某天在时间长廊看到几年前一段话忽然意识到来源于更早之前父亲一句话——走进根脉之庭记录下那句话关联到那天的笔记。

### 工作与劳动类

- **更漏 · 这一日（工作记录空间）**：记录为了生活付出的所有时间。更漏光仪环形时间装置（外环24小时，内环当前状态，常规班次暖金色光弧，夜班深蓝色，加班暗红色）。工作类型（常规班次可创建循环模板、倒夜班跨午夜自动处理、加班可设费率、待命与通勤用户自建）。工时年轮图（树的横截面，每圈年轮代表一个月，宽度代表时长，颜色代表夜班比例）。工资记录（发工资那天手札自动浮现暖金色光点，用户可写一句话）。加班后极简标记（身体感受：眼睛酸/肩膀硬/腰疼/还好，情绪状态：累/焦虑/麻木/平静/踏实）。夜班特别设计（载体光晕自动偏暗偏暖，时间长廊深蓝色细线）。休息日灰色细线标记。关联保险库房间、身体温室、蜕变回廊。
- **工痕 · 工作的身体印记**：身体地图标注不同工作类型对身体的磨损（长期伏案颈部、长期站立膝盖、倒夜班睡眠节律、高强度加班免疫力）。数据来自用户手动记录症状日志+身体温室自动关联+更漏工作记录。本地AI自动关联。只是镜子照出关联，不是系统警告。用户自己看到自己决定要不要调整。
- **劳酬 · 工作的价值回报**：安放工作换来的所有回报。工资收入自动关联保险库房间。福利、奖金。用户对工作的价值评估（不只是钱，还有成长、认可、意义感、人际关系）。每份工作结束时自动生成工作生涯总结。关联蜕变回廊、关联身体地图。
- **匠庐 · 工作成果与作品集**：安放用户在工作中产出的所有成果（完成的项目、写的报告、做的设计、解决的难题、获得的表彰）。每个成果是一枚小型光晶附照片/描述/完成时间/心情。光晶按时间排列形成职业生涯成果时间线。阅览殿里可看到整个职业生涯成果全景。幕僚关注：伯言在重要项目完成后放特别亮光晶。
- **业脉 · 工作关系网络**：工作中认识的人（同事、领导、下属、客户、导师、竞争对手）。自动关联羁绊之厅人物卡片，以“职业关系”维度重新排列。业脉网络随时间变化（有些人离开但光丝还在，有些人最近频繁互动光丝变粗）。用户考虑职业变动时可来此看到职业关系网全貌。
- **行囊 · 工作技能与工具**：安放工作中使用的技能和工具。技能（掌握哪些、熟练程度、正在学习、已经过时）。工具（软件、硬件、方法论）。技能和工具之间有连接。和经略阁知识体系打通——经略阁知识节点关联行囊技能节点。
- **息壤 · 工作间歇与休假**：安放工作中喘息的时间（午休、茶歇、短暂摸鱼、年假、病假）。更漏班次之间自动生成间歇记录。午休时在庭院坐一会儿、茶歇时和同事聊天、年假去了哪里。时间长廊里不仅是暗红色加班线，还有间歇空白光点——工作中被允许的呼吸。

### 计划与自动化类

- **逐日心锚**：日常计划与焦虑安放系统。锚点池（悬浮半透明光池，脑子里所有悬着的事倒进去不用分类排序）。锚点地图（把光点拖到时间轴上，点线面区四级尺度：点是一个具体行动，线是重复性脉络，面是有目标的整体，区是人生领域用户自建命名调色）。今日手札（只显示今天锚定的事按区域排列）。优先级（指尖在光钉上划一下切换：必锚变亮/可锚变柔和/浮锚变半透明）。完成（指尖轻触光钉变光晶沉入时间长廊）。未完成（不标记失败，自动漂移到明天或放回池子，反复拖延光点慢慢变淡）。锚点池永远有一些未安放的光点——人生永远有未完成的事这是常态。
- **留光阁 · 计划与成长的生长空间**：不催执行不评分。愿景层（穹顶极小的遥远光点像星座排列，随时间缓慢演化）。目标层（三年内具体方向，悬浮光球可展开看分解进度，目标间可有连线标注关联或冲突）。计划层（具体行动计划直接连接逐日心锚自动生成锚点）。计划生长状态（种子→发芽→持续生长植物叶片随执行频率繁茂稀疏→开花完成时开特别亮光晶自动进入蜕变回廊→休眠主动搁置变半透明灰色→沉入旧梦潭主动放弃沉入潭底可能再浮起）。职业发展区（技能树光点大小代表熟练度颜色代表状态点间连线标注基础和组合、行业地图经略阁知识自动投射、成长阶梯晋升/跳槽/转行等成长节点）。经济与财富规划区（储蓄目标光柱呈现，关联保险库房间，自动分解为月度计划）。健康与身体规划区（关联身体温室，完成计划对应植物开花，搁置植物进入休眠）。学习与认知规划区（知识树形式呈现，关联默渊）。幕僚与计划互动（设定目标时追风凑过来、达成时所有幕僚在入口庆祝）。
- **自律工坊**：本地自动化引擎。可视化拖拽编排（触发条件光点：手动/定时/殿堂事件/应用事件/设备状态/组合触发，原子操作光点：屏幕/应用/殿堂内/系统/条件逻辑/数据回流/打开书签）。支持条件判断（绿色是/灰色否）、循环（闭合光环）、变量、子流程调用。运行时悬浮窗（半透明圆环展开竖向卡片，暂停左划/停止右划到底/跳过上划/调参双指拉开/详情长按翻转）。三指三连点全局紧急终止。演员系统（每个流程有视觉化身：光点精灵/齿轮小人/翻页书虫/专注之眼/小信使光鸟，行为映射流程状态，可自定义）。多线程并行，线程间隔离，资源软上限。执行精度毫秒级，自动微调坐标模拟真人操作抖动。失败策略（跳过/重试N次/暂停通知/终止）。自动检测改进（连续三次同步骤出问题自动浮现建议光点，本地AI分析执行日志）。流程可分享.flow文件，社区有模板专区。安全红线（绝对本地、绝对不替用户决定、绝对可终止、坐标选择器模糊预览保护隐私）。

### 收藏与休闲类

- **逸趣阁 · 游戏与收藏展厅**：安放所有“玩”的痕迹。可切换视觉主题（街机厅主题/阁楼玩具间/极简展廊）。游戏区（游戏档案记录平台/类型/总时长、高分时刻以光质画框挂在卡片旁、游戏时长时间轴、和朋友一起玩的游戏关联羁绊之厅）。玩具区（童年和成年后实体玩具，每件照片一句话，已丢失的以半透明光点存在，按年龄排列形成玩具成长史，分享与传承关联羁绊之厅）。模型与手办区（收藏档案：系列/入手时间/价格可选/限量编号/展示位置，制作档案：制作周期/过程记录/定妆照）。其他收藏区（自定义展架，放唱片、邮票、硬币、贝壳、门票等任何想收藏的东西）。

### 管家与综合类

- **知微阁 · 私人管家系统**：知微珠（悬浮灯下的微光球体，几乎静止只在用户靠近时缓缓旋转，是被动回答的管家，跨所有房间进行深度关联）。自然语言提问（“我最近状态怎么样”“我该注意什么”“我和XX关系最近是不是有问题”“我现在该做什么”）。不主动给建议只是呈现关联。年度对话（信的格式手写体极简回顾一年关键变化，每条有具体数据来源可钻取到对应房间，用户可回信给明年自己封装为时间胶囊）。定音锤（用户受到巨大冲击自我认知被动摇时唤出，调取四幕证据：做过的事/对待别人的方式/如何成长/内心真正的声音，光幕展开呈现后收拢变回知微珠。不评价不反驳只是呈现。启动记录最高隐私。殿堂永远不记录攻击者任何信息）。
- **众生象 · 贯穿所有房间的镜子**：没有固定位置（时间长廊墙上/情绪花房某朵花后/羁绊之厅关系网络中央/阅览殿书扉页/字镜阁穹顶边缘）。不显示容貌，显示所有痕迹聚合——由无数光点组成的流动人像轮廓。光点来自时间结晶、情绪标记、羁绊之厅关系纹理、字镜阁字频墨色、释光阁认知光图、动律之间运动记录、更漏工作记录。时间长廊对比三年前和现在镜像。羁绊之厅不同人面前不同镜像——不是“不同的自己”是同一自己在不同关系真实显像，镜像间有光丝相连。触碰镜面荡开涟漪所有光点微亮然后恢复：“我看到了我接受了这些全都是我”。只是映照不评判不分析不建议。

### 其他功能房间

- **地图室**：去过的地方、走过的路、人生节点路标。标注的是你和那个地方的关系。运动足迹也在这里（跑道淡绿光轨/泳池水纹光点/山三角光点）。家人地理形成家族迁徙图。
- **成长庭院**：种子养成、习惯追踪、人生罗盘。
- **未完成花园**：搁置的种子、开了头没继续的书、写了一半的笔记。光线黄昏柔和，介质流动更慢。被中断的笔记以“未完”形态停留在中断处，末尾有极淡的像笔迹未干的墨痕。可以拿起继续也可以放下继续待着。一本书读到一半，书页边缘会留下轻微的折痕标记。
- **守护室**：安全相关功能统一入口。守门光盾平时完全隐形——只有开启安全功能时才浮现一枚极淡的半透明光盾。有风险时变成暖金色轻轻脉动，点击展开当前安全信息和紧急选项。所有核验记录归档为安静的“识破记录册”。
- **保险库房间**：最高加密等级的财产档案。需要密码或三指按特定节奏轻敲光盾才能进入。老式银行保险库风格——中央木桌上放着皮质封面账本（手写体字迹），老式天平两端放着代表收入与支出的光点，铜质指南针指向财务健康度（异常时轻微晃动）。财产数据最高加密等级。
- **书签与入口架**：从浏览器分享网页，在殿堂入口架生成微型小门。有标题、有图标、有保存时间。可选“保存为书签”或“保存并摘录”（同时生成知识结晶放进思绪书房）。小门可分组、排序、自定义样式。保存书签的行为在时间线上生成微型门形光点。
- **数据回流系统**：外部数据自动沉淀回殿堂。三种实现路径（系统级数据接口、健康数据联动、应用使用统计）。只捕获元数据（时长、次数、时间、进度），绝不捕获内容本身。回流数据触发自动化流程，汇入生命节律图谱，进入记忆殿堂对应房间以有温度形态生长。逐类授权管理，数据回流日志全部本地可查可清，一键熔断可停止所有回流。


## 树叶 · 具体功能与交互细节（各房间内展开）


### 交互细节

- 渐进式发现：萤火虫光点引导（新用户画布上有几颗极淡光点，停在长按、滑动、角落位置），发现即消失。功能发现机制在“殿堂探索”入口主动查看未发现功能，用户可标记“这个我不需要”。交互演示模式可随时进入看到所有当前可用手势和操作路径。
- 交互原子化配置：长按→唤出星盘/快捷菜单/开始计时/不做任何事；画圈→开始计时/打开笔记/进入安全岛/自定义；画叉→暂停/结束计时/关闭面板/自定义；画波浪线→快速记录/打开语音/自定义；双指长按→语音指令/截图/自定义；三指画圆→紧急SOS/切换载体/自定义；边缘滑动→切换房间/打开插件库/返回主界面/自定义。保存为交互风格包可导出分享。
- 手感调律：手指沿光轨抚摸，顺时针对应快/脆，逆时针对应慢/糯。可调节星盘展开坍缩时长、缓动曲线、磁吸强度、光轨宽度、粒子数量、轨迹光痕粗细/消散速度、结晶生长时长/光晕强度/沉降速度、面板翻卷速度、全局拖拽阻尼/回弹系数/惯性滑动衰减。
- 主界面在场感：介质从“静态呼吸”切换到“有观察者在场”的节奏。用户离开后介质逐渐回归平静。每次完成专注、写下笔记、完成引渡，介质以极慢幅度进行一次呼吸。删除或封存记录时介质在周围形成短暂“空位”然后缓慢弥合。
- 照片点击交互：照片全屏展开为时光切片，周围浮现关联信息光点（时间光点、地点光点、人物光点、情绪光点、关联记忆光点、故事光点）。时光回溯按钮让殿堂短暂回到拍摄时的环境参数。隐私模式用双指轻触仅显示照片本身。长按照片可封存或释放。

### 安全守护

- 数据安全：本地私有存储、端侧加密（可选）、插件三级权限沙箱（L0只读/L1部分/L2完全，沙箱隔离可逐项开关一键撤销）、多级备份（实时增量+多版本历史+时间琥珀回滚保留最近七天完整备份可回滚任意一天）、崩溃自恢复（下次启动自动检测异常退出从最近备份恢复以水面涟漪自愈动画告知）、数据自毁可选（连续输错N次密码自动销毁本地数据）。
- 财产安全：反诈骗联动（对接国家反诈中心官方能力，用户复制可疑内容双指敲击画布三下唤出核验窗口，结果以光色反馈：安全安静蓝光/可疑柔和暖金/高危深邃暗红，不弹窗不警告，所有核验记录归档为识破记录册）、数字人民币对接、财产全景视图、异常支出提醒、防诈骗转账二次确认。
- 人身安全：一键SOS（连续按电源键N次或三指快速画封闭圆——画布中央浮现质地厚重触感温暖的守护石，上面三个清晰光点：SOS、假来电、报平安）、行程守护（开启后玉珠旁多出极小的伴飞守护星，到达后轻轻闪烁消失，偏离路线或长时间停留则变暖金色触碰玉珠）、定时报平安、健康数据异常提醒、跌倒检测。所有位置共享消息发送只有用户主动触发才发生平时绝对不追踪位置。
- 心理安全：情绪持续低落时门口出现极薄对折的信（信封无字，打开后只有一行手写体“最近好像有点辛苦，这里有张地图”+通往安全岛微型光路图+全国心理援助热线号码）。明确自伤风险时殿堂背景光自动更柔和更暗如被深蓝色天鹅绒包裹，正中央浮现唯一不会消失的温暖光笺（“如果你现在很难受不用说话不用解释点一下这里会有人陪着你”+热线号码）。点击光笺后展开热线号码+两个选项“现在拨打”或“再坐一会儿”——两个都是有效选择没有暗示哪个更好。选“再坐一会儿”光笺缩回原来大小依然存在触手可及。拨打了热线殿堂只记录“有一次求助行为”时间戳不记录通话内容/号码/对话，用户可随时清除这条记录。光笺被触发但电话未接通记录一次“触碰但未完成”不生成通知不留标记。任何心理安全交互中用户可随时退出。绝对不报警、不泄露、不联系任何人。

### 数据主权

- 个人数据档案馆：所有散落各平台数据最终归档地。数据引渡仪式（外部文件拖入画布碎片如流星滑入，引力场荡开涟漪，用户亲手牵引到对应象限，碎片飞向时间线各自位置）。可导入聊天记录、语音录音、笔记文字、照片视频、健康运动数据。绝对本地、绝对只读、尊重隐私版权、用户完全掌控。
- 跨端接续：不同设备“同一个殿堂两种存在方式”，通过本地网络加密引渡用户主动触发不是自动后台。可引渡全部或指定时间范围。云端备份作为可选保险加密打包存用户自己云端空间默认关闭。
- 数据导出与跨容器存活：导出不只是JSON压缩包而是可重新被看见的时间线。结晶情感颜色、时间上下文、关联关系以可读方式保留。允许在另一个容器工具中继续生长。
- 数据追溯权：追溯任何数据来源和变化历史。一枚结晶从生成到现在被哪些幕僚翻阅过、被哪些外部数据关联过、用户自己修改过几次——呈现为极淡光丝。用户可随时删除任何数据及其全部历史，删除不可逆。
- 遗忘的权利：数据随时间自然老化（颜色变浅、边缘模糊、位置沉降）。主动封存（归档旧日档案馆不主动出现在时间线）。主动释放（像树叶落入泥土痕迹仍留画布纹理但不再以独立形态存在）。冬眠（记录不出现不活跃不参与关联但始终存在只能由用户主动解除）。用户可随时唤醒老数据让它重新变亮回到当前视野。
- 殿堂的退场：连续几个月未打开自动进入沉睡（不再加载背景资源和动效只保留数据）。手动封存殿堂（进入不可编辑但可查看状态可随时解封）。暂时离开（殿堂进入“不知道你会不会回来”状态灯光更安静介质更缓慢，几个月几年后打开以“从未离开过”方式迎接没有欢迎回来没有“你已离开X天”）。殿堂遗嘱（指定数字继承人：人/邮箱/公钥地址，可选继承哪些部分，可选殿堂自行关闭永不开启。无人继承时进入永恒守护——数据最后一次加密打包安静躺本地存储灯还亮但不会再有人进来）。
- 世界的传承：封存时幕僚进入沉睡状态入口多出几枚缓慢脉动光点。释放时镜我和幕僚变成一颗颗种子放在入口光盒用户可带走。传给数字继承人时幕僚记得旧主人——光晕里保留一层极淡属于旧主人的颜色。

### 社区与生态

- 社区：安静存在非社交平台，没有排行榜/热门推荐/点赞数。用户匿名分享风格包、环境预设、载体形象、交互配置、房间模板、自动化流程、幕僚性格模板。分享时不包含任何个人数据。
- 访客模式：用户可邀请信任的人以访客身份进入殿堂，访客可见区域由用户逐项设定。幕僚自动切换到访客模式。用户可预览访客会看到什么再正式开启。
- 对外输出：时间之书（将某段时光导出为有封面有章节有叙事的书）、知识体系导出（思维导图或知识图谱）、游戏史/玩具史页面分享、与幕僚对话记录整理为文本。
- 世界间的互通：两个用户都愿意时可建立极简互通桥。不是数据共享是主动分享特定内容。幕僚偶尔感知到另一个世界里同伴存在。用户随时可关闭。
- 插件生态：三级分级（官方认证/社区精选/实验插件），沙箱隔离，权限透明声明，可逐项开关一键撤销，房间模板安装前沙盒预览，社区举报机制极简有效。
- 商业红线：可以赚风格包、交互引擎包、场景包、高级插件、企业定制、用户打赏。绝对不赚卖数据、广告、订阅制绑架核心功能、诱导消费、贩卖焦虑。
- 向善的生态：所有官方和社区内容不得含推送通知、弹窗广告、诱导打卡、制造焦虑、排行榜攀比、社交压力。所有AI和自动化行为不得对用户进行任何形式评判、催促、贬低。用户数据是用户自己的不上传不云端。开源架构和接口用户可自行查看修改本地数据结构。


## 落地顺序（树的生长顺序）

1. **树根**：宪法前四条 + 弹性宪法定义
2. **主干第一层**：底层运行底座 + 共鸣协议层
3. **主干第二层**：可插拔引擎层（交互引擎 + AI引擎 + 呈现引擎）
4. **内核（最小可运行单元）**：引力场画布 + 介质呼吸 + 基础计时 + 时间结晶 + 插件管理器 + 风格包加载器 + 本地存储 + 默认玉珠载体
5. **主干第三层**：插件化调度层 + 功能插件生态层 + 殿堂装修工坊 + 用户数据资产层 + 殿堂的触角
6. **主要枝干**：幕僚统一体系 → 家与场景系统 → 环境与氛围系统（世界的生命）
7. **次级枝干（按类别分批）**：
   - 第一批（时间与记忆）：时间长廊 + 阅览殿 + 字镜阁 + 梦乡小筑 + 岁时阁 + 平行世界
   - 第二批（认知与思维）：思绪书房 + 经略阁 + 释光阁 + 素镜 + 殿堂辞典
   - 第三批（身体与情绪）：情绪花房 + 安全岛 + 身体温室 + 藏象阁 + 动律之间
   - 第四批（关系与成长）：羁绊之厅 + 蜕变回廊 + 根脉之庭
   - 第五批（工作与劳动）：更漏 + 工痕 + 劳酬 + 匠庐 + 业脉 + 行囊 + 息壤
   - 第六批（计划与自动化）：逐日心锚 + 留光阁 + 自律工坊
   - 第七批（收藏与休闲）：逸趣阁
   - 第八批（管家与综合）：知微阁 + 众生象
   - 第九批（其他）：地图室 + 成长庭院 + 未完成花园 + 守护室 + 保险库房间 + 书签与入口架 + 数据回流系统
8. **树叶**：所有交互细节、安全守护细节、数据主权细节、社区生态细节在对应房间中同步落地
9. **生态开放**：插件开发API + 社区市场 + 完全开源

这就是按照树的形状组织起来的完整蓝图。从树根到主干，从主要枝干到次级枝干，再到每一片树叶。你从树根开始，逐步向上构建，每一个阶段都是完整的、可用的产品。树不会一次性长成，但它知道自己最终的样子。你现在可以从主干开始，一步一步让它生长出来。
