# CAB 分阶段推进设计

## 一、概述

本设计文档规划了从当前状态（共鸣协议层 + 输出管理 + 时间线索引已完成）推进到蓝图完整实现的路线。采用 **C → A → B** 顺序：

- **C**：按空间顺序，从家→工作区→世界空间，逐块完善房间功能
- **A**：深化 P1 功能模块，提升已有模块的交互深度
- **B**：建设新模块，补齐蓝图关键缺失

---

## 二、C 阶段：按空间顺序完善

### C1：家空间完善（当前阶段）

**目标**：将 HomeSpace 从导航仪表板改造为可浏览的居住空间。

**蓝图对家的定义**：9 个内部房间——

| 房间 | 当前状态 | 需添加 |
|------|---------|-------|
| 玄关 | ⚠️ 隐含存在 | 走廊氛围 + 入口过渡 |
| 衣帽间 | ❌ 缺失 | 衣物展示区 + 记忆关联 |
| 厨房 | ⚠️ 隐含存在 | 烹饪记录 + 食材管理 |
| 餐厅 | ❌ 缺失 | 餐桌 + 深夜食堂意象 |
| 卧室 | ⚠️ 隐含存在 | 睡眠数据关联 + 夜灯 |
| 浴室 | ❌ 缺失 | 放松记录 + 环境音 |
| 客厅 | ❌ 缺失 | 社交 + 访客模式核心 |
| 书房 | ⚠️ 隐含存在 | 知识关联 + 书架 |
| 庭院 | ⚠️ 隐含存在 | 植物生长 + 放松 |

**实现方案**：

1. **场景切换栏** — HomeSpace 顶部添加 9 个房间标签栏，点击切换当前展示的房间视图
2. **缺失房间组件** — 衣帽间、餐厅、浴室、客厅各自实现 `RoomScene*.vue` 组件，包含：
   - 氛围描述文字（引用蓝图原文）
   - 动态氛围光色渐变
   - 关联数据展示（如浴室→身体温室数据、客厅→访客模式）
   - 功能入口（如餐厅→深夜食堂、客厅→羁绊之厅）
3. **氛围动态系统** — 每个房间切换时，背景光色/氛围参数通过 CSS 变量渐变
   - 玄关：暖黄 2700K
   - 衣帽间：中性白 4000K
   - 厨房：暖白 3500K
   - 餐厅：暖橙 3000K
   - 卧室：柔和琥珀 2200K
   - 浴室：水雾蓝 5000K
   - 客厅：暖白 3500K
   - 书房：暖白 4000K
   - 庭院：自然光 5000K
4. **场景编辑入口** — 每个房间卡片预留编辑按钮，对接未来的装修工坊

**文件变更**：
- `src/views/HomeSpace.vue` — 重构主视图，添加场景切换逻辑
- `src/views/HomeSpaceEntrance.vue` — 玄关视图（新建）
- `src/views/RoomSceneWardrobe.vue` — 衣帽间视图（新建）
- `src/views/RoomSceneKitchen.vue` — 厨房视图（新建）
- `src/views/RoomSceneDining.vue` — 餐厅视图（新建）
- `src/views/RoomSceneBedroom.vue` — 卧室视图（新建）
- `src/views/RoomSceneBath.vue` — 浴室视图（新建）
- `src/views/RoomSceneLiving.vue` — 客厅视图（新建）
- `src/views/RoomSceneStudy.vue` — 书房视图（新建）
- `src/views/RoomSceneCourtyard.vue` — 庭院视图（新建）
- `src/composables/useRoomAtmosphere.ts` — 氛围管理 composable（新建）
- `src/views/__tests__/HomeSpace.test.ts` — 更新测试
- `src/views/__tests__/RoomScene*.test.ts` — 新增测试文件（每个房间 3-5 个测试）

## 三、A 阶段：核心功能深度完善

### A1：情绪花房（模块四）

**当前**：基础记录 CRUD + 情绪类型管理
**需加**：
- 花朵品种映射（每种情绪类型对应一种花的品种和颜色）
- 花房环境系统（温度/湿度/光照参数影响花朵状态）
- 空间布局（花朵在花房中的位置排列）
- LOD 降级（花朵数量多时自动降级渲染精度）

### A2：逐日心锚（模块五）

**当前**：锚点 CRUD + 优先级（must/optional/can）
**需加**：
- 锚点池系统（锚点复用/推荐/过期清理）
- 手札日记（锚点关联的日记记录）
- 四种时间尺度（日/周/月/年视图）
- 光丝串联（完成锚点间形成光丝路径）

### A3：守护室（模块六）

**当前**：基础界面
**需加**：
- 治理台四页（数据治理/存储治理/权限治理/隐私治理）
- 安全台四令牌（数据安全/网络安全/设备安全/应急安全）
- 健康台（身体数据总览）
- 心理安全（光笺机制 + 热线接入）

### A4：镜我——幕僚系统（模块七）

**当前**：对话系统 + 幕僚基础调度
**需加**：
- 定音锤四幕（第一幕·你做过的事 / 第二幕·你走过的路 / 第三幕·你学会的 / 第四幕·你在成为的）
- 年度对话（年终回顾叙事）
- 幕僚调度（任务感知 + 分身调度 + 进度展示）

### A5：留光阁（模块八）

**当前**：基础目标管理
**需加**：
- 愿景区（长期愿景设定）
- 计划区（目标拆解为计划）
- 旧梦潭（未完成目标归档）
- 专项规划区（跨目标专项规划）

### A6：思绪书房（模块九）

**当前**：笔记 CRUD
**需加**：
- 书籍导入（外部书籍导入书架）
- 聊天信笺（关联 IM 聊天记录）
- 通话磁带（关联通话记录）
- 网页摘录（网页笔记摘录）
- 知识年轮（知识积累的可视化年轮）

## 四、B 阶段：新模块建设

### B1：经略阁（模块十）

**蓝图定义**：知识图谱引擎，七种展示方式（星图/地图/时间线/树状/网络/画廊/书架），AI 管家辅助。

**实现要点**：
- 知识节点（概念/来源/关联）的 CRUD
- 节点间关系定义（相关/因果/隶属/对比）
- 至少一种展示方式（星图，其他后续扩展）
- 与思绪书房（模块九）的联动

### B2：应用空间自定义体系（模块十四·五）

**蓝图定义**：七维配置引擎，8 个预置模板，用户可自定义空间结构和功能组合。

**实现要点**：
- 配置引擎（空间结构/功能模块/交互方式/视觉风格/数据关联/权限/场景）
- 至少 3 个预置模板（标准/极简/禅意）
- 用户自定义空间创建流程

### B3：装修工坊（第六层）

**蓝图定义**：场景编辑器 + 载体编辑器 + 环境编辑器 + 宪法编辑器。

**实现要点**：
- 场景编辑器入口（从 C1 预留的编辑按钮接入）
- 基础场景参数调整（光色/氛围/背景）
- 载体编辑器独立界面

## 五、优先顺序与依赖关系

```
C1（家空间）        → 无依赖，立即开始
  ↓
C2（工作区）        → 依赖 C1 的氛围系统框架
  ↓
C3（世界空间）      → 依赖 C2 的增强模式
  ↓
A1-A6（P1模块）     → 部分依赖 C3 的房间改造
  ↓
B1-B3（新模块）     → 依赖前序阶段框架成熟
```
