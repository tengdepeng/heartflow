# 修复 B：宅院 3D 漫游自定义入口（宪法「不写死」）

**日期**：2026-08-25
**根因**（见 `docs/缺口查缺报告-宅院壳2D3D-2026-08-24.md`）：3D 宅院壳的 `OrbitControls` 参数（`rotateSpeed`/`zoomSpeed`/`min·maxDistance`/`orbitMode`/俯仰限位）全部硬编码在 `courtyard-3d.ts` 内，且 **没有任何用户 UI 入口**——用户无法调节漫游手感，违背宪法第 2 条「超级自定义 / 外观与参数本地保存、不写死」。2D 宅院同样无拖拽缩放入口。

## 修法
建立「UI 入口 → config 持久化 → 3D 壳实时消费」的完整链路，全程不写死：

- `types/index.ts`：`WorldShellConfig.shellConfig` 增 `courtyard3d?: { rotateSpeed?; zoomSpeed?; orbitMode?: 'first-person'|'orbit'; minDistance?; maxDistance? }`。
- `engine/storage/core.ts`：默认 `shellConfig.courtyard3d = { rotateSpeed:0.45, zoomSpeed:0.6, orbitMode:'first-person', minDistance:8, maxDistance:60 }`（仅作回退默认值，用户覆盖优先）。
- `modules/world-shell/courtyard-3d.ts`：重构 `applyControlConfig()` 与 `buildControls()`——
  - 不再内联硬编码 polarAngle/min·maxDistance/rotateSpeed/zoomSpeed；改为读 `config.courtyard3d`，缺省回退内置默认；
  - `orbitMode`：`'first-person'` → 禁平移 + 限俯仰（π·0.36 ~ π·0.62，拖拽=环视）；`'orbit'` → 放开限位 + 允许平移（自由绕飞）；
  - `updateContext` 在 intensity / sanctuary / config 变化时均调用 `applyControlConfig()`。
- `views/DecorationWorkshop.vue`（换境 · 世界壳）：仅当 `activeShell==='courtyard'` 渲染「宅院 3D 漫游」面板——
  - 漫游方式分段按钮（第一人称环视 / 自由绕飞）；
  - 旋转灵敏度 / 缩放灵敏度 / 最近距离 / 最远距离 四个 range；
  - 绑定 `c3d`（computed，铺默认）与 `setCourtyard3d(key,value)` → `configStore.updateShellConfig({ courtyard3d })`；
  - CSS 沿用 accent 设计语言（`.shell-3d-tweaks`/`.tweak-row`/`.seg`/`.seg-btn`/range 滑块）。
- `modules/canvas/CanvasRoom.vue`：新增 `courtyard3d` 深度 watch——参数变化（不重建壳）实时 `updateContext({ config })`，3D 漫游手感即时生效。
- `courtyard-3d.ts` 增 **dev-only 探针**（`import.meta.env.DEV` 包裹，生产构建剔除）：把 `OrbitControls` 暴露到 `window.__courtyard3dControls`，仅供真机验证脚本读取实时参数，零生产足迹。

## 真机验证（独立 Edge + CDP 9222，复用 vite :1001，hash 路由）
路由为 hash 模式（`/#/`），导航须用 `Page.navigate` 到 `http://127.0.0.1:1001/#/decoration-workshop`。

1. **面板渲染**：`document.querySelector('.shell-3d-tweaks')` 存在，标题「宅院 3D 漫游」，2 个分段按钮（第一人称环视/自由绕飞）+ 4 个滑块（旋转 0.05–1.5 / 缩放 0.1–2 / 最近 4–20 / 最远 40–100）。
2. **交互写入本地 config（宪法「本地保存不写死」）**：点击「自由绕飞」+ 旋转灵敏度=1.2 + 缩放灵敏度=1.4 后，读 `localStorage['heartflow:storage']` → `worldShell.shellConfig.courtyard3d = { rotateSpeed:1.2, zoomSpeed:1.4, orbitMode:'orbit', minDistance:8, maxDistance:60 }` ✅。
3. **3D 壳实际消费（即时生效）**：回首页，3D 壳 remount 后读 `window.__courtyard3dControls`：
   - baseline（first-person）：`enablePan:false, minPolarAngle≈1.131, maxPolarAngle≈1.948, rotateSpeed:0.45`；
   - after（orbit + 用户值）：`enablePan:true, minPolarAngle:0, maxPolarAngle:π, rotateSpeed:1.2, zoomSpeed:1.4`；
   - → 漫游方式切换、灵敏度、缩放范围全部被 OrbitControls 真实采用 ✅。
4. `vue-tsc --noEmit` 0 错（heap 6144MB）。

**VERDICT：`PASS_B_ENTRY_PERSIST_CONSUME`**（面板渲染 + 本地持久化 + 3D 壳消费，三项全绿）。
