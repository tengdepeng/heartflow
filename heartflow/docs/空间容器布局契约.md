# 空间容器布局契约

> 本文件是「心流工坊 · 空间容器」前端布局的设计契约基线，由 2026-08-23 / 08-24 的混乱诊断与重设计评审沉淀而来。
> 目的：用一套统一契约收口四类视觉混乱（浮层叠放 / 内容排版 / 常驻元素跳动 / 视觉风格不统一）。
> 宪法硬约束：① 本地私有 ② 超级自定义（外观切换交用户本地保存，不写死；令牌层允许换肤）。

---

## 一、四层叠放架构（框架与内容分离）

| 层级 | 作用 | 技术方案 | 是否随世界壳换皮 |
|---|---|---|---|
| 最底层 · 视频/3D 背景 | 铺满屏幕，沉浸氛围 | `HomeBackgroundMedia` + `CanvasRoom`(世界壳) | 用户切换世界壳时替换 |
| 第二层 · 空间实体 | 玉珠、光点、房间轮廓、入口光门 | 世界壳 Canvas 2D 绘制（courtyard/stars） | 随世界壳变化 |
| 第三层 · 2D UI 覆盖层 | 计时器、玉珠对话、导航文字、功能入口 | Vue 组件 + CSS，固定屏位 | **不随世界壳变化**（主题色跟随） |
| 最上层 · 交互层 | 鼠标拖拽视角、点击进入、滚轮缩放 | 透明命中层转发 + 点击射线检测 | 固定不变 |

空间递进（越往里越私密）：屏风(screen) → 前院(front-yard) → 正堂(hall) → 后院(back-yard) → 厢房(side-wing) → 角门(corner)。
数据层由 `engine/room-graph.ts` 的 `RoomSlot` 模型承载，与世界壳 `ZONES` 一一对应。

## 二、z 轴令牌层契约（收口"浮层叠放乱 + 常驻跳动"）

中心化令牌，定义在 `assets/design-tokens.css`，所有浮层消费对应 `var(--z-*)`，**数值不可手写散落**。

| 令牌 | 取值 | 承载层 | 说明 |
|---|---|---|---|
| `--z-base` | 0 | 世界壳 `CanvasRoom` | 背景层，不参与 UI 叠放 |
| `--z-ambient` | 1 | `ambient-layer` / `GlowOverlay` | 氛围光，消费全局 `--accent` |
| `--z-content` | 1 | `.main-content` 路由视图 | 卡片栅格统一令牌 |
| `--z-overlay` | 8 | （原门厅计时器层，已撤回） | 仅门厅态、居中屏风；**用户已明确不要门厅计时器** |
| `--z-jade` | 20 | `MirrorSelf` 玉珠 | 门厅屏侧 / 房间右下，锚点固定禁瞬移 |
| `--z-floating` | 90 | `FloatingNavBar` 液态栏 | 锚点恒定、显隐随路由 |
| `--z-modal` | 9999 | `Astrolabe` 星盘 | 独占模态遮罩 |

**关键约束**
- 世界壳 canvas 在 z:0，被 `.main-content`(z:1) 盖住 **收不到点击**。任何世界壳交互（如空间递进点击进入）**必须走 canvas 之上的透明命中层**（`.shell-hit-layer`，pointer-events:auto, z:1），由命中层转发坐标给 `courtyard.hitTest()`，再 `router.push(room.path)`。禁止把点击绑在 canvas 元素本身。
- **全屏 fixed 容器 + 内部 fixed 子元素 = z 逃逸陷阱**：子元素独立参与叠放且 `overflow:visible` 会逃逸容器 z 约束。内部定位元素应用 `absolute` 相对该容器（曾因此导致门厅计时器压住液态栏，已修/撤）。
- 新增任何浮层必须消费上述令牌，禁止新写裸 `z-index` 数字。

## 三、三态锚点契约（收口"常驻元素跳动"）

浮动 UI 层「世界壳无关」：不随壳换皮位移。

| 态 | 计时器层 | 玉珠(MirrorSelf) | 液态栏 |
|---|---|---|---|
| 宅院壳门厅态 | 已撤回（用户不要） | 锚定屏风屏侧（hallAnchor） | 左下/右下常驻 |
| 星辰壳门厅态 | 已撤回 | 经 `getEffectiveScreenRect()` fallback 或回右下 | 左下/右下常驻 |
| 房间态 | 更漏房间内（`ClepsydraRoom.vue`） | 回默认右下常驻位 | 左下/右下常驻 |

**契约就绪守卫**：`screenContract.ready === false` 时，依赖屏风契约的定位元素**不渲染**（非兜底位），杜绝首帧跳位。`getEffectiveScreenRect()` 是唯一取位来源（就绪且 rect>0 返真实，否则返视口中心兜底矩形）。

## 四、视觉令牌（收口"风格不统一"）

| 令牌 | 取值 | 说明 |
|---|---|---|
| `--accent` | `#d4af74`（默认暖琥珀，用户本地可换肤） | 同温层主调，所有浮层/光效消费 |
| `categoryColors` 同温层 | 暖琥珀辅色系（见 `theme/categoryColors.ts`） | 禁同温层外 hex |
| `--grid-cols` | `auto-fit minmax(240px,1fr)` | 统一替换 3 套旧栅格 |
| `--text-clamp` | `clamp(13px,1vw,15px)` | 长文本容器收束，弃 `overflow:ellipsis` 兜底 |

**lint 红线**：`eslint.config.js` 注册 `heartflow/no-offtone-hex`（error 级），扫描 `.ts` 中离调亮色 hex（蓝/紫/绿/冷色，套用 `LEGACY_CATEGORY_COLORS` 键集）。旧色走 `categoryColors` 迁移映射。
**已知未覆盖**：`.vue` 文件红线因缺 `vue-eslint-parser` 暂未启用，views 离调 hex 靠手动迁移，需独立排期补 `vue-eslint-parser`。
**Astrolabe / GlowOverlay**：改消费全局 `--accent`（GlowOverlay 冷蓝兜底已改 `var(--accent-rgb)`），不再自成一派。

## 五、空间递进交互契约（收口"一层皮"）

- `courtyard.ts`：`hitTest(x,y)` 先判房间墨点（半径 + 8px 容差）→ 返回 `{slot, roomPath, roomName, roomId}`；否则判 zone 矩形包含 → 返回 `{slot}`（上层 push 该 slot 首房）；画布外返回 null。`setHover(slot, roomId)` 驱动描金高亮 + 墨点放大 1.6×。
- `layoutHitTargets()` 在 mount/resize/updateContext(rooms) 时缓存 zone 矩形 + 墨点坐标，避免每帧重算。
- `CanvasRoom.vue`：透明命中层 `.shell-hit-layer`（z:1，结晶 z:2 仍可点）接收 click/pointermove → 坐标换算 → `hitTest` / `setHover` → `router.push`。仅 `courtyard + full` 模式启用（星辰壳暂未接）。
- `WorldShellRenderer` 接口 `hitTest` / `setHover` 为可选扩展，不影响未实现壳（星辰壳）。
