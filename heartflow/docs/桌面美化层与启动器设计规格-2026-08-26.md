## 0. 范围锁定（三项决策）

| 项 | 决策 |
|----|------|
| 平台 | **桌面优先**（Win/Mac Tauri2）。平板/手机列为后续，移动端深链能力届时启用。 |
| 美化层形态 | **透明常驻浮层**为容器 + **多元化氛围主题（可切换/可调）**。 |
| 启动器深度 | **不嵌入，仅找对应入口启动 + 深链跳子页**（App 支持才跳，否则降级首页）。 |

宪法对齐：本地私有（不联网、不收集）、超级自定义（主题/入口用户自定）。

## 1. 命名与冲突规避

- 现有 `src/modules/space/`（AppSpace / app-market）是**本软件自有**空间/模板/主题/插件市场，入口全是内部路由，**不是**外部启动器。
- 新功能另起命名，避免混淆：
  - 美化层 → **AuraLayer**（氛围层）
  - 启动器 → **Launcher**（外部应用启动器），新增模块 `src/modules/launcher/`
  - 美化层模块 → `src/modules/aura/`
- 不在现有 AppSpace 内混入外部 App 概念。

## 2. Feature A · 桌面美化层 AuraLayer

### 2.1 触发
- **快捷键**：全局热键（Tauri `global-shortcut`）切换 AuraLayer 显隐（如 `Ctrl/Cmd+Shift+A`）。
- **退出软件时**：关闭主窗口不退出进程，主进程保留一个 AuraLayer 透明窗（"缩小为美化层"）。可配置：退出=最小化到美化层 / 完全退出。
- 二者皆用户可在设置里关。

### 2.2 窗口形态（Tauri 原生可行）
新建第二个窗口 `aura`（独立 label，区别于主窗 `main`）：
- `transparent: true`（去背景，仅渲染内容）
- `alwaysOnTop: true` + `setAlwaysOnTop(true)`
- `decorations: false`、`resizable: false`
- 全屏铺满；CSS `pointer-events: none` 让鼠标**穿透**到桌面/下层窗口；仅具体小组件（如时钟、点击展开按钮）`pointer-events: auto`
- 主窗关闭后 aura 窗由 Rust 主进程保活（不 `destroy`）

### 2.3 多元化氛围主题（核心：不止几种死样式）
`src/modules/aura/themes.ts` 定义主题注册表，用户可切换 + 调参：
- `starmap` 星图 ambient（复用星盘视觉）
- `breath` 呼吸球 ambient（镜我静息态）
- `fluid` 流体实时壁纸（渐变流光 shader/CSS）
- `clock-quote` 时钟 + 每日一言
- `solar` 节气 / 时光胶囊 ambient
- `minimal` 极简留白（仅一缕微光）
每主题暴露可定制项：主色、密度、动效速度、是否显示时钟/名言。持久化进 `useAppearance` 同类 `createSimple` 本地存储。

### 2.4 持久化
- `auraEnabled`、`auraTheme`、`auraHotkey`、`exitToAura`、`themeOverrides` 落本地配置（明文 JSON 引擎，沿用 `engine/storage`）。

### 2.5 Tauri 改动（src-tauri，独立于前端组件，可先行）
- `tauri.conf.json`：`windows` 增 `aura` 窗（transparent/alwaysOnTop/decorations:false）
- `capabilities/default.json` 或新建 `aura.json`：加 `core:window:allow-set-always-on-top`、`core:window:allow-show`、`core:window:allow-hide`、`core:global-shortcut:allow-register`
- Rust：主进程监听退出事件，保活 aura 窗；global-shortcut 命令切换显隐

## 3. Feature B · 启动器 Launcher

### 3.1 数据模型
`src/modules/launcher/types.ts`：
```ts
interface ExternalAppEntry {
  id: string
  name: string            // 显示名，如「网易云音乐」
  icon: string            // emoji 或本地图标路径
  category: string        // 用户自建分类，如「音乐」「支付」「办公」
  launch: string          // 启动方式：可执行路径 或 URI scheme
  deepLink?: string       // 可选：深链 URI，如 orpheus://playlist/{id}
  useDeepLink: boolean    // 优先用 deepLink 还是 launch
  sort: number
  lastLaunchedAt?: string
  launchCount: number
}
```

### 3.2 启动机制（桌面可行）
- 有 `deepLink` 且 `useDeepLink` → `plugin-shell` 的 `open(deepLink)`（OS 默认处理器解析 `weixin://`/`orpheus://`/`https://`）。
- 否则 `open(launch)`（launch 为 `.exe`/`.app` 路径，OS 关联打开）。
- 权限：`shell:allow-open`（URI/路径打开）+ 按需 `process:allow-spawn`（直接 spawn exe）。
- 不嵌入任何外部 App 窗口（原生桌面程序无法嵌 webview）。

### 3.3 深度链接（graceful degrade）
- 点击条目 → 拉起 App；`deepLink` 命中且**目标 App 认协议** → 跳子页；不认 → 停在首页。
- 用户自填 `deepLink`，不预置任何"伪直达"。
- 例：网易云「我喜欢的歌单」→ `deepLink = orpheus://playlist/<id>`（或对应 web URL），可直达歌单。
- 反例：微信支付桌面端无公开深链 → 填 `weixin://` 仅拉起微信首页，用户自点支付（不造假"直达"）。

### 3.4 UI（Launcher 房间/空间）
- 新增 Launcher 视图（路由 `/launcher`），呈现用户 App 库，按 `category` 分组。
- 操作：添加条目（名/图标/启动方式/深链/分类）、编辑、删除、拖拽排序、分类管理。
- 入口：从 FloatingNavBar 或侧栏房间树进入（遵循空间容器布局契约，新增浮层须在 `.app-shell.chrome-hidden` 加淡出规则）。
- 可选增强：首次扫描系统已装 App 生成候选（Win 读注册表 `HKLM\Software\Microsoft\Windows\CurrentVersion\App Paths`；Mac 读 `/Applications`）——列为 Phase 2。

### 3.5 持久化
- `externalAppEntries` 落本地明文 JSON（沿用 `engine/storage` KV）。

### 3.6 Tauri 改动
- `Cargo.toml` 加 `tauri-plugin-shell`（+ 按需 `tauri-plugin-process`）
- `capabilities` 加 `shell:allow-open`（及 `process:allow-spawn` 若直 spawn）
- Rust `main.rs` 注册插件

## 4. 可行性边界（必须明示，不造假）
- ✅ 拉起已装 App 到首页：100% 可行。
- ✅ 深链跳子页：对**开放 URI Scheme** 的 App 可行（网易云 `orpheus://`、多数桌面 IM 的部分 scheme）。
- ⚠️ 微信支付子页：桌面端无公开深链，仅能拉起微信首页，降级处理。
- ❌ 嵌入外部原生 App 窗口：不可行（非 webview），本设计已排除。
- 移动端（后续）：Android/iOS 的 URI Scheme / App Link 深链能力显著更强，"跳子页"红利在那时释放。

## 7. 风险
- 透明窗在某些 GPU/远程桌面下渲染异常 → 提供"非透明降级"（半透明实底）开关。
- 全局热键与其他软件冲突 → 设置内可改键。
- 深链协议随目标 App 版本失效 → 永远降级到首页，不报错卡死。
