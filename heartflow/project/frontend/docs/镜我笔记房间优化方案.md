# 镜我 × 笔记房间 · 优化提案

> 范围：首页幕僚坞里的「镜我」(`MirrorSelf` + `MirrorDialogue`) 与「笔记房间」(`StudyRoom` 为核心 + `HomeRoomPanel`/`HomeRoomAtmosphere`)。
> 目标：重新优化**内部功能**与体验，并与已落地的语丝能力（房间感知 / 结构化抽取 / 语音）形成闭环。
> 蓝图口径：仅守前两条硬约束（本地私有 + 超级自定义），不越界强加形态——以下方案均为"增强默认体验"，用户可在载体编辑器里覆盖。

---

## 一、现状速写

### 镜我（玉珠自照）
| 部件 | 现状 | 问题 |
|---|---|---|
| 玉珠光点 `MirrorSelf` | 时段色彩 + 呼吸/光晕动画（蓝图指定初始形态=玉珠） | 纯装饰，状态信息靠长按才有 |
| 长按状态面板 | 今日专注 / 总笔记 / 待办锚点 / 情绪花房 + 定音锤进度 | 固定 4 项，无房间维度、无时间轴 |
| 定音锤四幕入口 | 📜 按钮 → `/dingyin-four-acts` | 与玉珠割裂，常驻占空间 |
| 镜我对话 `MirrorDialogue` | 消息流 + 意图标签 + 执行结果 + 歧义候选 + 6 个快捷建议 | **无语音**（语丝有）；**无结构化回显**（语丝有）；**无房间感知**；歧义"消除"只是重发原文，没真生效 |

### 笔记房间（家 · 空间）
| 部件 | 现状 | 问题 |
|---|---|---|
| 书房 `StudyRoom` | 真实联动笔记数/结晶数；书架按 **tag** 分类；结晶概览；静默深渊入口；导航 | 书架**按 tag 不分房间**；笔记卡片**不显示** roomId / due / 执行人 / 优先级（语丝已落库却没消费） |
| 房间切换器 `HomeRoomPanel` | 右下浮窗，3 列房间网格 + 当前房间描述 | 内嵌坞时网格拥挤；当前房间仅文字描述，无预览 |
| 氛围层 `HomeRoomAtmosphere` | 9 种纹理 + 壁纸 + 装饰粒子 | 粒子纯随机（`Math.random`），无语义 |
| 房间系统 | `rooms.ts` 11 房间定义，仅书房有完整 Room 组件 | 其他房间（客厅/卧室…）是平行组件，无统一"房间内记录"入口 |

### 核心断点（本次最关键）
语丝的方案 11 已给笔记打 `roomId`，方案 14 已落 `due/assignee/priority`，但**书房和镜我都没读这些数据**——"语丝在书房记了一件事"在书房里看不到归属，时间/执行人/优先级也不可见。这是"数据已产生但没展示"的缺口，也是本次最高性价比切入点。

## 二、镜我优化方案（6）

**M1 · 镜我对话接入语音**（复用 `useVoiceInput`，与语丝一致）
- `MirrorDialogue` 加麦克风按钮；停止后回填输入框确认再发，避免误建。消除"语丝能说、镜我要打字"的不一致。

**M2 · 镜我对话结构化回显**（复用 `extractStructured`）
- 用户在镜我说"明天下午3点让张三处理上线"，消息旁回显 `时间·明天15:00 / 执行·张三 / 高优先级` chip，落库时注入。与语丝体验对齐。

**M3 · 镜我房间感知**（修复断点）
- 坞里 `mirror` 标签当前**未传 activeRoomId**；补 `:active-room-id`，让镜我语气/快捷建议随房间微调（书房偏"记录/整理"，卧室偏"安顿"）。纯提示层，不强制。

**M4 · 歧义真正消除**（修复 bug）
- `handleResolveAmbiguity` 现只重发原文，没传 intent；改为把选定意图带入 `send`，真正消歧。

**M5 · 玉珠状态拟态**（视觉增强，非强制形态）
- 玉珠随生命态/时段微调：专注时在侧→稳定微光；忙碌→核心加速搏动；安睡→灰度下沉。仍是玉珠（蓝图指定初始形态），只是"活"起来。用户可在载体编辑器覆盖。

**M6 · 长按面板升级**
- 增加"今日时间轴"迷你条（晨→夜专注分布）、房间维度（当前房间今日记录数）、手势（左滑切房间/右滑唤对话）。内部功能深化。

## 三、笔记房间优化方案（6）

**R1 · 书房按房间聚合**（闭环核心）
- 书架分类增加"来自哪个房间"维度：带 `roomId` 的笔记显示房间小标签（如 `书房`/`阳台`）；可切"按标签 / 按房间"两种视图。消费语丝方案 11 的数据。

**R2 · 结构化字段回显**（闭环核心）
- 笔记卡片与详情回显 `due / 执行人 / 优先级`（来自方案 14）。卡片角标高优先级（橙）/低（蓝）；详情区列出时间·执行人。让抽取真正可见。

**R3 · 房间内快速记录入口**（内部功能）
- 书房底部加"在此记录"按钮，直接唤起语丝 compact（预填 `activeRoomId=书房`），不用切回坞。降低记录 friction。

**R4 · 氛围语义化**（视觉）
- 粒子按房间性格 + 时段变化（书房=墨色慢浮、庭院=绿点飘落、夜房=冷蓝微星），取代纯随机。复用 `HomeRoomAtmosphere` 现有结构。

**R5 · 切换器重设计**（形态）
- 内嵌坞时改为 2 列紧凑 + 当前房间大图预览（图标+描述+今日记录数）；常驻浮窗保持 3 列。提升"探索房间"的质感。

**R6 · 跨房间记忆流**（方案 13 延伸）
- 每房间沉淀"今日在此做了什么"（记了几条、专注几次），首页房间卡显示今日活跃度。增强连续性。

## 四、推荐 MVP（本次建议落地）

| 组合 | 方案 | 价值 | 风险 |
|---|---|---|---|
| **MVP-A（推荐）** | R1 + R2 + M1 + M2 + M3 + M4 | 闭合"语丝产数据→书房/镜我消费"最大断点；消除镜我/语丝能力差；全为复用已落库能力，低风险 | 低 |
| MVP-B 笔记房间优先 | R1 + R2 + R3 | 只做笔记房间闭环 + 记录入口 | 低 |
| MVP-C 镜我优先 | M1 + M2 + M3 + M4 | 只做镜我一致性补全 + 歧义修复 | 低 |
| 全做 | M1–M6 + R1–R6 | 完整优化 | 中（含形态/记忆流，需多轮回归） |

**MVP-A 落地内容（均非破坏性、复用已有能力）：**
- `StudyRoom`：书架加 roomId 维度 + 笔记卡片/详情回显结构化字段（R1/R2）
- `MirrorDialogue`：接 `useVoiceInput` + 结构化回显 + 接收 `activeRoomId`（M1/M2/M3/M4）
- `AdvisorDock`：`mirror` 标签补 `:active-room-id`（M3 接线）
- 单测覆盖房间聚合与结构化回显；四道闸门验证；原子提交（仅 `src/`，排除 `Astrolabe.vue`）

> 蓝图合规：M5 仍是玉珠初始形态（仅拟态动画），M3 仅提示层，均不越界；所有载体/性格仍由用户在载体编辑器定义。
