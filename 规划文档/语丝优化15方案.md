# 语丝（首页镜我·自然语言快建）重优化 — 15 种方案

> 范围：首页幕僚坞 `nl` 标签 = `NaturalLanguageCreate.vue`（紧凑态），底层引擎 `modules/mirror/nl-create.ts` 的 `executeNaturalLanguageCreate()`。
> 目标：保留「镜我轻声陪你记下一切」的诗意定位，重做**形态 + 交互 + 内部能力**，给出 15 个可落地方向，供挑选与组合。
> 日期：2026-08-16

---

## 一、现状速写（改造前）

| 维度 | 现状 |
|---|---|
| 入口 | 幕僚坞 `nl` 标签 → `NaturalLanguageCreate :compact="true"` |
| UI | 单行 `input` + 「创建」按钮 + 一行反馈文字 + 「前往 ›」 |
| 内部引擎 | `executeNaturalLanguageCreate(raw)`：①习惯关键词(`每天/坚持/打卡…`)优先→自律工坊 `addHabit`；②否则 `parseTaskBest` → `plan`(经略阁节点)/`note`(思绪书房 `quickCapture`)/`focus`(仅标记，无落库)/`unsupported` |
| 路由 | `/automation`(习惯) `/knowledge`(计划) `/study`(笔记) `/worklog`(专注) |
| 已知可用但未接 | `modules/mirror/voice-input.ts`（语音输入已存在，语丝未用）；`AdvisorDock` 已收到 `activeRoomId` 却从未传给 NL 引擎 |

## 二、8 个核心痛点

1. **黑盒创建**：提交前看不到「会建什么、建在哪、标题是什么」。
2. **单意图**：一句话只能建一个；「记灵感 并 建习惯」无法一次完成。
3. **无语音**：`voice-input.ts` 已就绪却没接，触屏/移动端体验断档。
4. **无房间感知**：在书房/庭院/阳台说「记一下」，都进同一处，丢失空间语境。
5. **语丝说完即焚**：无「今日语丝」回溯、无历史、无法重编辑。
6. **反馈弱、无人格**：仅一行文字，镜我从不回应，与「陪伴」定位割裂。
7. **形态普通**：普通输入框，与「语丝/镜我/玉珠」诗意割裂。
8. **结构化缺失**：无法抽取时间(`明早9点`)/标签(`#项目`)/优先级/周期，实体信息贫瘠。

## 三、15 种方案（分三组）

### A 组 · 形态与容器革新（解决痛点 7/6/视觉割裂）

#### 1. 浮丝丝带（Whisper Ribbon）
- **视觉**：首页底部常驻一条极细的浮丝 pill（仅图标+占位），点击/上滑展开为输入台，松手即收。
- **交互**：轻量常驻，零侵入；展开后才显示输入框与意图提示。
- **内部改动**：几乎只改 `NaturalLanguageCreate` 外壳，引擎不动。
- **适用**：想要「一直在、又不挡视线」的极简主义。
- **成本**：低。

#### 2. 镜面涟漪输入（Orb Ripple）
- **视觉**：语丝直接内嵌镜我玉珠——输入框浮在珠心，输入时玉珠泛起涟漪，文字「落入」珠中。
- **交互**：点玉珠 → 珠内浮现输入；提交后珠心亮一下（已收下）。
- **内部改动**：把 `NaturalLanguageCreate` 的 `compact` 模式嵌进 `MirrorSelf` 的 orb 区；复用现有 orb 动画。
- **适用**：强化「镜我即入口」的一体感，最贴合蓝图诗意。
- **成本**：中。

#### 3. 语丝抽屉台（Bottom-Sheet Console）
- **视觉**：点「语丝」从底部滑出半屏抽屉：大输入框 + 实时意图预览 + 最近语丝历史。
- **交互**：抽屉内完成输入/预览/确认，关抽屉即收。
- **内部改动**：新增 `WhisperSheet` 容器；意图预览复用方案 6 的实时解析。
- **适用**：需要「一屏内看到创建内容与历史」的实用派。
- **成本**：中。

#### 4. 气泡对话式（Conversational Creation）
- **视觉**：语丝复用 `MirrorDialogue` 对话流——你说一句，镜我回一句「已为你记下 ✦」，像聊天一样创建。
- **交互**：自然语言来回确认（「要设为每天吗？」），创建即对话气泡。
- **内部改动**：`executeNaturalLanguageCreate` 返回结果后由 `MirrorDialogue` 渲染为气泡；需接 `advisor.currentBubble` 式回声。
- **适用**：最像「和镜我说话」，陪伴感最强。
- **成本**：高。

#### 5. 全屏沉浸画布（Immersive Canvas）
- **视觉**：上滑玉珠进入全屏语丝画布，背景取当前房间氛围光，大字号、语音优先。
- **交互**：全屏专注记录；完成后下滑退出，回到首页。
- **内部改动**：新增全屏路由/overlay；接房间氛围色(`getHomeRoom().atmosphereColor`)。
- **适用**：夜深独处、想「认真写一段」的场景。
- **成本**：高。

### B 组 · 交互范式（解决痛点 1/2/3/8）

#### 6. 实时意图预览（Live Intent Preview）★强烈推荐
- **视觉**：输入时下方实时出现意图 chip：`[笔记] 记一下灵感：…`，可点 chip 切换意图或改标题。
- **交互**：边打字边解析（`parseTaskBest` 实时调用），提交前可校正，避免建错地方。
- **内部改动**：`executeNaturalLanguageCreate` 拆出 `previewIntent(raw)`；`NaturalLanguageCreate` 加可编辑 chip。
- **适用**：根治「黑盒创建」，性价比最高。
- **成本**：中。

#### 7. 多选意图批处理（Multi-Intent Batch）
- **视觉**：一句话拆成多条待建项清单（checkbox），逐条确认/删除后一次性建。
- **交互**：「每天跑步 / 记一下灵感 / 制定季度计划」→ 三条清单，全选提交。
- **内部改动**：新增分句 + 多意图分段解析；循环调用创建 API。
- **适用**：灵感爆发、想一口气记下多件。
- **成本**：高。

#### 8. 语音优先（Voice-First Whisper）★强烈推荐
- **视觉**：主按钮为麦克风；点按说话，实时转写进输入框，文字作回退。
- **交互**：`voice-input.ts` 已存在 → 接 `start()/stop()`，转写文本喂给同一引擎。
- **内部改动**：`NaturalLanguageCreate` 接语音模块；移动端零额外成本。
- **适用**：走路/躺着不想打字，移动端首选。
- **成本**：中。

#### 9. 语丝快捷片（Whisper Chips / 模板）
- **视觉**：输入框上方一排快捷片：`记灵感 / 建习惯 / 开始专注 / 加计划` + 最近短语。
- **交互**：一点即预填模板文本，回车即建。
- **内部改动**：`NaturalLanguageCreate` 加 chips；模板即预置 prompt 串。
- **适用**：高频固定动作，降低输入负担。
- **成本**：低。

#### 10. 手势与房间拖拽（Gesture + Room Routing）
- **视觉**：长按玉珠语音；把语丝气泡拖到某房间卡片上，即把笔记路由到该房间。
- **交互**：拖拽落点 = 目标房间；结合方案 11 的房间感知。
- **内部改动**：拖拽事件 + 房间命中检测；路由参数注入。
- **适用**：空间感强的用户，但学习成本偏高。
- **成本**：高。

### C 组 · 内部能力升级（解决痛点 4/5/6/8）

#### 11. 房间感知路由（Room-Aware Routing）★强烈推荐
- **视觉**：语丝头部显示「在·书房」当前房间；「记一下」自动带房间标签。
- **交互**：`AdvisorDock` 已传 `activeRoomId` → 注入 `executeNaturalLanguageCreate(raw, { roomId })`；笔记/计划带房间上下文。
- **内部改动**：引擎加 `context` 参数；`quickCapture`/`createPlanNode` 接收并存储 roomId。
- **适用**：把「语丝」和「笔记房间」真正打通（用户原话核心）。
- **成本**：中。

#### 12. 幕僚人格化回应（Persona Echo）
- **视觉**：创建后镜我用性格口吻回应一句（关怀型「记下了，累了就看看它」/活泼型「收到！这就安排上 ✦」）。
- **交互**：结果回传 `AdvisorProfile.personality` → 取对应回声文案。
- **内部改动**：新增 `personaEcho(kind, personality)` 映射；渲染进气泡或反馈区。
- **适用**：强化陪伴、消除「冷冰冰反馈」。
- **成本**：低。

#### 13. 语丝记忆流（Whisper Memory Stream）
- **视觉**：语丝面板内嵌「今日语丝」时间线，可重开/重编辑/删除历史 whisper。
- **交互**：每次创建落本地 KV 流；点击任一条回灌到输入框编辑重提交。
- **内部改动**：新增 `whisper-log` 存储(`storage.setKV`) + 列表组件；不改创建逻辑。
- **适用**：解决「说完即焚」，形成可追溯的轻声日记。
- **成本**：中。

#### 14. 结构化抽取（Structured Extraction）
- **视觉**：解析出 `时间/标签/优先级/周期` 字段，预览时以子 chip 展示（`⏰明早9点 #项目 ⏫高`）。
- **交互**：`parseTaskBest` 扩展抽取日期/标签(`#`)/优先级/周期；创建更丰富实体。
- **内部改动**：扩展 parser；各创建 API 接收扩展字段（需对应模块支持）。
- **适用**：想让语丝建的笔记/计划自带元数据。
- **成本**：高。

#### 15. 跨系统编排 + 双向链接（Orchestration & Auto-Link）
- **视觉**：一句话可串联多动作（「记灵感 并设为今日专注」→ 建笔记 + 启专注 + 自动加双向链接）。
- **交互**：编排层解析连接词(`并/然后`)，顺序执行多创建 + `relation.createLink`（蓝图 #76 双向链接）。
- **内部改动**：新增 `orchestrate()` 层；接 `createNode` 的双向链接能力。
- **适用**：深度用户，把语丝当「指挥棒」。
- **成本**：高。

## 五、推荐落地组合（MVP → 进阶）

**MVP（低成本、高回报，建议先做这 4 个）**
- **6 实时意图预览**：根治黑盒，体验跃升。
- **8 语音优先**：接已存在的 `voice-input.ts`，移动端质变。
- **11 房间感知路由**：打通「语丝 ↔ 笔记房间」，正是你点名的语境。
- **12 人格化回应**：几乎零成本，把冷反馈变陪伴。

**进阶（第二阶段）**
- **13 语丝记忆流**（可追溯轻声日记）+ **2 镜面涟漪 / 3 语丝抽屉台**（形态升级）。

**深度（第三阶段，按需）**
- **4 气泡对话式 / 15 跨系统编排 / 14 结构化抽取**。
