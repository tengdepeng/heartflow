## 0. 先对齐两件事

**① 两条硬约束（不可破）**
- 本地私有：数据只在本机，不外发、不落云。
- 超级自定义：规则/界面/交互均可用户自定义。

**② 「最新型」在本项目里 = 五个现约定**
| 维度 | 现约定 | 参照 |
|---|---|---|
| 模块形态 | 一律 `export function useXxx()`，模块级单例 ref 跨消费方共享 | `modules/reading/reading-content.ts:28-30` |
| 持久化 | 统一 `storage.getKV/setKV`（单一 schema + migrate，SCHEMA_VERSION=10） | `engine/storage/kv.ts:11-18`、`core.ts:485-655` |
| 浮层布局 | 用 `assets/layout-contract.css` 契约类，禁 HARD `height:100vh` | `layout-contract.css:29` |
| 视觉 | 玻璃拟态同源配方 + 纯 CSS 合成动画（禁 rAF 每帧写盘） | `.ms-orb`（`MirrorSelf.vue:812-826`）、`JadeBead.vue:397-415`、`useCanvasBreathing.ts`（`9c05519`） |
| 接线 | 接主线：共鸣 / 时间长廊 / 手札 / 时光胶囊 / 幕僚 | `room-resonance`、`timeline-bridge`、`anchor-journal` |

**判定**：这两块都是「**功能齐、面板全，但刚好卡在上述范式之外**」——不是从零造，是**接线 + 换范式 + 补形态**。

   → 阅读统计 → 时间长廊

## 5. 风险与合规
- **配额**：localStorage ~5MB；照片必须搬走，否则必炸（当前无护栏=静默丢）。
- **性能**：大图解码阻塞主线程；引入 canvas 降采样即可，暂不必上 Worker。
- **合规**：照片与阅读数据全程本地，符合「本地私有」；不得引入任何云同步。
- **回归面**：`dingyin-engine` key 修正会改变铭音取数（需连同 `stores/health.ts` 归属澄清一起做，避免又一处误指）。
