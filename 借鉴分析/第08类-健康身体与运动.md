# 第8类 · 健康 / 身体 / 运动（11个）

> **核心答案**：身体数据怎么接进来
> **影响模块**：模块十五·身体温室
> **宪法兼容**：身体感受而非指标；拒绝目标评分、穿戴依赖、健康建议；健康数据本地脱敏存储（Health Connect 仅脱敏元数据）；拒绝诊断/建议。

---

## 一、蓝图规格内 App（7个）

### 1. Keep（结构化运动课程体系）
- **核心功能**：将运动健身拆成结构化课程、自由训练、跑步记录、身体数据追踪四大模块，并配套成就徽章体系。
- **借鉴点**：
  1. 结构化课程——身体温室「运动处方」
  2. 训练记录——身体温室运动日志
  3. 身体数据仪表盘——身体温室「身体仪表盘」
  4. 运动日历热力图——自律工坊运动打卡月历
  5. 自定义训练编排——身体温室支持创建自定义训练
- **目标房间**：模块十五·身体温室 / 模块十六·自律工坊

### 2. 华为运动健康（全面健康数据仪表盘）
- **核心功能**：以全天候健康监测与科学运动指导为核心，将心率、血氧、睡眠、压力、体重、运动等健康指标整合为健康数据仪表盘。
- **借鉴点**：
  1. 健康数据仪表盘——身体温室「健康仪表盘」
  2. 健康趋势分析——数据可视化「健康趋势」
  3. 科学睡眠分析——身体温室「睡眠分析」
  4. 健康三环——自律工坊「健康三环」（状态导向，非评分）
  5. 压力监测与呼吸训练——身体温室「压力指数」
- **目标房间**：模块十五·身体温室

### 3. 小米运动健康（健康生态与运动数据追踪）
- **核心功能**：以「可视化健康，让数据驱动改变」为核心，将步数、卡路里、心率、睡眠、血氧、压力、体重等健康指标以卡片式布局统一呈现。
- **借鉴点**：
  1. 健康数据仪表盘——身体温室「健康仪表盘」
  2. 运动模式自动识别——身体温室「运动感知」
  3. 运动记录与报告——身体温室「运动日志」
  4. PAI 活力指数——身体温室「活力指数」
  5. 健康数据趋势汇总——身体温室「健康周报」
- **目标房间**：模块十五·身体温室

### 4. 每日减脂（饮食运动双轨管理）
- **核心功能**：以「饮食运动双轨制」为核心架构，从饮食摄入、运动消耗到身体测量数据变化，在统一时间轴上汇聚。饮食轨以「餐盘」为视觉隐喻，系统自动计算热量和营养素。运动轨覆盖多种运动类型，身体测量支持多围度追踪。
- **借鉴点**：
  1. 饮食记录——餐盘隐喻，热量与营养素环形图
  2. 运动记录——多运动类型独立模板
  3. 身体测量趋势——多指标折线图 + 双 Y 轴对比
  4. 饮食拍照日记——照片嵌入饮食记录卡片
  5. 进度图表与趋势可视化——日/周/月/年四种粒度
- **目标房间**：模块十五·身体温室 / 模块十六·自律工坊

### 5. 知源中医（中医知识体系与体质辨识）
- **核心功能**：以「中医知识体系化」为理念，整合体质辨识、经络穴位、方剂药膳、节气养生、中药材等中医知识，并配合 3D 经络可视化和体质测试。
- **借鉴点**：
  1. 体质辨识问卷和雷达图——身体温室「体质画像」
  2. 经络穴位知识库——知微阁「经络穴位」卡片牌组
  3. 方剂知识库——经略阁「方剂卡片」
  4. 节气养生提醒——身体温室「节气日历」
  5. 药膳食谱——身体温室「药膳食谱」
- **目标房间**：模块十五·身体温室 / 模块三十四·知微阁

### 6. 人纪针灸（针灸学习与经络穴位结构化）
- **核心功能**：以「倪海厦人纪针灸教程」为核心，提供系统化的针灸学习与经络穴位知识体系。将 14 条正经和奇经八脉的穴位知识按「经络→穴位→定位→主治→配伍→禁忌」的层级结构组织。
- **借鉴点**：
  1. 经络穴位结构化学习——层级结构组织
  2. 穴位详情展示——定位/解剖/深度/主治/配伍/禁忌
  3. 经络循行路线动画——高亮线条 + 沿途穴位
  4. 穴位定位图——2D/3D 视图切换
  5. 针灸禁忌与注意事项——红色警告标识
- **目标房间**：模块十五·身体温室 / 模块三十四·知微阁

### 7. 健康数据共享（统一健康数据中枢）
- **核心功能**：Android 系统级的健康数据统一存储与共享平台，核心理念是打破各健康应用之间的数据孤岛，让不同应用的数据汇聚到一个中心化的本地数据库中，并允许授权应用读取和写入。
- **借鉴点**：
  1. 统一健康数据模型——身体温室「健康数据中枢」
  2. 跨应用数据聚合——身体温室「数据聚合」
  3. 细粒度权限控制——感知层「数据权限」
  4. 数据变化自动同步——身体温室「数据联动」
  5. 历史数据趋势分析——身体温室「趋势仪表盘」
- **目标房间**：模块十五·身体温室 / 感知层

## 二、补充参考 App（4个，通用产品知识）

### 8. 小米健康（健康数据管理）
- **核心功能**：小米生态健康数据管理应用，聚合步数、心率、睡眠、体重等数据，提供健康卡片与趋势图表。
- **借鉴点**：
  1. 健康卡片——身体温室「健康仪表盘」
  2. 数据聚合——多源健康数据统一
  3. 趋势图表——数据可视化「健康趋势」
- **目标房间**：模块十五·身体温室

### 9. 苹果健康（Apple Health）
- **核心功能**：iOS 系统级健康数据中枢，聚合健康与健身数据，支持数据授权、健康记录、趋势分析与「健康共享」。
- **借鉴点**：
  1. 健康数据中枢——身体温室「健康数据中枢」
  2. 数据授权模型——感知层「数据权限」
  3. 趋势分析——数据可视化「健康趋势」
  4. 健康记录——身体温室「身体档案」
- **目标房间**：模块十五·身体温室 / 感知层

### 10. Zepp（健康运动追踪）
- **核心功能**：智能穿戴健康平台，提供心率、睡眠、压力、血氧等健康监测与运动记录。
- **借鉴点**：
  1. 健康监测——身体温室「健康仪表盘」
  2. 睡眠分析——身体温室「睡眠分析」
  3. 运动记录——身体温室「运动日志」
- **目标房间**：模块十五·身体温室

### 11. Strava（运动记录与社交）
- **核心功能**：专业运动记录应用，以 GPS 轨迹、运动数据统计、路线分享著称（社交部分拒绝）。
- **借鉴点**：
  1. GPS 轨迹记录——身体温室「运动轨迹」
  2. 运动数据统计——身体温室「运动日志」
  3. 路线管理——地图室「路线回顾」
  4. 拒绝社交分享与排行
- **目标房间**：模块十五·身体温室 / 模块三十·地图室

## 三、落地要点小结（模块十五·身体温室）

1. **健康数据中枢**：吸收健康数据共享/苹果健康/小米健康——统一健康数据模型、细粒度权限、跨应用聚合（本地脱敏）。
2. **身体仪表盘**：吸收华为/小米运动健康/Zepp——心率/血氧/睡眠/压力/体重卡片式布局，状态导向而非评分。
3. **运动体系**：吸收 Keep/每日减脂/Strava——结构化课程、运动日志、餐盘隐喻、GPS 轨迹。
4. **中医身体观**：吸收知源中医/人纪针灸——体质画像、经络穴位层级、节气养生（「象」非「症」，拒绝诊断建议）。
5. **拒绝**：目标评分、穿戴依赖、健康建议、诊断、社交排行。
