# 第12类 · 全局UI / 组件 / 主题（5个）

> **核心答案**：界面长什么样、怎么换皮肤
> **影响模块**：模块〇·数据可视化自定义体系
> **宪法兼容**：主题/组件全部本地可自定义（第2条超级自定义强制）；拒绝云端主题商店依赖；组件库可替换。

---

## 一、蓝图规格内 App（2个）

### 1. 小组件盒子（桌面小组件生态）
- **核心功能**：将时钟、日历、天气、待办、倒计时、习惯打卡、步数、电池、照片等分散信息展示需求统一为可组合、可定制的小组件体系。
- **借鉴点**：
  1. 组件化信息卡片设计——全局 UI「信息卡片组件」
  2. 数据看板聚合展示——引力场画布「数据看板」
  3. 小组件主题一键切换——核心组件库「主题系统」
  4. 倒计时/进度环组件——核心组件库「进度环组件」
  5. 日历热力图组件——核心组件库「日历热力图」
- **目标房间**：模块〇·数据可视化自定义体系

### 2. 系统桌面（桌面启动器与空间布局）
- **核心功能**：是小米 HyperOS 的桌面启动器，核心功能是管理手机主屏幕的应用图标、小组件、文件夹和负一屏。设计哲学是「空间即组织」。
- **借鉴点**：
  1. 网格化空间布局——空间管理「房间网格」
  2. 文件夹聚合容器——空间管理「房间组」
  3. 负一屏信息聚合——全局 UI「信息面板」
  4. 手势触发多层空间——手势系统「空间手势」
  5. 小组件灵活放置——全局 UI「桌面小组件」
- **目标房间**：模块〇·数据可视化自定义体系 / 空间管理 / 手势系统

## 二、补充参考 App（3个，通用产品知识 · UI部分）

### 3. 元气壁纸（UI部分）
- **核心功能**：提供治愈系、元气系壁纸资源，以明亮温暖的视觉风格营造好心情。
- **借鉴点**：
  1. 治愈系视觉——「温柔感」配色参考
  2. 壁纸主题——模块〇「主题系统」壁纸素材
  3. 每日更新——本地壁纸轮换
- **目标房间**：模块〇·数据可视化自定义体系

### 4. 人工桌面（UI部分）
- **核心功能**：桌面虚拟角色/宠物应用，角色可互动、陪伴、反馈，营造「有人陪着」的氛围。
- **借鉴点**：
  1. 桌面陪伴角色——情绪花房「花房精灵」/守护室「守护灵」
  2. 互动反馈——角色对用户操作的回应
  3. 拟人化陪伴——镜我「安静陪伴者」的视觉层
- **目标房间**：模块〇·数据可视化自定义体系 / 模块四·情绪花房 / 模块七·镜我

### 5. Salt Player（UI部分）
- **核心功能**：以「本地音乐播放」为核心的高质量播放器，注重音质、极简 UI 与本地曲库管理。
- **借鉴点**：
  1. 极简 UI——「温柔感」界面参考
  2. 本地曲库——守护室/情绪花房本地音源
  3. 高质量播放——沉浸式听感
- **目标房间**：模块〇·数据可视化自定义体系 / 模块六·守护室

## 三、落地要点小结（模块〇·数据可视化自定义体系）

1. **组件化体系**：吸收小组件盒子——信息卡片组件、进度环组件、日历热力图组件、数据看板。
2. **空间布局**：吸收系统桌面——网格化空间、房间组、信息面板、手势触发多层空间。
3. **主题系统**：吸收元气壁纸/人工桌面/Salt Player——治愈系配色、陪伴角色、极简 UI，全部本地可自定义。
4. **拒绝**：云端主题商店依赖、固定皮肤、不可替换组件。
