# 第15类 · 书签 / 扫描 / 入口（4个）

> **核心答案**：网页怎么存、纸质怎么扫
> **影响模块**：模块三十三·书签与入口架
> **宪法兼容**：网页剪藏本地化；扫描 OCR 本地离线；拒绝云端收藏同步与社交分享。

---

## 一、蓝图规格内 App（3个）

### 1. 扫描全能王（文档扫描与OCR归档）
- **核心功能**：以「手机即扫描仪」为理念，将文档拍摄、图像优化、OCR 识别、PDF 生成、文档归档整合为移动扫描工作流。
- **借鉴点**：
  1. 智能边缘检测与自动裁剪——书签入口架「快速扫描」
  2. 图像增强——输出管理「图像增强」
  3. OCR 文字识别——输出管理本地 OCR 引擎
  4. 文件夹层级归档——书签入口架「文档归档」
  5. 批注与标注——思绪书房「文档批注」
- **目标房间**：模块三十三·书签与入口架 / 模块一·输出管理

### 2. 熊猫去水印下载（多媒体内容下载与管理）
- **核心功能**：以「多媒体内容下载与管理」为核心，支持从多个平台下载视频、图片、音频内容，并自动去除水印。下载内容按来源平台、文件类型、下载时间自动分类，支持批量管理，并内置媒体播放器和图片浏览器。
- **借鉴点**：
  1. 内容聚合管理——按来源/类型/时间分类（书签入口架「收藏分类」）
  2. 批量文件管理——删除/移动/重命名
  3. 内置媒体预览——内置播放器和图片浏览器
  4. 下载历史——时间线展示，搜索筛选
  5. 本地存储管理——文件占用空间可视化
- **目标房间**：模块三十三·书签与入口架（收藏部分）/ 模块一·输出管理

### 3. Pocket（稍后阅读与网页收藏）
- **核心功能**：稍后阅读类产品的核心是「捕获与排空」双通道：看到值得读的内容时以极低成本一键暂存，之后在安静、纯净的阅读环境中集中消化，阅读中的高亮与笔记沉淀为个人资产。
- **借鉴点**：
  1. 一键捕获暂存——书签入口架「稍后阅读」待读箱
  2. 纯净阅读环境——阅览殿「待读清单」沉浸排版与续读
  3. 高亮与批注沉淀——高亮转笔记草稿，加工后入思绪书房
  4. 收藏资产化——归档条目与高亮汇入释光阁长期检索
  5. 待读清理提醒——久未阅读条目定期提醒，防收藏积压
- **目标房间**：模块三十三·书签与入口架 / 模块十八·释光阁 / 模块十九·阅览殿 / 模块九·思绪书房

## 二、补充参考（1个，模块自身定位）

### 4. 书签与入口架（模块三十三自身）
- **核心功能**：心流工坊的书签与入口架模块定位——网页怎么存、纸质怎么扫、入口怎么组织。
- **借鉴点**：
  1. 网页剪藏——本地化剪藏为卡片
  2. 稍后阅读——待读箱与排空
  3. 快速扫描——纸质文档数字化入口
  4. 入口组织——常用入口聚合
- **目标房间**：模块三十三·书签与入口架

## 三、落地要点小结（模块三十三·书签与入口架）

1. **捕获与排空**：吸收 Pocket——一键捕获暂存、纯净阅读、待读清理提醒。
2. **快速扫描**：吸收扫描全能王——智能边缘检测、图像增强、本地 OCR、文档归档。
3. **收藏分类**：吸收熊猫去水印下载——按来源/类型/时间分类、批量管理、本地存储可视化。
4. **拒绝**：云端收藏同步、社交分享、推送轰炸。
