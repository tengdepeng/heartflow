# 第9类 · 效率 / 习惯 / 任务（16个）

> **核心答案**：任务怎么管、习惯怎么养
> **影响模块**：模块十六·自律工坊 / 模块二十一·更漏 / 模块三十七·成长庭院
> **宪法兼容**：内在驱动而非外部奖惩；拒绝 XP/等级/排行/积分/连续签到压力；人升「自我奖励商店」用成长值而非金币；拒绝提醒轰炸。

---

## 一、蓝图规格内 App（6个）

### 1. 时光序（全能效率工具体系）
- **核心功能**：以「一个 App 搞定所有日常管理」为核心理念，将 18+ 功能模块（日历、任务、习惯、记账、日记、备忘录、课程表、专注计时、纪念日、健康追踪、读书笔记、心愿清单、喝水提醒、生理期、天气、倒数日、事项四象限、目标管理）统一收纳于一个应用中。所有模块共享同一套本地数据层，通过模块化卡片首页实现「可组装式个人仪表盘」。
- **借鉴点**：
  1. 模块化卡片首页——更漏首页以卡片网格展示各模块摘要
  2. 统一本地数据层——所有模块共用 SQLite 数据库
  3. 跨模块事件链接——任务关联日历、习惯触发奖励
  4. 多视图日历——更漏日志视图支持月/周/日/列表
  5. 习惯打卡连续记录——自律工坊维护 streak 机制
  6. 四象限任务管理——自律工坊任务支持紧急重要度分组
  7. 专注计时与任务关联——自律工坊计时器关联任务
  8. 心愿清单与习惯联动——成长庭院心愿清单解锁条件
  9. 全量数据导出备份——输出管理加密备份
- **目标房间**：模块二十一·更漏 / 模块十六·自律工坊 / 模块三十七·成长庭院

### 2. 人升（游戏化习惯养成）
- **核心功能**：将日常生活转化为 RPG 角色扮演游戏，通过六大属性值量化个人成长，以任务完成获取经验值与金币、属性升级驱动正反馈循环，最终通过自定义奖励商店和成就徽章体系构建完整的行动、成长、兑换、激励闭环。
- **借鉴点**：
  1. 六大属性值系统——简化为「成长维度」体系，映射六大生活领域
  2. 任务完成获得成长值与花瓣币
  3. 属性升级反馈——成长庭院中每个维度对应植物、升级触发生长动画
  4. 自定义奖励商店——用户可用花瓣币兑换自定义奖励
  5. 成就徽章系统——展示已解锁徽章，维持无社交比较
- **目标房间**：模块十六·自律工坊 / 模块三十七·成长庭院 / 模块二十三·劳酬

### 3. 滴答清单（全能任务管理）
- **核心功能**：以 GTD 方法论为核心，将任务管理、日历排程、习惯养成、番茄专注整合，通过自然语言解析降低任务创建摩擦。
- **借鉴点**：
  1. 自然语言解析创建任务——更漏 NLP 时间解析器
  2. 智能清单——今日、明日、本周、已逾期等筛选
  3. 多视图切换——列表、看板、日历、时间轴
  4. 番茄专注与任务绑定——自律工坊计时器关联任务
  5. 习惯打卡——数值型和布尔型打卡
- **目标房间**：模块二十一·更漏 / 模块十六·自律工坊

### 4. OffScreen（屏幕时间与专注管理）
- **核心功能**：以与屏幕建立健康关系为理念，通过屏幕时间追踪、番茄钟式专注会话、应用使用限额和成就徽章，减少屏幕焦虑。
- **借鉴点**：
  1. 屏幕时间仪表盘——守护室「数字生活仪表盘」
  2. 专注计时器——自律工坊「心流聚焦」
  3. 应用分类限额——守护室「数字边界」
  4. 每日/每周/每月报告——更漏「专注周报」
  5. 成就徽章系统——奖励「守护者徽章」
- **目标房间**：模块十六·自律工坊 / 模块六·守护室

### 5. 番茄浏览阅读器（番茄工作法+阅读）
- **核心功能**：以「番茄工作法+阅读」为核心，将番茄钟计时与阅读行为融合。阅读番茄钟提供倒计时进度条，并在结束后提醒休息。系统还记录阅读目标、成就徽章、网页转阅读和护眼模式。
- **借鉴点**：
  1. 阅读番茄钟——倒计时进度条，可选严格模式
  2. 阅读目标与进度追踪——环形进度条展示
  3. 成就徽章系统——纯自我激励，无排行榜
  4. 网页转阅读模式——提取纯净阅读视图
  5. 护眼模式——夜间模式/蓝光过滤/字体缩放联动
- **目标房间**：模块十·经略阁 / 模块十六·自律工坊

### 6. Forest（番茄专注计时）
- **核心功能**：用「种树」把专注可视化：每完成一个专注时段就种下一棵树，中途放弃则树枯萎，让时间投入看得见、舍不得中断。
- **借鉴点**：
  1. 专注计时——自律工坊「专注计时」
  2. 种树可视化——自律工坊「树园」成长可视化
  3. 休息节奏管理——更漏「休息倒计时」
  4. 中断如实记录——自律工坊「中断日志」
  5. 每日/每周统计——更漏「专注回顾」
  6. 连续天数激励——自律工坊「连续天数」
- **目标房间**：模块十六·自律工坊 / 模块二十一·更漏

## 二、补充参考 App（10个，通用产品知识）

### 7. OCAT（开源番茄钟）
- **核心功能**：开源番茄钟应用，支持自定义时长、任务关联、统计报表，无广告无追踪。
- **借鉴点**：
  1. 自定义番茄时长——更漏「专注时段」
  2. 任务关联——自律工坊计时器关联任务
  3. 统计报表——更漏「专注回顾」
- **目标房间**：模块二十一·更漏 / 模块十六·自律工坊

### 8. Todoist（GTD任务管理）
- **核心功能**：跨平台任务管理应用，以自然语言快速添加、项目/标签/优先级、过滤器与 Karma 积分（积分部分拒绝）著称。
- **借鉴点**：
  1. 自然语言添加任务——更漏 NLP 解析
  2. 项目/标签/优先级——任务组织
  3. 过滤器——智能清单
  4. 拒绝 Karma 积分与社交排行
- **目标房间**：模块二十一·更漏 / 模块十六·自律工坊

### 9. Microsoft To Do（任务管理）
- **核心功能**：微软任务管理应用，以「我的一天」、智能建议、任务列表、步骤与提醒为特色。
- **借鉴点**：
  1. 「我的一天」——更漏「今日专注」
  2. 智能建议——基于习惯的任务推荐
  3. 步骤拆解——任务子步骤
  4. 提醒——本地提醒（非推送轰炸）
- **目标房间**：模块二十一·更漏

### 10. TickTick（滴答清单国际版）
- **核心功能**：滴答清单的国际版，功能类似，整合任务、日历、番茄钟、习惯。
- **借鉴点**：
  1. 任务+日历+番茄整合——更漏「日课桥接」
  2. 习惯打卡——自律工坊
  3. 多视图——列表/看板/日历
- **目标房间**：模块二十一·更漏 / 模块十六·自律工坊

### 11. Habitica（游戏化习惯 RPG）
- **核心功能**：将习惯养成 RPG 化，完成任务获得经验/金币，角色升级，失败掉血（游戏化部分借鉴，社交/公会拒绝）。
- **借鉴点**：
  1. 习惯 RPG 化——自律工坊「成长维度」
  2. 任务/习惯/每日待办分类——自律工坊
  3. 拒绝社交公会与排行榜
- **目标房间**：模块十六·自律工坊 / 模块三十七·成长庭院

### 12. Streaks（习惯养成）
- **核心功能**：以「连续天数」为核心的习惯养成应用，最多 12 个习惯，强调简单与坚持。
- **借鉴点**：
  1. 连续天数——自律工坊「连续天数」
  2. 极简习惯列表——自律工坊「习惯清单」
  3. 完成即打卡——低摩擦
- **目标房间**：模块十六·自律工坊

### 13. Productivity Challenge Timer（生产力挑战计时）
- **核心功能**：以「挑战式专注」为核心，通过设定专注目标与挑战模式激励用户完成专注时段。
- **借鉴点**：
  1. 挑战式专注——自律工坊「心流挑战」
  2. 目标设定——更漏「专注目标」
  3. 进度反馈——环形进度
- **目标房间**：模块十六·自律工坊 / 模块二十一·更漏

### 14. Focus To-Do（番茄钟+任务）
- **核心功能**：番茄钟与任务管理结合，支持任务关联番茄、白噪音、统计报表。
- **借鉴点**：
  1. 番茄+任务绑定——自律工坊计时器关联任务
  2. 白噪音——更漏「专注环境」
  3. 统计报表——更漏「专注回顾」
- **目标房间**：模块二十一·更漏 / 模块十六·自律工坊

### 15. Sorted（时间块规划）
- **核心功能**：以「自动规划」为核心的任务应用，通过「Hyper Schedule」自动将任务排入时间块，支持拖拽调整。
- **借鉴点**：
  1. 时间块规划——更漏「时间块」
  2. 自动排程——更漏「自动规划」
  3. 拖拽调整——时间块重排
- **目标房间**：模块二十一·更漏

### 16. Things 3（优雅任务管理）
- **核心功能**：以「优雅极简」著称的任务管理应用，强调「今天/计划/收件箱/项目」的清晰结构。
- **借鉴点**：
  1. 收件箱→项目→今天——更漏「任务漏斗」
  2. 极简交互——自律工坊「低摩擦」
  3. 优雅 UI——「温柔感」界面参考
- **目标房间**：模块二十一·更漏 / 模块十六·自律工坊

## 三、落地要点小结（模块十六·自律工坊 / 模块二十一·更漏 / 模块三十七·成长庭院）

1. **任务管理**：吸收滴答/Todoist/Things 3/Sorted——自然语言解析、智能清单、多视图、时间块规划。
2. **习惯养成**：吸收人升/Streaks/Habitica——连续天数、成长维度、自我奖励商店（成长值而非金币）。
3. **专注计时**：吸收 Forest/OCAT/Focus To-Do——种树可视化、番茄+任务绑定、中断日志、专注回顾。
4. **模块化仪表盘**：吸收时光序——模块化卡片首页、统一本地数据层、跨模块事件链接。
5. **成长庭院**：吸收人升属性升级——每个维度对应植物、升级触发生长动画、心愿清单解锁。
6. **拒绝**：XP/等级/排行/积分、连续签到压力、社交公会、提醒轰炸。
