### 3. 循环依赖修复：engine/automation ↔ operation-mode/gate
- 问题：`engine/automation.ts` 运行时导入 `modules/operation-mode/gate`，而 gate 又 `import type { SavedFlow }` 回引 automation，形成环。
- 解法：自动化流程类型（TriggerType / ActionType / ConditionOperator / FlowCondition / ActionParams / FlowStep / SavedFlow / ExecutionRecord / FlowTemplate）统一收口到 `src/types/automation.ts`；`automation.ts` 改为 `export type { ... } from '../types/automation'` 重导出保持既有消费方兼容；`gate.ts` 与 `modules/automation/flows.ts` 改从 `src/types/automation` 直接引 SavedFlow。
- 验证：`madge --circular --extensions ts --ts-config tsconfig.json src/modules src/engine`（1111 文件）→ No circular dependency found；compliance-gate / flows 相关测试 11 例全过；eslint 无新增错误；vue-tsc 无新增错误（既有 world-shell / self-reward / canvas 等无关报错保持不变）。

## 十二、工程清理：vue-tsc 全绿 + 交互缺陷修复（2026-08-26）

8. **constitution.test.ts**（TS2790）：`delete r.scaleScores` 报错 → `ConstitutionScaleResult.scaleScores` 改为可选（运行时 `constitutionRadarData` 本就用 `??` 回退到 `scores*100`）
