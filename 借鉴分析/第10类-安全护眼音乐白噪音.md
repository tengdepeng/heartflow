# 第10类 · 安全 / 护眼 / 音乐 / 白噪音（13个）

> **核心答案**：安全怎么兜底、屏幕怎么护
> **影响模块**：模块六·守护室 / 感知层
> **宪法兼容**：无障碍自动化仅本地运行、不联网不收集数据；护眼能力本地计算；加速器/代理类仅作网络能力参考（本地化）；拒绝推送轰炸与云端依赖。

---

## 一、蓝图规格内 App（10个）

### 1. 李跳跳（无障碍服务自动化）
- **核心功能**：以「自动跳过开屏广告」为核心，通过检测应用开屏页面的「跳过」按钮位置并自动模拟点击，帮助用户跳过应用启动广告。应用体积小巧，不联网、不收集数据，完全在本地运行。
- **借鉴点**：
  1. 无障碍服务自动化——基于系统无障碍服务监听界面
  2. 极简体积——追求最小功能体积
  3. 完全离线运行——不联网、不收集数据
  4. 规则自定义——按应用配置跳过规则
  5. 日志记录——本地存储每次自动跳过记录
- **目标房间**：模块六·守护室 / 感知层

### 2. 夜间模式（超低亮度+蓝光过滤）
- **核心功能**：以「超低亮度+蓝光过滤」为核心，提供比系统最低亮度更暗的屏幕亮度和色温调节。多重护眼策略包括亮度遮罩、蓝光过滤、灰度模式，用户可独立调节每种策略的强度，也可选择预设组合。
- **借鉴点**：
  1. 多重护眼叠加——亮度遮罩/蓝光过滤/灰度模式
  2. 超低亮度模式——半透明黑色遮罩，0%-80% 可调
  3. 灰度模式——降低视觉刺激，可叠加蓝光过滤
  4. 定时启停——基于日出日落或自定义时间
  5. 快捷开关——通知栏磁贴，一键切换
- **目标房间**：模块六·守护室 / 感知层

### 3. 暮光（蓝光过滤与屏幕色温自适应）
- **核心功能**：以「昼夜节律感知型屏幕护眼」为核心，构建从日落到日出的完整屏幕色温自适应调节系统。应用根据日出日落时间自动调整蓝光分量与暖色调，并提供色温、强度、低亮度等个性化参数。
- **借鉴点**：
  1. 蓝光过滤——基于地理位置计算色温过渡曲线
  2. 日出日落自动启停——本地缓存计算结果
  3. 过滤强度与颜色自定义——色温 + 强度双维度
  4. 超低亮度模式——黑色遮罩 + 手势唤醒
  5. 特定应用暂停过滤——白名单机制
- **目标房间**：模块六·守护室 / 感知层

### 4. 熊猫去水印下载（多媒体内容下载与管理）
- **核心功能**：以「多媒体内容下载与管理」为核心，支持从多个平台下载视频、图片、音频内容，并自动去除水印。下载内容按来源平台、文件类型、下载时间自动分类，支持批量管理，并内置媒体播放器和图片浏览器。
- **借鉴点**：
  1. 内容聚合管理——按来源/类型/时间分类
  2. 批量文件管理——删除/移动/重命名
  3. 内置媒体预览——内置播放器和图片浏览器
  4. 下载历史——时间线展示，搜索筛选
  5. 本地存储管理——文件占用空间可视化
- **目标房间**：模块一·输出管理 / 模块三十三·书签与入口架（收藏部分）

### 5. 音乐标签（音乐元数据批量编辑）
- **核心功能**：以「音乐文件元数据编辑」为核心，支持编辑本地音乐文件的 ID3 标签，包括标题、艺术家、专辑、年份、流派、封面等。支持批量标签编辑，并可从文件名自动解析标签信息。
- **借鉴点**：
  1. 批量标签编辑——同时选中多个文件修改标签
  2. 自动标签解析——从文件名解析艺术家/歌曲名等
  3. 封面管理——嵌入/替换/删除封面图片
  4. 标签模板——预设常用标签组合
  5. 文件重命名——基于标签信息批量重命名
- **目标房间**：模块十·经略阁 / 模块一·输出管理

### 6. 超级小爱（全域语音助手与主动服务）
- **核心功能**：是小米 HyperOS 的全域语音助手，核心功能是通过语音交互完成设备控制、信息查询、任务执行等操作。设计理念是「全域覆盖+主动服务」，覆盖系统设置、应用操作、内容搜索、智能家居控制等全域场景。
- **借鉴点**：
  1. 全域语音交互——镜我「语音对话」
  2. 多模态输入融合——镜我「多模态输入」
  3. 全双工自然对话——镜我「全双工对话」
  4. 主动场景服务——镜我「主动服务」
  5. 上下文连续理解——镜我「上下文记忆」
- **目标房间**：模块七·镜我 / 感知层

### 7. 小米澎湃AI引擎（端侧AI推理引擎与模型调度）
- **核心功能**：是小米 HyperOS 的端侧 AI 推理框架，核心功能是在手机本地运行 AI 模型，实现图像识别、语音转文字、自然语言理解、智能推荐等 AI 能力，无需联网。
- **借鉴点**：
  1. 端侧 AI 推理引擎——镜我「本地推理引擎」
  2. CPU/GPU/NPU 自动调度——感知层「算力调度」
  3. 模型动态加载与卸载——镜我「模型管理」
  4. 标准化 AI 能力 API——感知层「AI 能力接口」
  5. 端侧优先+云端增强——镜我「混合推理」
- **目标房间**：模块七·镜我 / 感知层

### 8. 小米AI服务（系统级AI服务框架与多模态感知）
- **核心功能**：是小米 HyperOS 的系统级 AI 服务框架，为系统中的各项智能功能提供统一的 AI 能力支撑。核心功能包括：智能场景识别、多模态感知融合、主动服务推送。
- **借鉴点**：
  1. 智能场景识别——感知层「场景感知」
  2. 多模态感知融合——感知层「感知融合」
  3. 主动服务推送——镜我「主动关怀」
  4. 场景自适应模式切换——守护室「场景自适应」
  5. 个人 AI 画像学习——镜我「习惯学习」
- **目标房间**：感知层 / 模块七·镜我 / 模块六·守护室

### 9. 系统桌面（桌面启动器与空间布局）
- **核心功能**：是小米 HyperOS 的桌面启动器，核心功能是管理手机主屏幕的应用图标、小组件、文件夹和负一屏。设计哲学是「空间即组织」。
- **借鉴点**：
  1. 网格化空间布局——空间管理「房间网格」
  2. 文件夹聚合容器——空间管理「房间组」
  3. 负一屏信息聚合——全局 UI「信息面板」
  4. 手势触发多层空间——手势系统「空间手势」
  5. 小组件灵活放置——全局 UI「桌面小组件」
- **目标房间**：模块〇·数据可视化自定义体系 / 空间管理 / 手势系统

### 10. 小组件盒子（桌面小组件生态）
- **核心功能**：将时钟、日历、天气、待办、倒计时、习惯打卡、步数、电池、照片等分散信息展示需求统一为可组合、可定制的小组件体系。
- **借鉴点**：
  1. 组件化信息卡片设计——全局 UI「信息卡片组件」
  2. 数据看板聚合展示——引力场画布「数据看板」
  3. 小组件主题一键切换——核心组件库「主题系统」
  4. 倒计时/进度环组件——核心组件库「进度环组件」
  5. 日历热力图组件——核心组件库「日历热力图」
- **目标房间**：模块〇·数据可视化自定义体系

## 三、落地要点小结（模块六·守护室 / 感知层）

1. **安全兜底**：吸收李跳跳——无障碍自动化本地运行、不联网不收集数据、规则自定义。
2. **屏幕护眼**：吸收夜间模式/暮光——超低亮度、蓝光过滤、灰度模式、日出日落自动启停、白名单。
3. **端侧 AI**：吸收小米澎湃AI引擎/小米AI服务——端侧推理引擎、算力调度、场景感知、多模态融合（本地化）。
4. **语音助手**：吸收超级小爱——全域语音、全双工对话、主动场景服务（本地化，拒绝云端）。
5. **桌面与组件**：吸收系统桌面/小组件盒子——网格空间、信息面板、组件化卡片、主题切换。
6. **网络能力**：Clash Meta/OurPlay/UU 仅作网络能力参考，本地化。
7. **拒绝**：云端依赖、推送轰炸、数据收集、广告。
