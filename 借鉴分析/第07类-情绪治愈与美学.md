# 第7类 · 情绪 / 治愈 / 美学（14个）

> **核心答案**：怎么让界面看起来"温柔"
> **影响模块**：模块四·情绪花房 / 模块六·守护室
> **宪法兼容**：白噪音/冥想/治愈类全部本地音源；拒绝云端音乐依赖、社交分享、冥想课程付费墙；界面美学吸收「温柔感」但保持可自定义。

---

## 一、蓝图规格内 App（3个）

### 1. 鸭鸭快乐盒（快乐收集与情绪管理）
- **核心功能**：以「快乐收集与情绪管理」为核心，通过收集日常中的快乐瞬间来提升幸福感。快乐收集和情绪记录的交互模式可借鉴到情绪花房。
- **借鉴点**：
  1. 快乐瞬间收集——情绪花房「快乐收集」
  2. 情绪盒子——情绪花房「情绪盒子」
  3. 随机回顾——情绪花房「随机回顾」
  4. 情绪统计——情绪花房「情绪统计」
- **目标房间**：模块四·情绪花房

### 2. 爱鸭手帐（手帐创作与贴纸素材）
- **核心功能**：以「手帐鸭」IP 形象为核心，打造拼贴式手帐创作工具，用户可在画布上自由放置文字、贴纸、图片、胶带等元素。
- **借鉴点**：
  1. 画布式自由排版引擎——情绪花房手帐编辑页
  2. 素材库浏览与选用——情绪花房内置本地素材库
  3. 时间卷轴管理——逐日心锚「时间卷轴」
  4. 月历视图——逐日心锚日历视图
  5. 手帐元素独立变换——情绪花房画布每个元素独立图层
- **目标房间**：模块四·情绪花房 / 模块五·逐日心锚

### 3. 潮汐（白噪音与冥想）
- **核心功能**：把白噪音、冥想引导与番茄钟、睡眠结合，用声音搭建可切换的环境：下雨、海浪、篝火、风铃，以及有引导语的冥想段落。
- **借鉴点**：
  1. 白噪音场景——守护室「声音场景」
  2. 冥想引导——守护室「冥想」
  3. 定时伴睡——梦乡小筑「睡前声音」
  4. 声音预设管理——守护室「声音库」
  5. 心境前后对照——守护室「冥想回顾」
  6. 睡眠场景衔接——梦乡小筑「睡眠记录」
- **目标房间**：模块六·守护室 / 模块三十八·梦乡小筑

## 二、补充参考 App（11个，通用产品知识）

### 4. 元气壁纸（治愈系壁纸）
- **核心功能**：提供治愈系、元气系壁纸资源，以明亮温暖的视觉风格营造好心情。
- **借鉴点**：
  1. 治愈系视觉——情绪花房/守护室「温柔感」配色参考
  2. 壁纸主题——模块〇「主题系统」壁纸素材
  3. 每日更新——本地壁纸轮换
- **目标房间**：模块四·情绪花房 / 模块〇·数据可视化自定义体系

### 5. 人工桌面（桌面宠物）
- **核心功能**：桌面虚拟角色/宠物应用，角色可互动、陪伴、反馈，营造「有人陪着」的氛围。
- **借鉴点**：
  1. 桌面陪伴角色——情绪花房「花房精灵」/守护室「守护灵」
  2. 互动反馈——角色对用户操作的回应
  3. 拟人化陪伴——镜我「安静陪伴者」的视觉层
- **目标房间**：模块四·情绪花房 / 模块六·守护室 / 模块七·镜我

### 6. Salt Player（本地音乐播放器）
- **核心功能**：以「本地音乐播放」为核心的高质量播放器，注重音质、极简 UI 与本地曲库管理。
- **借鉴点**：
  1. 本地曲库——守护室/情绪花房本地音源
  2. 极简 UI——「温柔感」界面参考
  3. 高质量播放——沉浸式听感
- **目标房间**：模块四·情绪花房 / 模块六·守护室 / 模块〇·数据可视化自定义体系（UI部分）

### 7. 洛雪音乐（本地音乐播放）

## 三、落地要点小结（模块四·情绪花房 / 模块六·守护室）

1. **快乐收集**：吸收鸭鸭快乐盒——快乐瞬间收集、情绪盒子、随机回顾。
2. **手帐创作**：吸收爱鸭手帐——画布式自由排版、本地素材库、元素独立图层。
3. **声音环境**：吸收潮汐/小睡眠/潮汐白噪音——白噪音场景、冥想引导、定时伴睡、呼吸引导。
4. **温柔美学**：吸收元气壁纸/人工桌面/Salt Player——治愈系配色、陪伴角色、极简 UI。
5. **冥想体系**：吸收冥想星球/Now冥想/Headspace/Calm——冥想课程、睡眠故事、渐进式引导（本地化、无付费墙）。
6. **拒绝**：云端音乐依赖、社交分享、冥想课程付费墙、推送轰炸。
