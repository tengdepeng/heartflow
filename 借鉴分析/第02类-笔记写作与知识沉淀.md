# 第2类 · 笔记 / 写作 / 知识沉淀（18个）

> **核心答案**：写东西、存东西、找东西
> **影响模块**：模块九·思绪书房
> **宪法兼容**：全部本地优先；拒绝云同步、协作、集市；flomo/思源/Notion 的云端能力一律改造为本地存储。

---

## 一、蓝图规格内 App（9个）

### 1. flomo 浮墨笔记（轻量卡片笔记）
- **核心功能**：以「无压记录」为核心哲学，通过极简输入框让用户像发短信一样键入内容并保存为卡片，用标签体系形成自底向上的涌现式分类。
- **借鉴点**：
  1. 零摩擦卡片输入——思绪书房「极简模式」
  2. 内联标签系统——内容中以标签自然生长
  3. 标签热力云——经略阁标签面板可视化
  4. 流式时间线——反向时间流展示卡片
  5. 每日回顾引擎——加权随机选取卡片回顾
- **目标房间**：模块九·思绪书房 / 模块十·经略阁

### 2. 思源笔记（本地优先知识管理）
- **核心功能**：以本地优先、块级粒度、双向链接为核心，将数据以本地文件系统存储，通过 wiki 链接建立正向引用，并自动维护反向链接图谱。
- **借鉴点**：
  1. 本地优先文件存储——所有知识数据以本地 JSON/文件系统存储
  2. 块级内容模型——每条知识条目作为独立可寻址内容块
  3. 双向链接——`[[条目名]]` 语法
  4. 块引用嵌入——书签条目引用殿堂辞典定义块
  5. 快照版本控制——数据资产层定期自动创建数据快照
- **目标房间**：模块九·思绪书房 / 模块十·经略阁 / 模块三十三·书签与入口架

### 3. 幕布（大纲思维导图双视图）
- **核心功能**：将结构化思考拆成两步：先用大纲列表快速捕捉线性思路，再一键切换为思维导图获得全局视角。
- **借鉴点**：
  1. 大纲树形编辑器——思绪书房「大纲模式」
  2. 大纲到导图一键切换——引力场画布「从大纲生成」
  3. 层级折叠/展开和节点缩进——思绪书房节点操作
  4. 专注模式——聚焦当前节点及其子孙节点
  5. 多格式导出——大纲导出到输出管理
- **目标房间**：模块九·思绪书房 / 模块一·输出管理

### 4. 纯纯写作（沉浸式写作）
- **核心功能**：以打字机滚动模式为核心，将光标固定在屏幕中央三分之一处，文字随输入向上滚动，营造沉浸式写作节奏。
- **借鉴点**：
  1. 打字机滚动模式——编辑器光标固定居中、文本向上滚动
  2. 即时自动保存——每击键触发 SQLite 增量写入
  3. 版本历史「时光机」——数据资产层 Snapshot 表
  4. 快速草稿入口——思绪书房「速写」模式
  5. 沉浸模式——全屏写作模式
- **目标房间**：模块九·思绪书房

### 5. 有道云笔记（多类型笔记与语音速记）
- **核心功能**：以「全类型内容创作中枢」为理念，将文字笔记、手写笔记、语音速记、拍照扫描、PDF 标注、待办清单统一在一个平台中。
- **借鉴点**：
  1. 多类型笔记融合——思绪书房「多模态笔记编辑器」
  2. 多级文件夹层级管理——经略阁「知识树」
  3. 语音速记——思绪书房「声纹笔记」（录音+实时转文字+时间轴同步）
  4. 文档扫描——思绪书房「扫墨」
  5. 全文搜索——思绪书房「万象搜索」
- **目标房间**：模块九·思绪书房 / 模块十·经略阁 / 模块一·输出管理（导出部分）

### 6. 轻羽写作（轻量专业写作）
- **核心功能**：在移动端构建专业写作工作流，支持 Markdown 源码与富文本预览切换、大纲式写作、思维导图模式和专注模式。
- **借鉴点**：
  1. Markdown 编辑器 + 实时预览——思绪书房「双栏编辑器」
  2. 大纲式写作——思绪书房「大纲视图」
  3. 思维导图模式——思绪书房「导图模式」
  4. 专注模式——思绪书房「沉浸模式」
  5. 版本历史——思绪书房「写作安全网」（自动保存+手动快照+左右对比）
- **目标房间**：模块九·思绪书房 / 模块一·输出管理（导出部分）

### 7. 云上写作（专业写作工作台）
- **核心功能**：面向专业写作者，围绕「结构化创作，渐进式完稿」，将写作拆为大纲、章节、段落，并提供树形目录、章节统计、角色/场景卡片和专注模式。
- **借鉴点**：
  1. 树形章节目录结构——思绪书房「笔记树」
  2. 写作统计仪表盘——输出管理「写作统计」
  3. 大纲编辑器——思绪书房「大纲视图」
  4. 角色/场景卡片管理——思绪书房「角色卡片」
  5. 专注模式编辑器——思绪书房「专注模式」
- **目标房间**：模块九·思绪书房 / 模块一·输出管理（导出部分）

### 8. 简记事（三合一轻量管理）
- **核心功能**：将记事本、待办清单、日历备忘融合为统一轻量应用，支持 Markdown 内联编辑、实时渲染、待办复选框、日历统一视图和全应用密码锁。
- **借鉴点**：
  1. 三合一融合架构——思绪书房与更漏「日课桥接」
  2. Markdown 内联编辑 + 实时渲染——思绪书房「双栏实时预览」
  3. 待办复选框——`- [ ]` 渲染为可交互复选框
  4. 子任务层级结构——更漏「任务树」
  5. 日历统一视图——更漏「日课历」月视图
- **目标房间**：模块九·思绪书房 / 模块二十一·更漏

### 9. Notion AI（AI文档生成与就地写作增强）
- **核心功能**：核心不是「对话式问答」，而是「就地生成」。AI 能力以编辑器内嵌功能形式存在，用户正在写什么，AI 就基于上下文续写、扩写、总结、改语气或生成大纲与表格。生成结果先以草案形式呈现，经用户确认后才写入。
- **借鉴点**：
  1. 就地生成——编辑器内嵌 AI 能力，不中断创作流
  2. 基于当前文本上下文生成——续写/扩写/总结/改语气
  3. 生成结果先草案呈现，确认后写入
  4. AI 大纲与表格生成——基于文档结构生成
  5. 本地执行——创作主权在用户手中
- **目标房间**：模块九·思绪书房 / 模块十七·字镜阁 / 模块一·输出管理

## 二、补充参考 App（9个，通用产品知识）

### 10. Obsidian（本地双链笔记）
- **核心功能**：本地 Markdown 笔记库，以双向链接与图谱为核心，插件生态丰富，数据完全存于本地文件夹。
- **借鉴点**：
  1. 本地 Markdown 库——思绪书房本地文件存储
  2. 双向链接与关系图谱——知识关联可视化
  3. 图谱视图——笔记网络一屏总览
  4. 插件化扩展——功能按需装配
- **目标房间**：模块九·思绪书房 / 模块十·经略阁

### 11. Logseq（大纲式双链笔记）
- **核心功能**：大纲式（outliner）本地笔记，以块为单位组织，支持双向链接、日记流与白板（canvas）。
- **借鉴点**：
  1. 大纲式组织——思绪书房「大纲模式」
  2. 块级双向链接——`[[块]]` 引用
  3. 日记流——逐日心锚与笔记联动
  4. 白板——引力场画布的笔记化
- **目标房间**：模块九·思绪书房

### 12. Roam Research（双链笔记鼻祖）
- **核心功能**：首创块级双向链接与「每日笔记」工作流，以图谱组织知识，强调「无结构输入，结构化输出」。
- **借鉴点**：
  1. 每日笔记工作流——思绪书房与逐日心锚联动
  2. 块级引用与反链——知识复用
  3. 图谱化知识网络——经略阁知识星图
- **目标房间**：模块九·思绪书房 / 模块十·经略阁

### 13. Bear（极简 Markdown 笔记）
- **核心功能**：以极简美学著称的 Markdown 笔记应用，支持标签嵌套、主题切换、导出多种格式。
- **借鉴点**：
  1. 极简美学——思绪书房的视觉基调
  2. 嵌套标签——标签体系
  3. 多格式导出——输出管理
- **目标房间**：模块九·思绪书房

### 14. Ulysses（长文写作）
- **核心功能**：面向长文写作的 Markdown 编辑器，以「文稿库」组织碎片与成稿，支持目标设定、附件管理与多格式导出。
- **借鉴点**：
  1. 文稿库——碎片到成稿的流转
  2. 写作目标——字数/时间目标
  3. 多格式导出——输出管理
- **目标房间**：模块九·思绪书房

### 15. iA Writer（专注写作）
- **核心功能**：极简专注写作工具，以「内容优先」为理念，支持 Markdown、语法高亮、专注模式与文稿库。
- **借鉴点**：
  1. 内容优先排版——思绪书房沉浸模式
  2. 语法高亮——Markdown 实时渲染
  3. 专注模式——全屏无干扰
- **目标房间**：模块九·思绪书房

### 16. Typora（所见即所得 Markdown）
- **核心功能**：所见即所得的 Markdown 编辑器，输入即渲染，支持主题、导出与大纲。
- **借鉴点**：
  1. 所见即所得——思绪书房实时渲染
  2. 大纲面板——文档结构导航
  3. 主题系统——可换肤
- **目标房间**：模块九·思绪书房

### 17. Notability（手写笔记）
- **核心功能**：iPad 手写笔记应用，支持手写、录音同步、PDF 标注与多笔记管理，以「录音+手写回放」著称。
- **借鉴点**：
  1. 手写笔迹——思绪书房「手写模式」
  2. 录音同步回放——笔记与音频时间轴绑定
  3. PDF 标注——书签入口架「PDF 标注」
- **目标房间**：模块九·思绪书房 / 模块三十三·书签与入口架

### 18. GoodNotes（手写笔记）
- **核心功能**：iPad 手写笔记应用，以真实纸张体验、手写识别搜索、笔记本组织为特色。
- **借鉴点**：
  1. 手写识别搜索——思绪书房手写转文字
  2. 纸张模板——思绪书房「纸张模板」
  3. 笔记本组织——经略阁「笔记本」
- **目标房间**：模块九·思绪书房 / 模块十·经略阁

## 三、落地要点小结（模块九·思绪书房）

1. **无压记录**：吸收 flomo「零摩擦卡片输入」——思绪书房极简模式，先记后理。
2. **块级 + 双向链接**：吸收思源/Obsidian/Logseq/Roam——块级内容模型 + `[[双链]]` + 反链图谱，本地 JSON 存储。
3. **大纲 ⇄ 导图**：吸收幕布/XMind——大纲与思维导图一键互转。
4. **沉浸写作**：吸收纯纯写作/iA Writer/Typora——打字机滚动、所见即所得、全屏专注。
5. **多模态笔记**：吸收有道云/Notability/GoodNotes——文本/手写/语音/扫描混排。
6. **就地 AI 写作**：吸收 Notion AI——编辑器内嵌 AI，草案确认制，本地执行。
7. **拒绝**：云同步、协作、集市、社交分享。
