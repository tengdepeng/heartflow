# 第3类 · 知识图谱 / 学习工具（16个）

> **核心答案**：知识怎么串成网
> **影响模块**：模块十·经略阁 / 模块三十四·知微阁
> **宪法兼容**：间隔重复、卡片记忆、图谱可视化均本地化；拒绝游戏化排行、XP/等级、积分、连续签到压力；多邻国固定引导改为可关闭/可替换。

---

## 一、蓝图规格内 App（9个）

### 1. 氢刻（间隔重复记忆系统）
- **核心功能**：采用类 Anki 的 SM-2 间隔重复算法，将任意知识点封装为可复用的卡片模板（基础问答、填空遮盖、图片遮挡、多项选择），并自动根据用户每次回忆的难度自评生成下一次复习时间。
- **借鉴点**：
  1. SM-2 间隔重复算法——知微阁规则引擎
  2. 卡片模板系统——支持多种题型
  3. 记忆曲线可视化——艾宾浩斯曲线与个人复习历史并列展示
  4. 牌组与标签双层组织知识
  5. 复习统计——成长庭院数据面板
- **目标房间**：模块三十四·知微阁 / 模块十·经略阁

### 2. 墨墨背单词（自适应间隔算法）
- **核心功能**：以后端艾宾浩斯遗忘曲线为基础的自适应间隔算法为核心，根据每个单词的遗忘临界点动态调整复习时间。
- **借鉴点**：
  1. 自适应间隔算法——知微阁记忆引擎
  2. 三档反馈（认识/模糊/不认识）——知微阁复习卡片按钮
  3. 遗忘曲线可视化——数据可视化「遗忘曲线」
  4. 每日学习计划——知微阁「每日记忆计划」
  5. 学习日历热力图——自律工坊学习日历
- **目标房间**：模块三十四·知微阁 / 模块十·经略阁

### 3. Quizlet（闪卡学习系统）
- **核心功能**：以「闪卡」为原子知识单元，支持文字、图片、音频三种媒体类型的混合录入。提供学习模式、闪卡模式、书写模式、拼写模式、测试模式、配对游戏等多种练习方式。每张卡片维护状态，并基于遗忘曲线安排复习。
- **借鉴点**：
  1. 闪卡原子结构——双面卡片 + 富文本编辑 + 3D 翻转动画
  2. 多模式练习引擎——翻转/选择/默写/听写/配对
  3. 智能学习路径——新卡片→研磨中→已通透→待回炉
  4. 间隔重复调度——基于本地遗忘曲线算法
  5. 测试卷自动生成——选择题/判断题/填空题/配对题
- **目标房间**：模块三十四·知微阁 / 模块十·经略阁

### 4. 不背单词（真实语境学习）
- **核心功能**：以「真实语境记忆」为核心，从电影原声、英美剧台词、新闻、TED 演讲、经典文学等真实语料中精选例句，并结合词根词缀可视化和艾宾浩斯复习引擎。
- **借鉴点**：
  1. 多源真实语料例句——知微阁「多源语境卡片」
  2. 词根词缀可视化拆解——知微阁「知识拆解面板」
  3. 词根衍生词树形图——知微阁「知识派生图谱」
  4. 艾宾浩斯遗忘曲线间隔复习——知微阁「间隔回响」
  5. 知识包——知微阁「知识包」
- **目标房间**：模块三十四·知微阁

### 5. 欧路背单词（词典+背单词一体化）
- **核心功能**：以「词典+背单词一体化」为核心，将权威词典与间隔重复记忆系统融合。阅读中遇到生词时，长按查词可显示词典释义，并将该词加入生词本与复习计划。系统支持多本权威词典和听力训练。
- **借鉴点**：
  1. 查词即学习——阅读中查词→加入复习计划
  2. 多词典切换——自由切换，对比释义风格
  3. 间隔重复复习引擎——遗忘曲线 + 原词/释义/例句/发音
  4. 生词本管理——分组/标签/排序/筛选/搜索
  5. 听力训练——标准发音/调速/跟读/听写
- **目标房间**：模块三十四·知微阁 / 模块十·经略阁

### 6. 百词斩托福（图背单词+多感官学习）
- **核心功能**：以「图背单词+语境记忆」为核心，为每个单词配图，建立单词与视觉形象的直接关联。单词学习同时调动视觉、听觉、语义和情境四个认知通道。用户可选择「认识/模糊/不认识」反馈等级，系统据此调整复习计划。
- **借鉴点**：
  1. 图背单词——配图 + 释义 + 发音
  2. 多感官学习——视觉/听觉/语义/情境
  3. 自适应复习计划——根据反馈动态调整
  4. 真题语境——真题例句 + 场景描述
  5. 学习进度仪表盘——已学/掌握/每日时长/连续天数
- **目标房间**：模块三十四·知微阁 / 模块十六·自律工坊

### 7. 背书匠（渐进式背诵与准确率追踪）
- **核心功能**：以「背诵辅助工具」为核心，帮助用户记忆课文、诗词、演讲稿、法律条文等文本内容。系统通过逐步遮盖关键词，让用户从遮盖 20% 逐步到遮盖 100%，直到完整背诵。每次背诵记录准确率、用时和错误位置。
- **借鉴点**：
  1. 渐进式背诵——20%→100% 遮盖比例
  2. 背诵准确率追踪——进步曲线 + 错误位置高亮
  3. 多类型文本支持——课文/诗词/演讲稿/法律条文
  4. 语音朗读——TTS + 跟读对比
  5. 错误标记——反复出错位置集中强化
- **目标房间**：模块三十四·知微阁 / 模块十六·自律工坊

### 8. Readable（分级阅读与水平适配）
- **核心功能**：以「分级阅读+英语学习」为核心，提供与用户英语水平匹配的阅读材料。用户首次使用时完成水平测评，系统根据结果推荐 A1 到 C2 的阅读材料。每篇文章标注词汇量、难度等级和预估阅读时间，并支持生词自动加入生词本。
- **借鉴点**：
  1. 分级阅读——基于用户水平推荐材料
  2. 水平测评——词汇/语法/阅读综合测试
  3. 阅读中查词——点击生词释义→自动加入生词本
  4. 文章标注——词汇量/难度等级/预估时间
  5. 生词复习——纳入间隔重复复习计划
- **目标房间**：模块三十四·知微阁 / 模块十·经略阁

### 9. 无痛单词（无痛单词记忆与极简交互）
- **核心功能**：以「无痛单词记忆」为核心，通过极简交互和游戏化设计降低背单词的心理负担。单词学习界面仅显示单词、配图、发音按钮和三个反馈按钮，每次学习推送少量新词和复习词。系统还展示遗忘曲线和词根词缀拆解。
- **借鉴点**：
  1. 轻量交互——极简界面，降低认知负荷
  2. 少量多次——每次不超过 20 个单词/5 分钟
  3. 游戏化激励——连续打卡/成就徽章，无排行榜
  4. 遗忘曲线可视化——折线图展示最佳复习时间
  5. 词根词缀拆解——展示词源和构词逻辑
- **目标房间**：模块三十四·知微阁 / 模块十六·自律工坊

## 二、补充参考 App（7个，通用产品知识）

### 10. Anki（间隔重复鼻祖）
- **核心功能**：开源间隔重复记忆软件，基于 SM-2 算法，卡片可自定义模板、媒体、牌组层级，支持插件扩展。
- **借鉴点**：
  1. SM-2 算法——知微阁记忆引擎基准
  2. 牌组层级——知识分层组织
  3. 卡片模板自定义——题型扩展
  4. 复习统计——遗忘曲线与复习量
- **目标房间**：模块三十四·知微阁

### 11. SuperMemo（间隔重复算法发源地）
- **核心功能**：间隔重复算法（SM-2/SM-5/SM-17）的发源地，强调「最优复习时间」与「记忆最优性」。
- **借鉴点**：
  1. 最优复习时间计算——知微阁调度引擎
  2. 记忆难度分级——复习优先级
  3. 增量阅读——知识渐进式吸收
- **目标房间**：模块三十四·知微阁

### 12. Memrise（游戏化语言学习）
- **核心功能**：以「真实母语者视频 + 间隔重复 + 游戏化」为特色的语言学习应用。
- **借鉴点**：
  1. 真实语境视频——知微阁语境卡片
  2. 间隔重复——记忆调度
  3. 游戏化激励——无排行的自我激励
- **目标房间**：模块三十四·知微阁

### 13. Duolingo（多邻国，游戏化学习引擎）
- **核心功能**：将学习变成游戏，构建多层激励引擎，以经验值（XP）、皇冠等级、连胜天数、宝石货币和成就徽章驱动学习。学习路径按知识节点组织，每个节点包含多个探索深度等级，并完成具体课节任务。（同蓝图 2.122/2.152 多邻国）
- **借鉴点**：
  1. 技能树关卡系统——知微阁「探索星图」
  2. 皇冠等级制——知微阁「探索深度标尺」（每个节点 5 级掌握度）
  3. 微学习单元——知微阁「微探索」
  4. 多种回顾模式交替——联想/闪卡/填空/配对/复述/应用
  5. 沉浸式故事/场景内容——知微阁「知识场景」
- **目标房间**：模块三十四·知微阁 / 模块十六·自律工坊

### 14. Coursera（在线课程平台）
- **核心功能**：全球在线课程平台，提供结构化课程（视频+测验+作业+证书），以「学习路径」组织多门课程。
- **借鉴点**：
  1. 结构化课程——知微阁「知识课程」
  2. 学习路径——系列课程编排
  3. 测验与作业——知识检验
  4. 进度追踪——学习完成度
- **目标房间**：模块三十四·知微阁 / 模块十·经略阁

### 15. edX（在线课程平台）
- **核心功能**：非营利在线课程平台，提供大学级课程，强调学术严谨与知识体系化。
- **借鉴点**：
  1. 学术课程体系——知微阁知识层级
  2. 模块化学习——章节化组织
  3. 讨论与练习——本地化改造为自我测验
- **目标房间**：模块三十四·知微阁

### 16. Khan Academy（可汗学院）
- **核心功能**：免费在线学习平台，以「知识掌握度」为核心，通过练习+视频+掌握度追踪，让学习者按自己的节奏学习。
- **借鉴点**：
  1. 掌握度追踪——知微阁「知识掌握度」
  2. 练习与即时反馈——自我测验
  3. 学习地图——知识依赖关系可视化
  4. 按节奏学习——无固定进度压力
- **目标房间**：模块三十四·知微阁 / 模块十·经略阁

## 三、落地要点小结（模块十·经略阁 / 模块三十四·知微阁）

1. **间隔重复引擎**：吸收氢刻/墨墨/Anki/SuperMemo——SM-2 自适应算法，三档反馈（认识/模糊/不认识），遗忘曲线可视化。
2. **卡片模板**：吸收 Quizlet/氢刻——双面卡片 + 富文本 + 多题型（填空/选择/默写/配对）。
3. **语境化学习**：吸收不背单词/Memrise/百词斩——真实语料例句、图背单词、多感官通道。
4. **渐进式背诵**：吸收背书匠——遮盖比例 20%→100%，准确率追踪。
5. **分级适配**：吸收 Readable——水平测评 + 分级推荐。
6. **知识图谱**：吸收星云笔记/词根树（见第2类关联）——知识串成网，力导向图可视化。
7. **游戏化克制**：吸收多邻国技能树/皇冠等级但**拒绝** XP/排行/积分/连续签到压力——改为「探索星图 + 深度标尺」的自我激励。
8. **拒绝**：云端同步、社交排行、评价评判。
