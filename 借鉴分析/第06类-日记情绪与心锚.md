# 第6类 · 日记 / 情绪 / 心锚（8个）

> **核心答案**：写日记、记情绪、打卡
> **影响模块**：模块四·情绪花房 / 模块五·逐日心锚
> **宪法兼容**：情绪记录「无好坏之分」，拒绝情感分析评判；隐私保护（应用锁/伪装模式/加密）本地化；拒绝社交分享与排行。

---

## 一、蓝图规格内 App（6个）

### 1. Moo日记（情绪优先日记）
- **核心功能**：以「情绪优先」为理念，用户在写日记前先选择心情表情符号，再选择天气、正文、标签和里程碑信息。
- **借鉴点**：
  1. 情绪优先输入——情绪花房「每日情绪打卡」
  2. 天气-情绪关联——情绪花房「外部因素」维度
  3. 日历热力图——情绪花房「情绪日历热力图」
  4. 多维度搜索——心情、天气、标签、日期和关键词组合筛选
  5. 图片日记——多图上传、排序和全屏查看
- **目标房间**：模块四·情绪花房 / 模块五·逐日心锚

### 2. YoYo日常（萌系日常打卡与情绪收集）
- **核心功能**：以「让日常记录变得可爱」为理念，通过萌系角色陪伴、轻量打卡、心情天气记录、小确幸收集和主题装扮，将日常记录转为治愈互动。
- **借鉴点**：
  1. 萌系陪伴角色——情绪花房「花房精灵」
  2. 轻量打卡——逐日心锚「每日锚点」
  3. 心情优先记录——情绪花房「每日情绪打卡」
  4. 小确幸收集——逐日心锚「心锚·小确幸」
  5. 装扮与收集系统——情绪花房「花房装扮」
- **目标房间**：模块四·情绪花房 / 模块五·逐日心锚

### 3. 墨记日记（水墨风格日记）
- **核心功能**：以中国传统水墨画美学融入日记写作，通过极简水墨视觉语言营造书写氛围，并自动关联心情、天气、时辰、节气、位置和自定义标签。
- **借鉴点**：
  1. 水墨极简 UI 语言——情绪花房「水墨晕染」
  2. 心情标签体系——逐日心锚「心绪七色」
  3. 日记元数据自动采集——逐日心锚自动抓取天气/时辰/节气
  4. 图文混排编辑器——思绪书房富文本编辑器
  5. 情绪花房浇水交互——心情与成长反馈
- **目标房间**：模块五·逐日心锚 / 模块四·情绪花房

### 4. 素忆日记（素雅日记与回归本真）
- **核心功能**：以「素雅、安静、回归本真」为理念，通过大量留白、低饱和度配色和无干扰全屏编辑，引导用户专注书写，并用心情标记和月视图情绪热力图回顾日常。
- **借鉴点**：
  1. 极简全屏编辑界面——逐日心锚沉浸式全屏布局
  2. 心情标记体系——逐日心锚「心绪调色盘」
  3. 月视图情绪热力图——逐日心锚「心锚历」
  4. 密码锁/指纹锁——逐日心锚「心锚锁」
  5. 全文检索加标签筛选——逐日心锚 Fuse.js 模糊搜索
- **目标房间**：模块五·逐日心锚 / 模块四·情绪花房

### 5. 花简空间（极简美学日记）
- **核心功能**：以「极简美学日记」为核心，通过极简界面和优雅交互，让写日记成为享受而非负担。日记没有字数要求、格式限制和必填字段，打开即写，并可自动保存。日记列表以时间轴形式展示，每篇显示日期和首行预览。
- **借鉴点**：
  1. 无压力日记——无字数/格式/必填要求
  2. 时间轴日记列表——日期 + 首行预览
  3. 心情标记——emoji 或颜色标记
  4. 主题/字体自定义——背景色/字体/间距
  5. 日记搜索——全文搜索 + 关键词/日期/心情筛选
- **目标房间**：模块四·情绪花房 / 模块五·逐日心锚

### 6. 一本日记（多媒体日记与隐私保护）
- **核心功能**：将隐私保护作为产品基石，支持应用锁、伪装模式、端到端加密存储，以及文字、图片、视频、录音等日记记录形式。
- **借鉴点**：
  1. 应用锁——逐日心锚全局入口锁（密码 + 生物识别双重认证）
  2. 伪装模式——逐日心锚「静默模式」（输入伪装密码进入空界面）
  3. 日记加密存储——逐日心锚 AES-256 加密
  4. 多媒体记录——逐日心锚支持图片/视频/录音/心情/天气/标签
  5. 日历回溯——逐日心锚月视图日历（情绪色块标记）+「那年今日」
- **目标房间**：模块五·逐日心锚 / 模块四·情绪花房

## 二、补充参考 App（2个，通用产品知识）

### 7. Day One（经典日记应用）
- **核心功能**：以「记录生活」为核心的经典日记应用，支持多日记本、自动元数据（天气/位置/步数/音乐）、时间线回顾、照片日记与「On This Day」回忆。
- **借鉴点**：
  1. 多日记本——逐日心锚「多锚点本」
  2. 自动元数据——天气/位置/步数自动采集
  3. On This Day——「那年今日」回顾
  4. 时间线回顾——逐日心锚「时间流」
- **目标房间**：模块五·逐日心锚 / 模块四·情绪花房

### 8. Journey（跨平台日记）
- **核心功能**：跨平台日记应用，支持 Markdown 编辑、心情标签、日历视图、照片日记与端到端加密。
- **借鉴点**：
  1. 心情标签——逐日心锚「心绪标记」
  2. 日历视图——逐日心锚「心锚历」
  3. 端到端加密——本地加密存储
  4. Markdown 编辑——日记富文本
- **目标房间**：模块五·逐日心锚 / 模块四·情绪花房

## 三、落地要点小结（模块四·情绪花房 / 模块五·逐日心锚）

1. **情绪优先输入**：吸收 Moo/YoYo——先选心情再写正文，情绪无好坏之分。
2. **六步闭环**：吸收 YoYo 微小锚点 + 时光胶囊——逐日心锚「倾倒→安放→手札→完成→推迟→放回」。
3. **隐私保护**：吸收一本日记——应用锁、伪装模式、AES-256 加密、多媒体记录。
4. **水墨美学**：吸收墨记日记/素忆日记——水墨晕染、低饱和配色、留白。
5. **时间轴与回顾**：吸收花简空间/Day One——时间轴列表、On This Day、情绪热力图。
6. **拒绝**：情感分析评判、社交分享、排行、推送轰炸。
