# 快背中医（间隔重复 + 游戏化中医记忆）

> **所属大类**：第4类 · 词典 / 汉字 / 古籍
> **对应房间**：模块三十四·知微阁 / 模块十六·自律工坊
> **宪法兼容**：间隔重复与卡片化本地化；游戏化克制（拒绝排行榜与签到压力）。

## 核心功能
以「间隔重复 + 游戏化」为核心，将中药功效、方剂组成、穴位定位等中医知识拆解为最小记忆单元。每味中药、每个方剂、每个穴位封装为知识卡片，用户通过闪卡、选择题、填空默写等模式复习。

## 抄作业借鉴点
1. 中医知识卡片化 —— 正面名称，背面详情
2. 间隔重复复习引擎 —— 遗忘曲线 + 动态频率调整
3. 多模式复习 —— 闪卡 / 选择题 / 填空默写
4. 学习进度追踪 —— 日历热力图 + 连续学习天数
5. 困难攻克 —— 反复出错卡片自动标记

## 落地要点（对应房间）
- **模块三十四·知微阁**：中医知识卡片化、间隔重复引擎、多模式复习、学习进度热力图、困难攻克标记（反复出错卡片自动标记）。
- **模块十六·自律工坊**：学习日历热力图与打卡（低压力）。
