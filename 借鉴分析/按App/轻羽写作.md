# 轻羽写作（轻量专业写作 + 导出）

> **所属大类**：第2类 · 笔记 / 写作 / 知识沉淀（写作部分）+ 第14类 · 输出 / 导出 / 文件管理（导出部分）
> **对应房间**：模块九·思绪书房 / 模块一·输出管理
> **宪法兼容**：写作与导出全本地；拒绝云同步，多格式导出本地完成。

## 核心功能
在移动端构建专业写作工作流，支持 Markdown 源码与富文本预览切换、大纲式写作、思维导图模式和专注模式。支持 Markdown / Word / PDF 等格式导出与版本历史。

## 抄作业借鉴点
1. Markdown 编辑器 + 实时预览 —— 思绪书房「双栏编辑器」
2. 大纲式写作 —— 思绪书房「大纲视图」
3. 思维导图模式 —— 思绪书房「导图模式」
4. 专注模式 —— 思绪书房「沉浸模式」
5. 版本历史 —— 思绪书房「写作安全网」（自动保存 + 手动快照 + 左右对比）
6. 多格式导出 / 版本历史 —— 输出管理「格式导出 / 版本快照」

## 落地要点（对应房间）
- **模块九·思绪书房**：双栏编辑器、大纲视图、导图模式、沉浸模式、写作安全网。
- **模块一·输出管理**：多格式导出与版本快照。
