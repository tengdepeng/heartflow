# Day One（经典日记应用）

> **所属大类**：第6类 · 日记 / 情绪 / 心锚
> **对应房间**：模块五·逐日心锚 / 模块四·情绪花房
> **宪法兼容**：自动元数据本地采集；拒绝云端同步与社交分享。

## 核心功能
以「记录生活」为核心的经典日记应用，支持多日记本、自动元数据（天气 / 位置 / 步数 / 音乐）、时间线回顾、照片日记与「On This Day」回忆。

## 抄作业借鉴点
1. 多日记本 —— 逐日心锚「多锚点本」
2. 自动元数据 —— 天气 / 位置 / 步数自动采集
3. On This Day ——「那年今日」回顾
4. 时间线回顾 —— 逐日心锚「时间流」

## 落地要点（对应房间）
- **模块五·逐日心锚**：多锚点本、自动元数据采集（天气 / 位置 / 步数）、那年今日回顾、时间流。
- **模块四·情绪花房**：情绪时间线回顾。
