# 中医通（中医知识一站式学习平台）

> **所属大类**：第4类 · 词典 / 汉字 / 古籍
> **对应房间**：模块十五·身体温室 / 模块三十四·知微阁
> **宪法兼容**：中医知识以「象」呈现、症状自查仅作参考不诊断；数据本地化。

## 核心功能
以「中医知识一站式学习平台」为核心，整合中医基础理论、诊断学、中药学、方剂学、针灸学和临床各科知识。知识点按「基础理论 → 诊断方法 → 治疗手段 → 临床应用」的递进关系组织，并建立交叉引用链接。

## 抄作业借鉴点
1. 中医知识体系化 —— 递进关系 + 交叉引用
2. 中药详情 —— 性味归经 / 功效主治 / 用法用量 / 配伍禁忌
3. 方剂详情 —— 组成 / 功效 / 方解 / 临床加减
4. 中医体质辨识 —— 问卷 + 体质类型 + 调理建议
5. 症状自查 —— 症状推演证型，关联方药和调理方法

## 落地要点（对应房间）
- **模块十五·身体温室**：体质画像（问卷 + 类型）、节气养生、药膳食谱（以「象」呈现，拒绝诊断建议）。
- **模块三十四·知微阁**：中药 / 方剂知识详情卡片、症状自查（仅作参考不诊断）、经络穴位知识。
