# 周公解梦（梦境记录与传统文化知识）

> **所属大类**：第4类 · 词典 / 汉字 / 古籍 + 第16类 · 保险库 / 梦境 / 众生象
> **对应房间**：模块三十八·梦乡小筑 / 模块三十四·知微阁
> **宪法兼容**：仅借鉴梦境记录 / 分类 / 统计 / 搜索的交互模式；不引入迷信解析内容，梦境记录本地私有。

## 核心功能
以「梦境解析与传统文化」为核心，基于《周公解梦》等古籍提供梦境解析。与心流工坊核心功能关联较弱，但梦境记录和解析的交互模式可借鉴到梦乡小筑的梦境记录功能。

## 抄作业借鉴点
1. 梦境记录 —— 梦乡小筑「梦境记录」
2. 梦境分类 —— 梦乡小筑「梦境分类」
3. 梦境统计 —— 梦乡小筑「梦境统计」
4. 梦境关键词搜索 —— 梦乡小筑「梦境搜索」

## 落地要点（对应房间）
- **模块三十八·梦乡小筑**：梦境记录、分类、统计、关键词搜索（仅记录与回顾，不引入迷信解析）。
- **模块三十四·知微阁**：梦境相关内容的知识化整理。
