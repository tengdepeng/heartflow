# 人工桌面（桌面宠物 UI）

> **所属大类**：第7类 · 情绪 / 治愈 / 美学（陪伴角色）+ 第12类 · 全局UI / 组件 / 主题（UI部分）
> **对应房间**：模块四·情绪花房 / 模块六·守护室 / 模块七·镜我 / 模块〇·数据可视化自定义体系
> **宪法兼容**：陪伴角色本地化、不收集数据；拒绝云端依赖与吉祥物化。

## 核心功能
桌面虚拟角色 / 宠物应用，角色可互动、陪伴、反馈，营造「有人陪着」的氛围。

## 抄作业借鉴点
1. 桌面陪伴角色 —— 情绪花房「花房精灵」/ 守护室「守护灵」
2. 互动反馈 —— 角色对用户操作的回应
3. 拟人化陪伴 —— 镜我「安静陪伴者」的视觉层

## 落地要点（对应房间）
- **模块四·情绪花房**：花房精灵（陪伴角色）。
- **模块六·守护室**：守护灵（陪伴角色）。
- **模块七·镜我**：拟人化陪伴的视觉层（安静陪伴者）。
- **模块〇·数据可视化自定义体系**：陪伴角色 UI 组件。
