# WorkBuddy（AI 工作伙伴与工作流自动化）

> **所属大类**：第1类 · AI对话 / 幕僚 / 镜我
> **对应房间**：模块七·镜我 / 模块二十一·更漏
> **宪法兼容**：工作流自动拆解本地执行；拒绝云端账号、评价性回复；仅保留「陈列而非叙事」。

## 核心功能
以「AI 工作伙伴」为核心，支持文档处理、会议纪要、任务管理、日程安排等办公场景。用户可通过自然语言描述工作任务，WorkBuddy 自动拆解为子任务、分配优先级、设置截止日期，并跨工具执行操作。

## 抄作业借鉴点
1. 工作流自动化 —— 自然语言描述 → 拆解子任务 → 设置优先级
2. 会议纪要生成 —— 录音转写 → 摘要 → 提取待办
3. 文档处理 —— AI 辅助写作 / 编辑 / 格式调整
4. 跨工具协同 —— 任务 / 日历 / 文档 / 导出联动
5. 自然语言交互 —— 自然语言描述需求，AI 理解并执行

## 落地要点（对应房间）
- **模块七·镜我**：镜我将用户自然语言心愿拆解为子任务，展示推理与调令结果。
- **模块二十一·更漏**：任务拆解 / 优先级 / 截止日期落到更漏任务管理。
