# 有道云笔记（多类型笔记 + 语音速记 + 导出）

> **所属大类**：第2类 · 笔记 / 写作 / 知识沉淀（笔记部分）+ 第14类 · 输出 / 导出 / 文件管理（导出部分）
> **对应房间**：模块九·思绪书房 / 模块十·经略阁 / 模块一·输出管理
> **宪法兼容**：本地存储优先；多模态笔记、语音速记、扫描均本地化；导出口径用户可控（拒绝外部分享链路）。

## 核心功能
以「全类型内容创作中枢」为理念，将文字笔记、手写笔记、语音速记、拍照扫描、PDF 标注、待办清单统一在一个平台中。支持笔记导出为多种格式、批量导出与备份。

## 抄作业借鉴点
1. 多类型笔记融合 —— 思绪书房「多模态笔记编辑器」
2. 多级文件夹层级管理 —— 经略阁「知识树」
3. 语音速记 —— 思绪书房「声纹笔记」（录音 + 实时转文字 + 时间轴同步）
4. 文档扫描 —— 思绪书房「扫墨」
5. 全文搜索 —— 思绪书房「万象搜索」
6. 多格式导出 —— 输出管理「格式导出」
7. 批量导出 / 备份恢复 —— 输出管理「批量导出 / 备份」

## 落地要点（对应房间）
- **模块九·思绪书房**：多模态笔记、语音速记、扫描、全文搜索。
- **模块十·经略阁**：多级文件夹「知识树」。
- **模块一·输出管理**：多格式导出（Markdown / Word / PDF / 图片）、批量导出、备份恢复。
