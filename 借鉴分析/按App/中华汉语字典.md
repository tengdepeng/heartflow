# 中华汉语字典（多维检索汉字字典）

> **所属大类**：第4类 · 词典 / 汉字 / 古籍
> **对应房间**：模块三十六·殿堂辞典 / 模块三十四·知微阁
> **宪法兼容**：多维检索全部本地离线；拒绝联网查询依赖。

## 核心功能
以「汉语学习的终极参考工具」为核心，构建覆盖拼音、部首、笔画、五笔、仓颉等多维检索体系的汉字字典。每个汉字不仅展示基本释义，还包含笔顺动画、字形演变（甲骨文 → 金文 → 篆书 → 楷书）、康熙字典原文、说文解字注、汉语大字典引用等多层级知识体系。

## 抄作业借鉴点
1. 多维汉字检索 —— 拼音 / 部首 / 笔画 / 手写 / 语音 / 拍照
2. 单字详情页 —— 基本释义 + 笔顺 + 字源演变 + 经典文献引用
3. 部首树形检索 —— 214 个部首树形结构
4. 笔顺动画 —— Canvas 逐笔绘制，调速与暂停
5. 生字收藏与复习 —— 列表 / 网格 + 多条件排序

## 落地要点（对应房间）
- **模块三十六·殿堂辞典**：多维（拼音 / 部首 / 笔画 / 手写 / 语音 / 拍照）检索、汉字详情页（释义 + 笔顺 + 字源演变 + 文献引用）、部首树形检索、笔顺动画（调速 / 暂停）、生字收藏复习。
- **模块三十四·知微阁**：汉字学习与生字复习联动。
