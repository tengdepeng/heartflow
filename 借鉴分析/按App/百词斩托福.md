# 百词斩托福（图背单词 + 多感官学习）

> **所属大类**：第3类 · 知识图谱 / 学习工具
> **对应房间**：模块三十四·知微阁 / 模块十六·自律工坊
> **宪法兼容**：多感官学习本地化；拒绝连续签到压力与排行榜。

## 核心功能
以「图背单词 + 语境记忆」为核心，为每个单词配图，建立单词与视觉形象的直接关联。单词学习同时调动视觉、听觉、语义和情境四个认知通道。用户可选择「认识 / 模糊 / 不认识」反馈等级，系统据此调整复习计划。

## 抄作业借鉴点
1. 图背单词 —— 配图 + 释义 + 发音
2. 多感官学习 —— 视觉 / 听觉 / 语义 / 情境
3. 自适应复习计划 —— 根据反馈动态调整
4. 真题语境 —— 真题例句 + 场景描述
5. 学习进度仪表盘 —— 已学 / 掌握 / 每日时长 / 连续天数

## 落地要点（对应房间）
- **模块三十四·知微阁**：图背单词、多感官学习、自适应复习计划、真题语境。
- **模块十六·自律工坊**：学习进度仪表盘、每日时长统计。
