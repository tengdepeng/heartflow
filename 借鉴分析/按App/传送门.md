# 传送门（智能文本识别与快捷操作）

> **所属大类**：第11类 · 感知 / 系统 / 设备
> **对应房间**：感知层 / 模块三十三·书签与入口架 / 模块三十四·知微阁
> **宪法兼容**：文本识别本地化、剪贴板历史本地存储；拒绝云端上传与行为追踪。

## 核心功能
是 MIUI 系统的智能文本识别与快捷操作组件，核心功能是在用户长按或选中文本时，自动识别文本中的实体类型（人名、地名、链接、快递单号、航班号等），并在屏幕底部弹出对应的快捷操作卡片。

## 抄作业借鉴点
1. 长按文本智能识别 —— 书签入口架「速查」
2. 实体类型自动分类 —— 感知层「文本感知」
3. 快递 / 航班自动追踪 —— 书签入口架「物流追踪」
4. 翻译 / 搜索快捷入口 —— 知微阁「速查工具」
5. 卡片式结果展示 —— 书签入口架「信息卡片」
6. 剪贴板历史 —— 感知层「剪贴板管理」

## 落地要点（对应房间）
- **感知层**：文本感知（实体自动分类）、剪贴板管理（历史）。
- **模块三十三·书签与入口架**：速查、物流追踪、信息卡片。
- **模块三十四·知微阁**：速查工具（翻译 / 搜索快捷入口）。
