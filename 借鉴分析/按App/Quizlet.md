# Quizlet（闪卡学习系统）

> **所属大类**：第3类 · 知识图谱 / 学习工具
> **对应房间**：模块三十四·知微阁 / 模块十·经略阁
> **宪法兼容**：闪卡原子结构与间隔重复本地化；拒绝社交排行、游戏化排名。

## 核心功能
以「闪卡」为原子知识单元，支持文字、图片、音频三种媒体类型的混合录入。提供学习模式、闪卡模式、书写模式、拼写模式、测试模式、配对游戏等多种练习方式。每张卡片维护状态，并基于遗忘曲线安排复习。

## 抄作业借鉴点
1. 闪卡原子结构 —— 双面卡片 + 富文本编辑 + 3D 翻转动画
2. 多模式练习引擎 —— 翻转 / 选择 / 默写 / 听写 / 配对
3. 智能学习路径 —— 新卡片 → 研磨中 → 已通透 → 待回炉
4. 间隔重复调度 —— 基于本地遗忘曲线算法
5. 测试卷自动生成 —— 选择题 / 判断题 / 填空题 / 配对题

## 落地要点（对应房间）
- **模块三十四·知微阁**：双面闪卡 + 富文本 + 3D 翻转、多模式练习引擎、智能学习路径、间隔调度、自动生成测试卷。
- **模块十·经略阁**：卡片知识库组织。
