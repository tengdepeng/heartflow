# 一本日记（多媒体日记与隐私保护）

> **所属大类**：第6类 · 日记 / 情绪 / 心锚
> **对应房间**：模块五·逐日心锚 / 模块四·情绪花房
> **宪法兼容**：隐私保护（应用锁 / 伪装模式 / 端到端加密）全部本地化；拒绝社交分享。

## 核心功能
将隐私保护作为产品基石，支持应用锁、伪装模式、端到端加密存储，以及文字、图片、视频、录音等日记记录形式。

## 抄作业借鉴点
1. 应用锁 —— 逐日心锚全局入口锁（密码 + 生物识别双重认证）
2. 伪装模式 —— 逐日心锚「静默模式」（输入伪装密码进入空界面）
3. 日记加密存储 —— 逐日心锚 AES-256 加密
4. 多媒体记录 —— 逐日心锚支持图片 / 视频 / 录音 / 心情 / 天气 / 标签
5. 日历回溯 —— 逐日心锚月视图日历（情绪色块标记）+「那年今日」

## 落地要点（对应房间）
- **模块五·逐日心锚**：全局入口锁（密码 + 生物识别）、静默模式、AES-256 加密、多媒体记录、月视图日历 + 那年今日。
- **模块四·情绪花房**：情绪色块标记与回溯。
