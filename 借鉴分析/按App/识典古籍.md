# 识典古籍（古籍数字化阅读与注疏分层）

> **所属大类**：第4类 · 词典 / 汉字 / 古籍
> **对应房间**：模块三十四·知微阁
> **宪法兼容**：笔记、书摘与阅读偏好存储于本地；拒绝联网依赖。

## 核心功能
以「还原古籍阅读的真实感」为核心，将传统线装书形态转化为数字交互体验。提供竖排排版、影印对照、注释与注疏分层显示、句读 / 标点切换和繁简转换。笔记、书摘和阅读偏好均存储在本地。

## 抄作业借鉴点
1. 古籍竖排排版 —— 从右至左纵向排列（知微阁内建竖排文本渲染引擎）
2. 栏线与版式 —— 栏线、界行视觉辅助线
3. 影印对照 ——「原文纯文本」与「注疏增强文本」双视图
4. 注疏分层显示 —— 按「注者 / 朝代」分层组织
5. 句读 / 标点切换 —— 原始句读 / 现代标点 / 无标点三种模式

## 落地要点（对应房间）
- **模块三十四·知微阁**：竖排文本渲染、栏线版式、影印对照双视图、注疏按注者 / 朝代分层、句读 / 标点三态切换、繁简转换。笔记与偏好本地存储。
